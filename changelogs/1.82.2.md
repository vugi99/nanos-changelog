# nanos world - Version 1.82.2

- **Release Date:** 2025-08-13 13:21:33 UTC
- **Raw Timestamp:** `2025-08-13T13:21:33.513Z`

---

### 🆕 New Features
- Added new methods to Lua Default Library from PRs (thanks Timmy): [`string.ToTable()`](https://docs.nanos-world.com/docs/next/scripting-reference/standard-libraries/string#function-totable), [`Vector.Dot()`](https://docs.nanos-world.com/docs/next/scripting-reference/structs/vector#function-dot), [`Vector.Cross()`](https://docs.nanos-world.com/docs/next/scripting-reference/structs/vector#function-cross), [`NanosMath.LocalToWorld()`](https://docs.nanos-world.com/docs/next/scripting-reference/utility-libraries/nanosmath#static-function-localtoworld).

### ⏫ Improvements
- Now Trigger entity will trigger the EndOverlap event when an overlapping Actor is destroyed.
- Now CEF Hardware Acceleration and Accelerated Painting will behave separately.
- Updated CEF to version 139.

### 🔨 Bug Fixes
- Fixed PopUps in Settings opening behind the Escape Menu.
- Fixed Fatal Errors when calling MoveTo on client side.
- Fixed WebUI crash when being destroyed while audio is playing.
- Fixed StaticMesh and Prop not applying proper scale/location when attaching to other StaticMeshes/Props at a socket when the mesh was not yet loaded.
- Fixed WebUI scale being applied even when auto_resize was false.

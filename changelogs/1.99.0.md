# nanos world - Version 1.99.0

- **Release Date:** 2025-12-04 16:06:08 UTC
- **Raw Timestamp:** `2025-12-04T16:06:08.000Z`

---

### 🆕 New Features
- The game has been updated to **Unreal Engine** version `5.7.1`! Please let us know any bug or weird behavior!
- The default Steam branch was updated with the last version 1.98.1. And a new branch called `1.98.1` was created with this update.
- We've also updated the **ADK** project to support the new Unreal 5.7.
- Added a new method to **Client**: [`ShowNotification`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#static-function-shownotification), that integrates with the built-in notification system.

### ⏫ Improvements
- **DLSS** Plugin was updated to version `8.3`.
- **Ultra Dynamic Sky** was updated to version `9.2A`.
- Added new **Video Settings**: `MegaLights` and `SMAA` to anti-aliasing list.
- Minor UI improvements.

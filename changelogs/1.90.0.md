# nanos world - Version 1.90.0

- **Release Date:** 2025-10-07 20:11:39 UTC
- **Raw Timestamp:** `2025-10-07T20:11:39.727Z`

---

### 🆕 New Features
- Added a new method for **Pawn**: `SetControlRotation()`.

### ⏫ Improvements
- Now `TranslateTo()` and `RotateTo()` will be processed on all connected clients (instead of only the Network Authority), fixing some sync issues. Also it will snap to the target on server side if no player is connected.
- Greatly improved the Debug/Profiling UI performance, solving all stutters it had when updating the debug UI overlay.
- Improved network usage by reducing the sync of attached entities.
- Improved our internal network fetch to process network data in batches, reducing the internal API calls needed.
- We had several internal improvements on Network Authority and Distribution is calculated. Improving the performance and making it more consistent and bug-free proof. StaticMeshes and TextRender are not distributed anymore, improving network usage.

### 🔨 Bug Fixes
- Fixed spawning Props with not loaded meshes causing it to do not apply Physics Enabled setting.
- Fixed `JSON.stringify` causing Stack Overflow when passing circular references. Now circular references will be nullified.
- Fixed Melee being able to trigger attack multiple times if the cooldown is set lower than the damage time.

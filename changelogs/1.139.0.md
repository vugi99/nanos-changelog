# nanos world - Version 1.139.0

- **Release Date:** 2026-05-21 11:44:30 UTC
- **Raw Timestamp:** `2026-05-21T11:44:30.909Z`

---

### 🆕 New Features
- New *experimental* **Events** and **BaseEntity** Remote Calls/Broadcast format! Added a new argument `reliability` before the `args...` to allow sending events as unreliable for performance! See the [Compatibility Versions](https://docs.nanos-world.com/docs/next/core-concepts/packages/compatibility-versions#version-1139) docs page for more information on how to update your Packages! Please provide us feedback on this change!
- Added new **Events** methods: [`BroadcastRemoteInRadius()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/events#static-function-broadcastremoteinradius) and [`BroadcastRemoteInRadiusDimension()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/events#static-function-broadcastremoteinradiusdimension).
- Added new **Base Entity** methods: [`BroadcastRemoteInRadiusEvent()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/entity#function-broadcastremoteevent) and [`CallRemotePlayersEvent()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/entity#function-callremoteplayersevent).
- Added a new method to **CharacterSimple**: [`SetAnimationBlueprintPropertyValue`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/character-simple#function-setanimationblueprintpropertyvalue).
- Added new methods [`Server.GetPlayersInRadius()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-getplayersinradius) and [`Server/Client.GetActorsInRadius()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#static-function-getactorsinradius) to query all actors or players in an area efficiently.
- Added a new keybinding to hide all UIs.

### ⏫ Improvements
- Now some debug elements will only appear after leaving the loading screen.
- Now saving WebUI settings will show a Popup if it's required to restart the game.
- Improved methods lua errors and compatibility warnings by showing more information about the call stack and the method/class being called. Also Compatibility Version warnings will only show once as "warning" to prevent polluting the logs.
- Improved more UIs translations.
- Improved Profile Popup UI.
- Improved Video Settings layout.

### 🔨 Bug Fixes
- Fixed Ray Tracing settings being activated internally even for non compatible clients.
- Fixed Profile popup showing errors when opening a non nanos world players profile.
- Fixed Resolution Scale not applying properly.
- Fixed some widescreen resolutions not appearing in video settings.

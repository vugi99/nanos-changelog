# nanos world - Version 1.64.0

- **Release Date:** 2023-11-16 10:14:12 UTC
- **Raw Timestamp:** `2023-11-16T10:14:12.768Z`

---

🆕 **New Features**
- New Package Type: **C Module**! This is the new standard to load C binary libraries! Read more in the [October News Blog](https://docs.nanos.world/blog/october-2023#new-package-type-c-module)!

⏫ **Improvements**
- Now the New Game screen properly identifies if the last created server was singleplayer or multiplayer and show/hide the multiplayer dropdown settings automatically.
- Updated Ultra Dynamic Sky to latest version.
- Virtual Shadow Map now is always enabled (fixing landscape rendering issues).

🔨 **Bug Fixes**
- Fixed a crash when attempting to download an invalid image.

# nanos world - Version 1.110.3

- **Release Date:** 2026-03-03 19:04:03 UTC
- **Raw Timestamp:** `2026-03-03T19:04:03.446Z`

---

### ⏫ Improvements
- Now when the game starts with `+connect` command, the main menu will not be loaded, skipping a bunch of unneeded load and fixing validating assets errors.
- Now for some specific settings, applying the settings will only re-apply if those were modified (reducing some stutters when saving the settings).
- Improved all Props and Physics objects that was having the Water Pontoons Physics ticking even if they were not in water, increasing the performance.
- Improved all Async operations performance and memory usage, increasing the thread initialization efficiency.
- Improved our internal game-play sounds spawn performance.

### 🔨 Bug Fixes
- Mitigated an issue when closing the server was not kicking all players (they were kicked by timeout 20 seconds after).
- Attempt to fix crashes and unknown behavior when triggering new async operations from inside another async callback, getting worse if the server was closing or packages were unloading.
- Fixed `Input.GeyKeybindings()` not returning updated keybindings if they were changed in the settings after connected to a server.
- Fixed Persistent Data not saving if they were set while Package was unloading.
- Fixed local servers (started from menu) closing before the host connects completely.
- Fixed crashes when calling entities methods from their Destroy events.
- Fixed a crash when passing recursive tables to WebUI events.
- Fixed Linux server not completely terminating when stopping it, needing an extra "enter" input.
- Fixed some dark water particles.
- Fixed Branding Bar with full width wrongly.

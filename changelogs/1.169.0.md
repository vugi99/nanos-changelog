# nanos world - Version 1.169.0

- **Release Date:** 2026-11-05 11:45:00 UTC
- **Raw Timestamp:** `2026-11-05T11:45:00Z`

---

**Attention: the public branch has been updated to the this version as well.**

### 🆕 New Features
- Added [`Trigger:IsOverlapping()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/trigger#function-isoverlapping) to check whether an Actor's location is inside a Trigger.
- Added the [`VehicleWheeled.TireFlat`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehiclewheeled#event-tireflat) event, triggered when a tire goes flat or is restored.
- Added Tracy profiling to the game client and every dedicated server. While a profiler is connected, it captures Lua callbacks, logs, entity and player counts, memory and network statistics. Note that now Tracy is always integrated and don't have a separated NanosWorlsServerTracy binary included or --tracy command-line parameter.

### ⏫ Improvements
- Remade all assets Thumbnails images as .png.
- Images referenced through `assets://` or `package://` now tries `.png` and then `.jpg` if no extension is provided.
- Improved the sign-in popup with retry and account-related actions.
- Now servers without cover image will display the game-mode's image if it's on Vault.

### 🔨 Bug Fixes
- Fixed in-game Vault not showing resource requirements in the **Dependencies** tab.
- Fixed character respawn not applying the rotation to the controller.
- Fixed opening an unpublished Vault item in the Store not opening it's preview page on web.
- Fixed parked vehicles remaining suspended after a tire went flat until something hit them.
- Fixed the camera's side offset when collision is disabled.
- Fixed spotlights producing broken shadows when given an inner cone fraction outside the valid range (fixed Playground pixelated shadows).
- Fixed `SetTireFlat` accepting an invalid wheel index.
- Fixed the `LogType` enums.

### 🌐 Account, Store & Website
- Bug reports now ask what kind of issue is being reported and show fields appropriate to that type.
- Improved the feedback form with clearer descriptions, separators and an unsaved-changes prompt.
- Forms now validate on submission instead of showing errors when an empty field loses focus.
- Markdown links now open in a new tab.

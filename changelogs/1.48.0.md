# nanos world - Version 1.48.0

- **Release Date:** 2023-04-10 14:01:44 UTC
- **Raw Timestamp:** `2023-04-10T14:01:44.928Z`

---

⏫ **Improvements**
- Now Blueprints support receiving **FTransform** Unreal struct (pass as table `{ ["Translation"] = Vector(), ["Rotation"] = Rotator(), ["Scale"] = Vector() }`).
- Supressed a warning of packets received for a non-existing entity for Inherited entities which have been destroyed.

🔨 **Bug Fixes**
- Fixed Character and CharacterSimple not syncing most of it's dynamic properties (control rotation, aiming location, axis turn, input). ☠️
- Fixed Actor and Player TranslateTo and RotateTo extrapolating the location/rotation more than the target value in some cases.
- Fixed StaticMesh entity not spawning the Error Mesh if the provided path is wrong.
- Fixed Vector passed on Scripting events compressing with 1 decimal place of precision instead of 2 decimal places.

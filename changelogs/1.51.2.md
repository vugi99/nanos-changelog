# nanos world - Version 1.51.2

- **Release Date:** 2023-04-28 13:57:27 UTC
- **Raw Timestamp:** `2023-04-28T13:57:27.000Z`

---

🆕 **New Features**
- Added a new parameter to **Input.Register()**: `description` which is shown on Keybindings Settings when hovering it while in game.
- Now **Input** **KeyBindingChange** event has a new argument: `scale`, when this is an Axis input (for Game Keybindings).

⏫ **Improvements**
- Slightly increased the opacity of notification balloons.
- Added a new validator to prevent invalid Scale values when setting it through `:SetScale()`. It does not allow 0 values.

🔨 **Bug Fixes**
- Fixed Spawn events not triggering on client side if the entity was spawned on Server. ☠️
- Fixed Vector/Color/Vector2D structs setting only the X value when passing just a number as parameter, now it will set all properties (X, Y, Z).
- Fixed client side entities triggering Fatal errors on server by calling some internal sync methods.
- Fixed setting multiple keybindings at the same time to the same Game Binding not setting it properly (e.g. Move Forward and Backward).
- Fixed some errors on Linux not displaying the message properly.

# nanos world - Version 1.82.0

- **Release Date:** 2025-07-28 18:44:19 UTC
- **Raw Timestamp:** `2025-07-28T18:44:19.007Z`

---

### 🆕 New Features
- We are migrating our login system to a new backend, nothing should change for your, but if you see login errors, please let us know!
- Added a new parameter to [VehicleWheeled:SetSteeringWheelSetup](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehicle-wheeled#function-setsteeringwheelsetup): `rotation`. We refactored how our Procedural Steering Wheels placement work on VehicleWheeled, now the parameters passed to **SetSteeringWheelSetup** must be relative to the vehicle's root bone, all vehicles will need to be reconfigured using a new relative location.
- Added new Method to **VehicleWheeled**: [`SetDifferentialSetup(differential_type, front_rear_split)`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehicle-wheeled#function-setdifferentialsetup).
- Added new last parameter to **VehicleWheeled:SetEngineSetup**: [`torque_curve`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehicle-wheeled#function-setenginesetup).
- Added new last parameter to **VehicleWheeled:SetWheel**: [`suspension_sweep_shape`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehicle-wheeled#function-setwheel).

### ⏫ Improvements
- Improved Stack O Bot mesh physics ragdoll.
- Added the Asset Pack and Package version to logs when loading them.
- Updated CEF to version 138.

### 🔨 Bug Fixes
- Fixed Creating Package through UI or CLI not generating Client/Index.lua file.
- Fixed Server crashing when restarting the server or changing the map if a method was called from a Player's Destroy event.
- Fixed Characters not reacting properly to hit damages.

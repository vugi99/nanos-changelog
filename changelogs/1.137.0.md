# nanos world - Version 1.137.0

- **Release Date:** 2026-05-04 13:17:09 UTC
- **Raw Timestamp:** `2026-05-04T13:17:09.521Z`

### 🆕 New Features
- New **Client** and **Server** `ValueChange` event. Called when a value is changed (for both synced and local values).

### ⏫ Improvements
- Implemented a new system to allow sending larger network messages than 512KB (for now only implemented for Server's SetValue calls).
- Now the wishlist popup on Playtest will stop appearing after you press the "wishlist" button.
- Several internal code implements and minor fixes.

### 🔨 Bug Fixes
- Fixed a crash when changing entities dimensions.
- Fixed more UIs broken due localization and Chinese/Japanese texts.

# nanos world - Version 1.112.0

- **Release Date:** 2026-03-09 16:12:30 UTC
- **Raw Timestamp:** `2026-03-09T16:12:30.567Z`

---

### 🆕 New Features
- Added new **Thread Pool** system for async operations, now every async call (HTTP, Database, File) will be handled by our thread pool, which can be configured by `--thread_pool_count`. The default pool count is 8 (or the amount of CPU cores).
- Added a new Config.toml setting: `max_file_transfer_rate`, which allows separating the max file transfer download speed from the overall send rate for players.
- Added new built-in server commands: `profiling`, `log_level` and `max_file_transfer_rate`. To allow dynamically changing those values.
- Added new command-line parameters: `--max_file_transfer_rate` and `--thread_pool_count`.

### 🔨 Bug Fixes
- Fixed Packages being loaded in wrong order on client side.
- Fixed crash when calling `Client.Disconnect()`.
- Fixed "heartbeat" errors when starting a local server.
- Fixed server side profiling not outputting logs.
- Fixed server looping forever when having too many network packets to process and not being able to handle them in time.
- Attempt to fix crashes when ALT+F4 when having WebUIs spawned.

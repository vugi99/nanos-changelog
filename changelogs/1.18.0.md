# nanos world - Version 1.18.0

- **Release Date:** 2022-10-07 09:02:34 UTC
- **Raw Timestamp:** `2022-10-07T09:02:34.350Z`

---

**New Features**
- New **Dimensions**! Now it is possible to set entities/actors dimensions (experimental)!
- Added new methods to **Client**: `SetDebugEnabled()` (to force 3D debug off) and `GetFrameTime()`.
- Added `UnrealFolder` to Assets.GetAssetPacks().
- Added new method to **Actor**: `GetNetworkAuthority()`.

**Improvements**
- Added Vehicle wheel brake sound effects.
- Added auto FOV while driving.
- PickUp now has dynamic head/tail lights (experimental).

**Bug Fixes**
- Fixed non string keys in maps not being able to pass through CEF events.
- Fixed Canvas Materials crashing and not working (still not perfect).
- Fixed Detach destroying things and crashing the server.

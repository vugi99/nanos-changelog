# nanos world - Version 1.19.6

- **Release Date:** 2022-10-24 12:57:03 UTC
- **Raw Timestamp:** `2022-10-24T12:57:03.000Z`

---

**Improvements**
- Reduced Downward character force to 10% (will reduce weird physics effects when over other physics objects).
- Improved the camera transition to ragdoll mode (now it's smoother).

**Bug Fixes**
- Fixed Weapons keeping firing for other players when reloading.
- Fixed other players bullets going to world origin when iron-sighting.
- Fixed not being able to stand up when getting in ragdoll over physics entities.
- Fixed getting up from ragdoll when crouching/proning not restoring the state properly.
- Fixed crash when using Blueprint Event Dispatcher after closing the game.
- Fixed a bug which was duplicating Level StaticMeshes.
- Fixed Player.GetCameraLocation() returning Character location instead.

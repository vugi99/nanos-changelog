# nanos world - Version 0.20.0

- **Release Date:** 2020-05-26 13:35:24 UTC
- **Raw Timestamp:** `2020-05-26T13:35:24.964Z`

---

**New Features**
*  New Scripting function: `Client.IsKeyDown()`.
*  Now weapons won't trigger damage or effects when damage is set to 0 (useful for creating tool guns or prop spawning guns).
*  We've upgraded our Weapon's particles to use the newest Unreal's Particle System, it changed some assets used in the default Weapons. **Scripters: please download the newest version of nanos-weapons package.**

*Improvements**
*  We've improved all Weapon's Particles (Trail, Smoke and Shell Eject), and also added a light flash when shooting.

**Bug Fixes**
*  Fixed server not closing on Windows.
*  Fixed Weapons triggering Empty sound when Clip is full.

# nanos world - Version 1.45.1

- **Release Date:** 2023-03-27 11:13:20 UTC
- **Raw Timestamp:** `2023-03-27T11:13:20.000Z`

---

**⏫ Improvements**
- Now starting a New Game from menu uses the local port configured in the Config.toml to connect to localhost.
- Now connecting to a server started from New Game will fail (abort) if the server stops or fails to load, instead of waiting 5 minutes to timeout.

**🔨 Bug Fixes**
- Fixed Maps names showing trimmed in the Server List.
- Fixed Recommended map when starting a New Game appearing empty.
- Fixed not being able to start a server from New Game menu with empty Custom Settings set.
- Fixed a crash when starting a server with invalid 'custom_settings' command-line parameter, it will throw an error instead.
- Fixed invalid Config.toml causing the server to override all the settings, now it will just abort the server startup until it's fixed.
- Fixed CharacterSimple not working if spawned on Client Side.
- Fixed some typos in log messages.

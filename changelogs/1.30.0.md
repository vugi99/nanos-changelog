# nanos world - Version 1.30.0

- **Release Date:** 2023-01-22 13:38:30 UTC
- **Raw Timestamp:** `2023-01-22T13:38:30.978Z`

---

**New Features**
- Added new method to **Sky**: `ChangeWeather`, allowing it to use Ultra Dynamic Sky weather system.
- Now **Sky.Spawn()** has a new parameter `spawn_weather` to spawn Ultra Dynamic Weather actor to allow usage of Sky's Weather methods.
- Added new settings to **Map.toml**: `packages_requirements` and `compatibility_version`.
- Added new setting to **Package.toml**: `load_level_entities` to load Level Static Mesh Entities when map is loaded.
- Added new method to **Input**: `GetModifierKeys()` which returns all currently active modifier keys.
- Added new method to **WebUI**: `IsFrozen()`

**Improvements**
- Now server --offline mode will not fetch from Vault anymore when being starting.

**Bug Fixes**
- Fixed Input.GetKeyCode missing keys.
- Attempt to fix a random crash when using Level Streaming.
- Fixed verbose logs being active for initial logs when starting the server.
- Fixed wrong Package.toml wrong Compatibility Version being set by default.
- Fixed force_no_map_package not being reset when reloading all packages/changing map.
- Fixed a bug causing wrong Package environment being considered when spawning an entity or calling a special method (wrong Package Compatibility Version or Package entity owner).
- Fixed WebUI SetFreeze treating the parameter as inverted.

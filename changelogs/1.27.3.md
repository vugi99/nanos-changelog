# nanos world - Version 1.27.3

- **Release Date:** 2023-01-09 12:24:16 UTC
- **Raw Timestamp:** `2023-01-09T12:24:16.919Z`

---

**Improvements**
- Now it's possible to tweak and define Game Mode custom settings before starting a server from New Game menu even if the Package is not downloaded.
- Added a new system to queue server events and entities initialization while hot/reloading packages. All events will be triggered and all entities will be initialized only after the pending packages load (fixes entities being initialized without the Inherited Class).
- Improved/fixed a lot of unnecessary warnings in the client console.
- Improved Discord errors code messages.

**Bug Fixes**
- "Fixed" server list showing wrong max players due Steam clamping the values, we added a workaround to display the correct values.
- Fixed Compatibility Version setting wrong default values (it was inverted).
- Attempt to fix a CEF crash when rendering PopUps.

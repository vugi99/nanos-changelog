# nanos world - Version 1.97.2

- **Release Date:** 2025-11-21 15:55:04 UTC
- **Raw Timestamp:** `2025-11-21T15:55:04.156Z`

---

### 🆕 New Features
- Added a new **Badges** section to your in-game Profile! You can see all your earned Badges!

### ⏫ Improvements
- Now `Sky.Spawn()` will return true if we found an existing UDS Actor in the map.
- Now Spawning a Sky will also destroy `Engine/BP_Sky_Sphere` actor.
- Now if a Map Package depends on an outdated Asset Pack (with older Unreal Version), it will be disabled when selecting a map to start a game through the menu.

### 🔨 Bug Fixes
- Fixed some achievements and stats not counting properly.
- Fixed StopAnimation() not stopping if the animation was not a Montage.
- Fixed Vault not allowing to select any package as additional to start a server.
- Fixed Vault Map Package creation not setting the Package.toml properly.

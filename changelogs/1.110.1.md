# nanos world - Version 1.110.1

- **Release Date:** 2026-02-24 21:57:45 UTC
- **Raw Timestamp:** `2026-02-24T21:57:45.520Z`

---

### 🆕 New Features
- We implemented a new internal **Constructor Cache** system. Now the entities construction data is cached until modified, this way we can reduce (a lot) the CPU usage by not serialize/compress all the entities every time a player connects/changes dimensions. **If you notice any desync please let us know immediately!**

### ⏫ Improvements
- We upgraded our compression library, and it should be up to 4x faster to compress/decompress files and networking data.
- Moved [Set/GetDamageMultiplier](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/damageable#function-setdamagemultiplier) from Character to BaseDamageable. Now CharacterSimple can use it too.

### 🔨 Bug Fixes
- Fixed Consolle.RegisterCommand not working (from last update).
- Fixed Character SetAnimationsTransitionStandingCrouching and SetAnimationsTransitionCrouchingProning not syncing correctly.

# nanos world - Version 1.68.0

- **Release Date:** 2024-11-02 09:42:26 UTC
- **Raw Timestamp:** `2024-11-02T09:42:26.925Z`

---

⏫ **Improvements**
- Now the client will first validate if the server is in the same version, preventing crashes when we have the connection data changed.
- Now when starting a game from the menu, the client will validate if the local server wasn't started successfully and will show an error message and abort the connection.
- Now the server logs will tell the debug reason the client disconnected (instead of just "Goodbye").
- Reduced size of Character & CharacterSimple construction data.
- Changed the bottom bar text when loading the current version & build information.

🔨 **Bug Fixes**
- Fix keybindings & other custom options not persisting to disk when saving the settings.
- Fixed popup errors not always displaying if something fail when connecting to a server.

# nanos world - Version 1.9.7

- **Release Date:** 2022-06-22 16:17:58 UTC
- **Raw Timestamp:** `2022-06-22T16:17:58.766Z`

---

**New Features**
* Added new parameter to **Weapon:SetMagazineMesh()**: `magazine_mesh_hide_bone` (which bone to hide when reloading the weapon).

**Improvements**
* Now client inputted commands in the client console will be displayed in there.
* Added client console history (press arrow up/down to navigate).
* All old deprecated weapons accessors were removed.
* Increased ADS aiming animation speed.
* Updated Ultralight to latest build.

**Bug Fixes**
* Fixed a crash when setting tables with functions inside with :SetValue().
* Fixed logs being sync by default.
* Fixed some background colors in the settings.

# nanos world - Version 1.132.1

- **Release Date:** 2026-04-19 14:01:32 UTC
- **Raw Timestamp:** `2026-04-19T14:01:32.630Z`

---

### 🆕 New Features
- New `enable_water_buoyancy` property for Map `Package.toml`. Now you must enable it if your map uses Water Plugin and you want to use Buoyancy component on Actors. This will increase performance when not using water physics.

### ⏫ Improvements
- Now the max global Player **VOIP** channel count is `63` (was 31).
- Improved **Lua Events** performance by deferring the arguments construction to happen only if an event is subscribed. This will improve the overall performance when not subscribing to events.
- Improved the distance sync algorithm by making it more consistent, efficient and fixing some sync issues.
- Improved the client actor interpolation for high speed actors, causing them too hardsnap too often.
- Improved client HTTP errors by only showing a simplified error notification.
- Improved several internal syncing methods by reducing their usage and grouping calls for efficiency.

### 🔨 Bug Fixes
- Fixed `Package.SetPersistentData()` not escaping keys properly.
- Fixed several warnings when someone disconnects while in the authentication queue.
- Fixed **Mouse Inputs** not being released when setting Mouse Enabled, causing them to keep pressed until pressing again.

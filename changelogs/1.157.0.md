# nanos world - Version 1.157.0

- **Release Date:** 2026-09-23 11:59:01 UTC
- **Raw Timestamp:** `2026-09-23T11:59:01.000Z`

---

**Attention:** we are updating the `default` branch to the latest `1.156.0` version.

### ⏫ Improvements
- Servers can now mount their own **UltraDynamicSky** Asset Pack version, if none is mounted the native's one will be used for spawning `Sky`. **Note: we will update to the latest UDS version in the next updates!**
- Now the Team Popup "open in browser" button will open the team's public page properly.

### 🔨 Bug Fixes
- Fixed [`Vehicle:SetCameraOffset()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-setcameraoffset) not being applied to the live camera.
- Fixed [`Entity:CallRemoteEvent()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/entity#function-callremoteevent) and [`Entity:BroadcastRemoteEvent()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/entity#function-broadcastremoteevent) always sending as reliable regardless of the call's parameters.
- Fixed a character taking ragdoll damage when standing on a moving object.
- Fixed `Light.Rect` enum typo.
- Fixed server commandlines `--max_tick_rate`, `--max_sync_rate`, `--max_send_rate`, and `--max_file_transfer_rate` not being parsed correctly.
- Fixed `Sky.SetOverallIntensity()` not working correctly.

### 📜 Docs
- Updated/added all API functions, events and parameters descriptions.
- Improved a lot of tutorial pages, fixed wrong examples and added many new example pages and guides.

### 🌐 Account, Store & Website
- Now it's possible to add `Languages`, `Links` and `Videos` to your [Packages](https://nanos-world.com/account/packages) and [Asset Packs](https://nanos-world.com/account/assets) in the store!
- Redesigned profile and team pages with new tabs, your reviews, game jams participated, your resources and projects, and activity/stat counts!
- Now you can add links to your [Teams](https://nanos-world.com/account/teams) profile!
- Now all links added will match common pages brands and render it's icon automatically!
- Merged the publishing checklist and visibility settings, a resource/project can only be published after completing the checklist.
- Added a new notification pill in your profile image if you received a support message answer.
- Improved favorite buttons layout.
- Several minor improvements and bug fixes.

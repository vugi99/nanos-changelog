# nanos world - Version 1.64.10

- **Release Date:** 2024-02-20 12:55:26 UTC
- **Raw Timestamp:** `2024-02-20T12:55:26.255Z`

---

⏫ **Improvements**
- Added new Anti Aliasing Method Video Setting to choose which AA to use (TAA, FXAA, TSR or None).
- Now calling Character:SetSetGravityEnabled() will cause an warning (use Character:SetGravityScale() instead).
- Added new parameters to Rotator.Random(): min, max.
- Added new NanosMath.RandomFloat() aux method.

🔨 **Bug Fixes**
- Fixed vehicles unrotating even without engine started.
- Fixed Stance Mode set by server not applying properly on client (palliative).
- Fixed Actor:GetBounds() returning wrong values if the entity was scaled.
- Minor improvements and typo fixes.

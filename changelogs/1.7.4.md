# nanos world - Version 1.7.4

- **Release Date:** 2022-05-11 21:13:04 UTC
- **Raw Timestamp:** `2022-05-11T21:13:04.833Z`

---

**New Features**
* Added new arguments to all Weapon's Anims and Sounds setter methods (pitch, volume, rate).
* New Outline Post Process which supports thickness parameter to be configured on Client.SetOutlineColor.

**Improvements**
* Improved default Vehicle Pickup handling.
* Completely removed the deprecated old Weapon Constructor parameters.
* Reworked the Weapons animation when aiming or ADS to use the new UE5 Control Rig system (++ removing functionalities from the Animation Blueprint).
* Reduced Impulse from firing.
* We've momentarily disabled the CCD for Props and Grenades as it was causing some hit detection problems (already submitted a ticket to Epic).
* Enabled Runtime Generation Navmesh.
* We've completely moved all built-in Post Process settings to the Default Sun instead of the cameras.

**Bug Fixes**
* Fixed calling extended method Super not working if it was called by another extended method.
* Fixed Asset Packs not validating the "patch" version when connecting to a server.
* Fixed Props rescaling not recalculating ability to grab.
* We did an attempt to fix a weird and random WebUI crash.

# nanos world - Version 1.84.0

- **Release Date:** 2025-08-22 18:46:57 UTC
- **Raw Timestamp:** `2025-08-22T18:46:57.629Z`

---

### 🆕 New Features
- The **VOIP system** got a big overhaul, and some VOIP methods have been completely changed. Now Players will have two separated settings category, for Local and Global VOIP. New VOIP Multi-channel feature. Now it is possible to set a Player to multiple global channels at the same time. A player can be in any amount of channels as speaker, listener or both at the same time (the channels count limit is 31). See our new [Docs Tutorial](https://docs.nanos-world.com/docs/next/core-concepts/scripting/voip#muting) for more information.
- Added a bunch of new VOIP methods to Players: [`SetVOIPGlobalHighPassFilter()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoipglobalhighpassfilter), [`SetVOIPGlobalLowPassFilter()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoipgloballowpassfilter), [`SetVOIPGlobalVolume()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoipglobalvolume),  [`SetVOIPLocalVolume()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoiplocalvolume), [`SetVOIPLocalSetting()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoiplocalsetting),  [`SetVOIPGlobalChannelSetting()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoipglobalchannelsetting),  [`SetVOIPGlobalAllChannelsSetting()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoipglobalallchannelssetting),  [`SetVOIPMuted()`](https://docs.nanos-world.com/docs/scripting-reference/classes/player#function-setvoipmuted), and their respective Getters as well.
- Now starting the game for the first time will automatically run a **Benchmark** process to identify the best **Quality Settings**.
- Added an **Auto Detect** button to Video Settings, to identify and set the best Quality Settings.
- Added a **Configure Microphone** button in the Audio Settings, which will open the Steam Overlay settings.
- **DLSS** will be enabled by default on compatible PCs.

### ⏫ Improvements
- Improved **Fullscreen Mode** Video Setting: now selecting a fullscreen mode will only show the compatible resolutions for it. Also it will now detect if the Fullscreen Mode was changed with F11 or ALT+ENTER and update the UI properly.
- Improved **Max FPS** settings in Video Settings, now the unlimited will be achieved by moving the slide to the right, and the "unlimited" label will appear.
- Reduced Linux binary size (it was 10x it's size since some updates ago).
- Now Download Speed in Loading Screen will increase/decrease smoothly.
- Removed the DoF (Depth of Field) experimental setting (it was not good).

### 🔨 Bug Fixes
- Attempt to fix Fatal Errors when a Player disconnects while haven't fully connected on P2P server
- Fixed a server side crash when players connects.
- Fixed Blog News text overflow on main menu.
- Attempt to fix Scaled Display broken fullscreen.
- Fixed Players avatar in chat sometimes appearing white.

# nanos world - Version 1.13.2

- **Release Date:** 2022-08-06 14:37:35 UTC
- **Raw Timestamp:** `2022-08-06T14:37:35.733Z`

---

**Improvements**
- New In-game Console UI. Plain Text console was removed as it was extremely bad performatic and causing crashes. Now it's possible to copy console lines by selecting them and pressing CTRL+C.

**Bug Fixes**
- Fixed map-package not loading client side.
- Fixed grenades forcing it's collision to be Block All after being thrown.
- Fixed old assets/// and packages/// path not working anymore (now are just deprecated).
- Fixed WebUI crashing the  game when being destroyed.
- Fixed WebUI input locking ESC and other inputs.

# nanos world - Version 0.3.0

- **Release Date:** 2020-04-21 11:42:32 UTC
- **Raw Timestamp:** `2020-04-21T11:42:32.723Z`

---

**New Features:**
*  New **Prop Grabbing** system! Now Characters can grab Props around (E key), throw them (Left Click) and rotate them while grabbing (Mouse Wheel w/ optional Right Click).
*  New **Outline** system! Now Pickables (Weapons, Grenades and Items) and Props will highlight when you are able to interact with/pickup them.
*  Added **Mr. Neno** to post automatically the news in this channel :sunglasses:. This is integrated to our Build machine, so in about 5-10 minutes after this message, this version should be already available on Itch.
*  We've finished the Version system so each update will have a new version number and that will be displayed on Itch as well.

**Improvements**
*  Increased the precision of Synced objects.
*  Increased the interacting range of Characters.
*  Improved default Network Testing map floor (now it's better aligned and Vector(0, 0, 0) is the epicenter).

**Bug Fixes:**
*  Fixed a bug which was messing Players possessing Characters (with multiplayer), causing you to control other Character than the assigned.

# nanos world - Version 1.61.0

- **Release Date:** 2023-10-18 12:27:32 UTC
- **Raw Timestamp:** `2023-10-18T12:27:32.098Z`

---

🆕 **New Features**
- Added new method to **Character**: `SetHitReactionEnabled()`, to disable some ragdoll issues cause by custom skeletons.
- Added new methods to **Server**, **Client** and all **Entities**: `GetAllValuesKeys` to return a list of all keys set with SetValue.

⏫ **Improvements**
- Now NanosTable.Dump() will format empty tables in a more beautiful way, and also keys will be in Lua format with brackets [].
- Now SceneCapture has a maximum size of 4096.
- The main menu World has a better zooming behavior.
- Now Vault downloaded .zips will be deleted after the installation is finished.

🔨 **Bug Fixes**
- Fixed Character Punch event not triggering on client side.
- Fixed File not being able to access non existing files on server.
- Fixed Vault not showing up more than 50 items.
- Fixed a crash when passing the same table multiple times as parameters to events.

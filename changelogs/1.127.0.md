# nanos world - Version 1.127.0

- **Release Date:** 2026-04-10 15:56:48 UTC
- **Raw Timestamp:** `2026-04-10T15:56:48.049Z`

---

### 🆕 New Features
- Added a new setting to server **Config.toml**: `max_sync_rate`. To adjust the maximum actors sync frequency for location/rotation/velocity. It affects both clients and server and can drastically reduce networking usage and increase server performance.

### ⏫ Improvements
- Now **Ultra Dynamic Sky** Clouds Quality will be affected by the **Effects** video setting, being swapped with Static Clouds on medium/low setting.
- Disabled shadows on Blank Map floor.

### 🔨 Bug Fixes
- Attempt to fix a client crash due Decal actors being automatically destroyed by Unreal when fading out.

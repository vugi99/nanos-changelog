# nanos world - Version 1.49.0

- **Release Date:** 2023-04-14 12:48:30 UTC
- **Raw Timestamp:** `2023-04-14T12:48:30.419Z`

---

This update introduces a new compatibility version (1.49.0), which has changes to Package and Server methods.

🆕 **New Features**
- Now Logs are split by session! On server they are now saved into a new `.logs/` folder.
- Added new method to **Server**: `GetMapAsset()`, which returns the Map Asset which is loaded.
- The method `Server.GetPackages()` signature was changed and the old version now works in compatibility mode. The new version has a new parameter (package_type_filter) and now returns a list of tables with more information of the packages (was a list of packages names).
- The method `Server.GetMaps()` was deprecated in favor of Server.GetPackages(false, PackageType.Map)`.
- The method `Server.GetMap()` now works in compatibility mode as now it returns the Map Package name loaded.
- The method `Package.GetName()` now works in compatibility mode as now it returns the real Name/Path of the package, and not the Title anymore.
- We got a new method `Package.GetTitle()` for returning the title itself, and `Package.GetPath()` was deprecated in favor of the new `Package.GetName()`.
- Added a new event to **Input**: `KeyBindingChange` which is called when the player changes a keybinding in the Settings and press Apply.
- Added new Settings for debugging the network (`fake packet lag`, `fake rate limit` and `fake packet reorder`) to help debugging and testing with poor or bad connections.

⏫ **Improvements**
- Key Binding Settings are now are only saved when Apply Settings. (It was messy before, saving but not applying, so after reopening the game it was all applied).
- Also Key Bindings Settings show the real name when hovering the keys (which can be used through scripting).
- Now Input.SetInputEnabled() only disables the inputs, and do not show the mouse anymore.
- The overall hardcoded time taken between finishing up loading and starting to play has been reduced from 5.0 to 1.5 seconds.

🔨 **Bug Fixes**
- Fixed Escape Menu Server Information images and texts flickering. Made it more smooth overall.
- Fixed Input.SetInputEnabled() not disabling the input properly if the Character is not possessed.
- Fixed Widget.BringToFront() not working.
- Fixed some random crashes during File Transfer.

# nanos world - Version 1.86.0

- **Release Date:** 2025-09-19 13:03:38 UTC
- **Raw Timestamp:** `2025-09-19T13:03:38.112Z`

---

### 🆕 New Features
- Added a new parameter to **Light**: `source_radius`.
- Added a new method to **Server/Client**: `GetEntityByID()`.

### ⏫ Improvements
- Now Character.SetSpeedMultiplier will also scale the Character animation properly based on the Character scale.
- Ultra Dynamic Sky has been updated to version **9.1**. Please make sure to get the latest version on your Asset Pack.
- Now the Use Sound will be played attached to the Pickable (instead of spawning at it's location).
- Improved the TOML generator by prettifying the custom_data section.

### 🔨 Bug Fixes
- Fixed a deadlock causing freeze in the game/server when closing/disconnecting.
- Fixed Server.GetMapConfig and Server.GetSpawnPoints not retrieving the latest config when reloading the map package.
- Fixed Characters being damaged not applying the effects locally on the damaged client.
- Fixed duplicated inherited entities passed as parameters to events not being parsed properly.
- Fixed server crash when hot reloading an Asset Pack which got a modified invalid Assets.toml
- Fixed Attached entities not being loaded in order of creation on client side.
- Fixed ugly errors messages like "CARRIAGE RETURN" when parsing TOML files.
- Fixed NanosTable.Dump not considering Inherited Entities.
- Fixed Melee Use Sound not applying volume and pitch correctly.

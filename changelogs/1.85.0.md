# nanos world - Version 1.85.0

- **Release Date:** 2025-08-28 10:27:21 UTC
- **Raw Timestamp:** `2025-08-28T10:27:21.766Z`

---

### 🆕 New Features
- Now WebUI supports **Drag'n Drop** events! This has been finally been properly implemented!
- Added a new parameter to **AddStaticMeshAttached**: `attachable_id`, to attach this mesh to another attached mesh component, instead of the default root component.
- Added two new parameters to **AddSkeletalMeshAttached**: `use_base_leader_pose_component`, to set if this will copy the root component animations and `attachable_id` as well (same as static mesh).
- Added a new Loading Screen step for **Compiling Shaders**. Also added a Main Menu notification when shaders are being compiled in background.
- Added a new **Unbind** button to the Settings Keybindings, so you can leave a binding without a key assigned.

### ⏫ Improvements
- We've updated all the game **Cursors**.
- **Ultra Dynamic Sky** has been updated to the latest `v9.0B`. Please make sure to update yours to the latest version if you are using it in your assets!
- Improved the escape menu performance, fixing the stutter when opening it while in-game.
- Improved several UI Widgets, improving the overall menu performance, fixing some layout and usability.
- Now when you can't connect to log-in, an "offline" label will show up in the main menu.

### 🔨 Bug Fixes
- Attempt to fix Dispatchers Bind crashes.

# nanos world - Version 0.28.0

- **Release Date:** 2020-06-24 10:26:54 UTC
- **Raw Timestamp:** `2020-06-24T10:26:54.446Z`

---

**New Features**
*  Now Assets are validated on Server Side if they are from the correct type or if they exist.
*  Assets are now Pre-loaded on Client Side before entering the server itself, it will improve (a lot) the performance and will remove some stuttering.
*  Now if you try to load an Asset using the full path, you will get a warning.

**Bug Fixes**
*  Fixed some Packages not being sent to the clients.
*  Fixed Asset Packs not being loaded on client side.

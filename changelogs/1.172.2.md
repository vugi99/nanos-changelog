# nanos world - Version 1.172.2

- **Release Date:** 2026-11-26 16:00:00 UTC
- **Raw Timestamp:** `2026-11-26T16:00:00Z`

---

### 🆕 New Features
- Added `Vector2D` methods `Equals()`, `IsNearlyZero()` and `IsZero()`.

### ⏫ Improvements
- Now `Vector` and `Rotator` `Equals()` and `IsNearlyZero()` use a default tolerance of `0.0001`, the same as Unreal.
- Now numbers, `Vector`, `Rotator`, `Color` and `Vector2D` components smaller than `0.0001` are no longer rounded to `0` when they reach Lua.
- Now server files of `1 MB` and up download through HTTP again by default, falling back to sockets if HTTP fails.
- Added the `max_http_transfer_rate` setting (`Config.toml`, KB/s, unlimited by default) to cap the total HTTP download bandwidth of all players.

### 🔨 Bug Fixes
- Fixed a fatal error when reloading a package whose scripting files list is `512 KB` or larger.
- Fixed a player being disconnected when an HTTP file download failed. The download now falls back to sockets.
- Fixed ANSI colors in log messages showing as broken text like `[7m[34mINFO` in the server console.

### 🌐 Account, Store & Website
- Game jams moved into a Community tab, out of the top navigation.

### 📚 Documentation
- Fixed type names not breaking lines in tables, and improved the table, inline keys, functions and parameters layout.

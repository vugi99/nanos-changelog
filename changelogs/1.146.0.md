# nanos world - Version 1.146.0

- **Release Date:** 2026-07-09 10:41:08 UTC
- **Raw Timestamp:** `2026-07-09T10:41:08.933Z`

---

### 🆕 New Features
- Added new **Level** events [StreamLevelBeginPause](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/level#event-streamlevelbeginpause) and [StreamLevelEndPause](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/level#event-streamlevelendpause) when a stream level pause beings/end (also removed the unreal native throbber "...")
- Added new static method [Player.GetBySteamID()](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#static-function-getbysteamid) to retrieve a Player by it's Steam ID.
- Added new method [Timer.SetRemainingTime()](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/timer#static-function-setremainingtime) to modify an existing timer.
- Added new methods [BaseActor.SetDistanceOptimizationMultiplier()](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-setdistanceoptimizationmultiplier) and [Player.SetDistanceOptimizationMultiplier()](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-setdistanceoptimizationmultiplier) to customize per-entity distance optimization.
- Added "Bullet Hit Impact" particles to the Default Asset Pack.

### ⏫ Improvements
- Improved several menu UIs, for performance and localization.
- Added "Danger Zone" section to Vault Manage.

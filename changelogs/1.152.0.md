# nanos world - Version 1.152.0

- **Release Date:** 2026-08-20 12:50:48 UTC
- **Raw Timestamp:** `2026-08-20T12:50:48.486Z`

---

### 🆕 New Features
- Added a new method [`File.Rename()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/file#static-function-rename), to rename or move a file or folder.
- New **experimental** network packets bundling. Now network packets are merged together before flushing to reduce amount of packets being sent to the wire. Please let us know if you notice any network issue or desync. This can be disabled with the command `use_network_bundle`.

### ⏫ Improvements
- Improved the server files cache system by also validating if the file size was changed to invalidate the cache.
- Increased the File Transfer system tick rate and reduced the send buffer to improve the overall server responsiveness and mitigate some connection issues.
- Added the **NiagaraFluids** plugin content.
- Updated **Discord SDK** to v1.10.

### 🔨 Bug Fixes
- Fixed the **File Transfer Rate** server setting not working correctly.
- Fixed an internal progressive small memory leak.

### 🌐 Account, Store & Website
- Added new veteran badges (for having an account older than N years). E.g. [One Year](https://nanos-world.com/community/badges/7dd372b9-2ff3-42ed-be5a-62ede1024e08).
- Implemented several meta tags to display any store or community page prettier when sharing a link to discord or social media.
- Improved Team and Resource sorting on the Store to take total ratings and downloads into account.
- Now uploading a Team or Resource image requires the correct aspect ratios.
- Improved overall layout, unified and standardized components and added several tooltips to elements.
- Fixed compatible maps links broken.
- Fixed several bugs and issues.

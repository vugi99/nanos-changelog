# nanos world - Version 1.122.0

- **Release Date:** 2026-04-03 16:26:09 UTC
- **Raw Timestamp:** `2026-04-03T16:26:09.125Z`

---

### ⏫ Improvements
- Improved **Uploading Resources** through Vault and CLI, now it displays better progress bar when compressing/archiving the files (instead of just a 100% bar lasting *forever*).
- Now `Actor.IsNetworkDistributed()` also returns if the actor can *ever* distribute network authority (e.g. Light, TextRender, etc).
- Improved a lot of networking sync performance and network usage.
- Updated our internal HTTP library.
- The config `max_send_rate` was changed defaulted to 1024.

### 🔨 Bug Fixes
- Fixed HTTP requests/SSL errors when going to menu/starting the server.
- Fixed uploading resources to vault failing if any path/file contained non utf8 characters.
- Fixed StaticMesh not allowing distribute network authority.
- Fixed VOIP volume not affecting global VOIP audios.

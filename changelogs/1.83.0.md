# nanos world - Version 1.83.0

- **Release Date:** 2025-08-16 10:58:49 UTC
- **Raw Timestamp:** `2025-08-16T10:58:49.247Z`

---

### 🆕 New Features
- Added new client-side events to **CharacterSimple**: `Jump`, `StartCrouch`, `EndCrouch`, `Land` & `MovementModeChange`.
- Added new methods to **Client** & **Server**: `GetLogLevel()`.
- Added new method to **Console**: `Debug()` (`S_DEBUG`), to only output if Log Level is Debug or Verbose.
- Added a new Log Type: `PROFIL` to display only Profiling logs (if enabled).
- Added new methods to **CharacterSimple**: `Bind/UnbindAnimationBlueprintEventDispatcher`, now you can bind for it's AnimationBlueprint dispatchers.

### ⏫ Improvements
- Now Console log methods will display which package is calling it.
- Improved Character collisions when in Ragdoll.
- Improved Profiling system by grouping the same operation when displaying it on the screen (in the logs it still displays each operation separately).

### 🔨 Bug Fixes
- Fixed a client fatal error when calling CharacterSimple:SetMesh from server side.
- Fixed WebUI DevTools not working (downgraded CEF to 138).
- Attempt to fix Players Steam avatars images not loading randomly.

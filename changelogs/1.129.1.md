# nanos world - Version 1.129.1

- **Release Date:** 2026-04-12 15:55:20 UTC
- **Raw Timestamp:** `2026-04-12T15:55:20.210Z`

---

### 🆕 New Features
- Added a new **Authentication Queue** to attempt to prevent Steam rate limiting the server from authentication users. The queue time can be changed with `--auth_queue_time` console command and is by default `1` (second).

### ⏫ Improvements
- Now the **FPS** widget will display generated frames (from DLSS FG) besides the original FPS, instead of a new line.
- Now the **loading screen** will display the "waiting steam authentication" step.
- Now **Timers** will display the source Lua file and line for better debugging with Profiling.

### 🔨 Bug Fixes
- Fixed discord Rich Presence not updating current players count when players disconnect.
- Fixed server warnings of "deferred entities not found". Now it will display as a debug message (when clients send destroyed entities in events to server).

# nanos world - Version 1.124.4

- **Release Date:** 2026-04-06 22:04:54 UTC
- **Raw Timestamp:** `2026-04-06T22:04:54.268Z`

---

### 🆕 New Features
- Added new method [`Events.CallRemotePlayers()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/events#static-function-callremoteplayers) which accepts a table of players to send a message, this is more efficient than sending the same message individually to players.
- Added a new method [`Server.GetConnectionCount()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-getconnectioncount) which returns the total current connections (including players that didn't load yet).
- Added a new **Server** event [`PlayerDisconnect`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#event-playerdisconnect) which triggers even for players that didn't load yet.

### ⏫ Improvements
- Added a new system that drastically improves the network and CPU usage when syncing too many actors location/rotation/velocity, by grouping all changes into a single network call. Reducing duplicated syncs or general desyncs.
- Now only the network authority **Characters/CharacterSimple** will have the **Movement Component** enabled. If you see any desync issue with Characters/CharacterSimple please let us know!

### 🔨 Bug Fixes
- Fixed Trigger not "following" the attached actor on client side.

# nanos world - Version 1.169.2

- **Release Date:** 2026-11-06 10:00:00 UTC
- **Raw Timestamp:** `2026-11-06T10:00:00Z`

---

**Attention: the public branch has been updated to the this version as well.**

### ⏫ Improvements
- Timer and Input are now real Static Classes (internally).
- Improved loading performance when joining servers and loading Asset Packs.
- Improved client performance when tracking Actor visibility and their distance.
- Improved the responsiveness of HTTP and Vault operations on the client by using separated dedicated threads for them.
- Improved profiling displays for timing, memory, network usage, and counts, and named the CEF IO thread.

### 🔨 Bug Fixes
- Fixed VOIP audio causing bursts of sound when players start speaking.
- Fixed pausing a Timer not freezing its clock.
- Fixed sounds, fonts and textures failing to load from files with non-ASCII names.
- Fixed other players possessing Characters causing the game to freeze while waiting levels streamed finish.
- Fixed the client Chat `PlayerSubmit` event passing a destroyed Entity instead of the local Player.
- Fixed `Text3D` render cull distance and shadow settings being ignored.
- Fixed a Character's View Mode being overwritten when set immediately after possession.
- Fixed a crash when opening a ZIP archive fails.
- Fixed local Map and GameMode being able to open it's modal on escape menu.

### 🌐 Account, Store & Website
- Added new feed channels on discord to announce community creations (new resources, teams, projects, versions, releases): https://discord.com/channels/124107916432113666/1567875276132716564 and one specifically for feedback/bugs reports: https://discord.com/channels/124107916432113666/1567874906719387721.
- Public profiles and contributor leaderboards now show completed ideas and bug reports, and the leaderboard can be sorted by contribution type.
- The bug report form now distinguishes between Scripting API and Web API reports.
- Fixed resource validator not reporting the validation error to the user, keeping stuck in "validating" forever.

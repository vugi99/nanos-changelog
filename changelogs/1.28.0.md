# nanos world - Version 1.28.0

- **Release Date:** 2023-01-11 13:34:08 UTC
- **Raw Timestamp:** `2023-01-11T13:34:08.000Z`

---

**New Features**
- **Experimental**: Now Vectors support double precision! I've implemented a new compressor for that, please let me know any bug or weird thing. Large World Coordinates goes brr.
- Added new method to **PostProcess**: `.SetExposure()`.
- Added new method to **Level**: `.GetStreamLevels()`.
- Added a new setting to Video Settings: `Shadow Map Method`.
- Added "missing" `Server.LoadPackage()` method.

**Improvements**
- Now the default camera will not have any overridden default Post Process setting.
- Now all damage and team parameters are internally treated as unsigned integer.
- Now Unreal Compatible version will show correct values even for non downloaded assets (will start working on the next Store update and after the Asset Packs get updated).
- Some events have been renamed in the classes: Client, Character, Weapon, Vehicle and WebUI (pay attention to the deprecated warnings).

**Bug Fixes**
- Fixed a crash when loading packages with errors.
- Fixed GaitMode triggering even if Character is not moving.
- Fixed "no item found" image in the Vault list while loading.
- Fixed error handling when something fails when starting a server (server will stop properly).
- Fixed WebUI not triggering "Fail" event anymore.
- Fixed Map packages being loaded even without Packages.

# nanos world - Version 1.170.1

- **Release Date:** 2026-11-11 11:35:00 UTC
- **Raw Timestamp:** `2026-11-11T11:35:00Z`

---

**Attention: the `public` branch has been updated to the version 1.170.0.**

### ⏫ Improvements
- Now **Vault downloads** are resumed when interrupted and starting downloading again.
- Improved the default **Motorboat** and **FishingBoat** meshes with a new Single Layer Water material fixing "water getting into" the boat.
- Improved buoyancy defaults for more stable floating, including automatic default damping calculation for heavier objects.
- The server now refreshes the assets sent to joining players based on assets used by active entities and assets explicitly precached, fixing all ever loaded assets always being sent, loaded and stored in memory during the whole server life.

### 🔨 Bug Fixes
- Fixed water forces being applied twice per frame and pontoons becoming misaligned when an object was rotated.
- Fixed a possession error when another system moved a possessed Pawn to a different dimension.
- Fixed dimension serialization for null entities in remote events.
- Fixed cable replication when network authority changes between parent and child actors. Causing connected actors to start getting chaotic when multiple players are near.
- Fixed the camera boom not updating when changing vehicle scale.
- Fixed a crash when a C module fails to load.
- Fixed the server console colors remaining changed after shutdown or a crash.

### 🌐 Account, Store & Website
- Fixed creating PAT (Personal Access Tokens) generic errors when selecting an expiring date in the past.
- Markdown editors (feedback, descriptions, etc.) now preserve line breaks.

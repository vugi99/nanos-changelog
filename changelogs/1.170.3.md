# nanos world - Version 1.170.3

- **Release Date:** 2026-11-13 11:45:00 UTC
- **Raw Timestamp:** `2026-11-13T11:45:00Z`

---

**Attention: the public branch has been updated to the version `1.170.1`.**

### 🆕 New Features
- Added new Debug settings: `Debug Character AI` and `Debug Vehicle` (merged from old `vehicle doors debug`): It shows Character's navmesh path, current segment, destination radius, velocity. And for Vehicles, it shows suspension, contact, forces and per-wheel labels.
- Water **Vehicles** now explode with effects, damage and burnt materials when destroyed.

### ⏫ Improvements
- [Debug.DrawString](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/debug#static-function-drawstring) now draws centered on their location (same for native network Debug texts).
- Reduced the size and complexity of some meshes and the size of some textures and sounds, reducing the game total size.
- Improved the efficiency and speed of WebUI images loaded through `assets://` and `package://`.
- Improved markdown rendering: rounded tables with alternating row colors that scroll sideways on mobile, code blocks with a language header and a copy button, and line numbers with ```lang showLineNumbers
### 🔨 Bug Fixes
- Fixed destroyed Vehicles popping hidden tires, reactivating wheels when resized and playing the tire sound on dimension change.
- Fixed damage flattening the tires of an already destroyed wheeled Vehicle.

### 🌐 Account, Store & Website
- Added the 3 latest changelog versions as a timeline below the news on the home page, and improved the [changelog](https://nanos-world.com/changelog) page layout into a timeline with the date on the side and colored headings.
- The new feedback post form now shows up to 5 similar posts while you type the title to help finding existing suggestions/bugs.
- Improved the Bug report template output, displaying the description first and unifying the context together after it.
- Improved markdown rendering for tables and codeblocks, also codeblocks show a language header and a copy button, and line numbers with "lang showLineNumbers".
- Fixed links to a section of the home page (like `/#subscribe`) flashing the hero before scrolling down.

# nanos world - Version 1.167.0

- **Release Date:** 2026-10-30 11:20:00 UTC
- **Raw Timestamp:** `2026-10-30T11:20:00Z`

---

It's Halloween time! 🎃👻

**Attention: the public branch has been updated to the this version as well.**

### 🆕 New Features
- Added new method [`Actor.ResetVelocity()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-resetvelocity) to Actor, allowing scripts to stop an Actor's velocity (deprecated `stops_velocity` parameter of [`StopMovement()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-stopmovement)).

### ⏫ Improvements
- Now chat messages are sent only to players in the same dimension (fixing bug of no name/avatar messages).
- Slightly increased the interaction detection radius.
- Improved anti-cheat movement recovery and action limits.
- Now the server list displays `?` when the player count value is unavailable.

### 🔨 Bug Fixes
- Fixed firing inputs being missed at low FPS (also fixed for other inputs as well).
- Fixed characters receiving duplicate damage.
- Fixed uninitialized damage information when a character dies through a script.

### 🌐 Account, Store & Website
- Added relative comparisons to statistics cards on resources and projects.
- Fixed an error when reordering or deleting screenshots after image processing.

# nanos world - Version 1.21.0

- **Release Date:** 2022-11-11 09:29:55 UTC
- **Raw Timestamp:** `2022-11-11T09:29:55.580Z`

---

**New Features**
- Added new method to World: SetPPLookupTable.
- Added new methods to Player: StartCameraFade, SetManualCameraFade, StopCameraFade
- Added new event to Actors and Player: DimensionChange.
- Added Kill Z which automatically destroys entities below very low heights (experimental).

**Improvements**
- JSON class methods are now native (faster).
- Now Player.ResetCamera will reset movements as well.

**Bug Fixes**
- Fixed Player.AttachCameraTo not resetting currently attach movement.

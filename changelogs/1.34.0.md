# nanos world - Version 1.34.0

- **Release Date:** 2023-02-08 15:10:08 UTC
- **Raw Timestamp:** `2023-02-08T15:10:08.000Z`

---

🆕 **New Features**
- The game has been updated to Unreal 5.1.1. I've found no problems so far and all seems to keep working with assets compiled  in 5.1.0. Anything weird let me know!
- Added a new class: **CharacterSimple**! A new lean and simple Character class which allows loading custom AnimBlueprints, load StaticMeshes as meshes, supports dynamic Capsule Sizes based on Mesh Size and can be possessed!

⏫ **Improvements**
- The Console Command system was refactored (now built-in commands uses the same system), please let me know any bug or problems!
- Updated WebUI constructor visibility parameter to use the new WebUIVisibility enum.
- Improved the Chat background input text color, making it more legible.

🔨 **Bug Fixes**
- Fixed a crash when loading invalid JSON with async File read.
- Fixed a bug causing potential random crashes with async operations.
- Fixed Character PlayAnimation SlotType invalid validation when using default value.

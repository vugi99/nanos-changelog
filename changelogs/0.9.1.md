# nanos world - Version 0.9.1

- **Release Date:** 2020-05-01 18:37:51 UTC
- **Raw Timestamp:** `2020-05-01T18:37:51.262Z`

---

**Improvements**
*  We refactored Render namespace, new functions: `AddLine`, `AddBox`, `AddPolygon`, `AddText`, `Project` and `ClearItems`. Removed Functions: `DrawLine`, `DrawText` and `DrawBox`. We removed `DrawHUD` event. Now all drawing method are called from anywhere and can be clean with `ClearItems` method.
*  We added option to switch the `Font` and it's `Size` (but currently we have only Roboto).
*  Added `Tick` global event (gonna be changed soon)

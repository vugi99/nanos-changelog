# nanos world - Version 1.105.0

- **Release Date:** 2026-01-29 15:30:19 UTC
- **Raw Timestamp:** `2026-01-29T15:30:19.613Z`

---

### 🆕 New Features
- Added new **Interaction ToolTips** to Props, Weapons (Pickables) and Vehicles. A new tooltip text + image will appear on screen when looking at the objects.
- Added a new method to disable the Interaction ToolTip: `Viewport.SetInteractionToolTipEnabled()`.

### ⏫ Improvements
- Improved the rendering CEF code, improving performance and efficiency.
- Now resetting scripting key bindings will be only possible in the main menu (for now).
- Updated CEF to version 144.

### 🔨 Bug Fixes
- Fixed a crash when resizing the game window due WebUIs (CEF) using Hardware Acceleration.
- Fixed clients not downloading all possible files at the same time, limiting the download speed.

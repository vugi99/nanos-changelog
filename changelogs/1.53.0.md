# nanos world - Version 1.53.0

- **Release Date:** 2023-05-18 11:04:42 UTC
- **Raw Timestamp:** `2023-05-18T11:04:42.569Z`

---

🆕 **New Features**
- Added new features to Vault Manage tab: Now its possible to upload newer versions to store from that tab! Also we added a new button to open the Package.toml/Assets.toml directly from that tab.
- Now it's possible to create Map Packages in a more interactive way through the Vault Menu! By pressing Create Package button you can select it's asset pack and choose which map from the dropdown list that this Map Package will use.

⏫ **Improvements**
- We reworked our underlying "localhost" connection system, which had several workarounds to make it possible to connect with p2p servers, even causing some problems of timeouts if the server had several asset packs to be loaded.
- Improved Create Package/Assets screen with better tooltips for each option.
- Slightly improved menu tabs opacity intensity.
- Improved Vault Return button location on the screen.
- Now Pickables will syncing location to the server if being handled.
- Updated to Steamworks v1.57.

🔨 **Bug Fixes**
- Fixed New Game not saving/restoring dedicated server setting.
- Fixed Offroad vehicle not flatting tires or changing the material properly when exploding.
- Attempt to fix a bug when setting Post Process getting an error of no Camera Component found.

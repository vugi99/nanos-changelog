# nanos world - Version 1.141.0

- **Release Date:** 2026-06-04 12:34:00 UTC
- **Raw Timestamp:** `2026-06-04T12:34:00.267Z`

---

### 🆕 New Features
- Added a new extensions whitelist for `File` class. Accessing any file other than the [allowed list](https://docs.nanos-world.com/docs/next/scripting-reference/classes/file#file-access--sandboxing) will throw an error.
- Added new buttons for **Reporting** a Vault resource and **Reporting** a Review.
- Now you can see the user **avatars** in the Vault reviews tab.

### ⏫ Improvements
- Reworked `SetDimension()` implementation. Now it's much more efficient for performance and networking. If you notice any bug, please let us know!
- Improved our **snapshots** sync implementation efficiency and performance.
- Added a new button to **Profile Popup** to open your profile page in the web.
- Updated CEF to `v148`.

### 🔨 Bug Fixes
- Fixed loading packages recursively (package A requires B and B requires A) causing the server to crash.
- Fixed a game crash when aborting connecting to a localhost server.
- Fixed more UIs due localization.
- Fixed saving e-mail on Profile popup not working.

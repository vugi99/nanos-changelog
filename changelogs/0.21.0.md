# nanos world - Version 0.21.0

- **Release Date:** 2020-05-30 10:44:18 UTC
- **Raw Timestamp:** `2020-05-30T10:44:18.077Z`

---

Hey yeah this is another step further on exposing all customization possible to nanos.world! This time we are starting to change our **Character**!

**New Features**
*  You can now spawn any kind of **Character Mesh**! With that, we are including in this patch a Woman Mesh and plus more 3 example meshes which can be used! Please refer to our docs on how to spawn them https://docs.nanos.world/scripting/classes/Character.
*  New Character functions: `Character:AddStaticMeshAttached()`, `Character:AddSkeletalMeshAttached()`, `Character:RemoveStaticMeshAttached()`, `Character:RemoveSkeletalMeshAttached()`. These functions are for spawning and attaching custom meshes (in a optimized way) into our Character, with that is possible to spawn and attach custom **clothes** (Skeletal Meshes) and custom **hairs** (Static Meshes) for example. Please refer to our docs to see examples of clothes and hairs available: them https://docs.nanos.world/scripting/classes/Character.

**Improvements**
*  We've improved the character's weapon handling animations, now it will swing when moving and will not feel frozen anymore when FPS. Also improved to fit all character meshes.

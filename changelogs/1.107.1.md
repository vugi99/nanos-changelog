# nanos world - Version 1.107.1

- **Release Date:** 2026-02-12 16:53:45 UTC
- **Raw Timestamp:** `2026-02-12T16:53:45.861Z`

---

### 🆕 New Features
- Added new methods to **Actor**: [`:SetAngularForce()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-setangularforce) and [`:GetAngularForce()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-getangularforce).
- Added new methods to **Cable**: [`:SetPhysicsConstraintSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setphysicsconstraintsettings), [`:SetLinearMotorPositionSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setlinearmotorpositionsettings), [`:SetLinearMotorVelocitySettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setlinearmotorvelocitysettings), [`:SetAngularMotorSLERPOrientationSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setangularmotorslerporientationsettings), [`:SetAngularMotorSLERPVelocitySettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setangularmotorslerpvelocitysettings), [`:SetAngularMotorTwistAndSwingOrientationSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setangularmotortwistandswingorientationsettings) and [`:SetAngularMotorTwistAndSwingVelocitySettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-setangularmotortwistandswingvelocitysettings).

### ⏫ Improvements
- Updated the game to Unreal `5.7.3`. It should not break any existing Asset Pack.
- Drastically improved the server and client performance by skipping entities from ticking, improving a lot when having thousands of entities spawned (that don't require ticking - i.e. StaticMesh). **Note: This was a big internal change, let us know if you experience anything weird.**
- Added Unreal Pre/Post Physics total timing to Profiling list.

### 🔨 Bug Fixes
- Fixed Walk Distance Stats (for achievements) updating when not walking/sprinting (also fixed for swimming).
- Fixed tracing against **SM_Plane** not working on one side.
- Fixed `Cable.Attach` overriding the network authority on other ends incorrectly.
- Fixed rare crashes when destroying actors from **Kill Z** or **Life Span**.
- Fixed the default game fonts not supporting extended ASCII characters ****correctly.

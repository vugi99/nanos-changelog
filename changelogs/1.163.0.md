# nanos world - Version 1.163.0

- **Release Date:** 2026-10-23 19:00:00 UTC
- **Raw Timestamp:** `2026-10-23T19:00:00Z`

---

### 🆕 New Features
- Added a new setting to disable the initial loading video.
- Added a new **Debug** setting to enable debug libraries on the client.
- Added a new **Steam Branch Selector** to switch from bleeding-edge or default when pressing the **News** balloon.

### ⏫ Improvements
- Now Vault downloads will retry once if it fails after a dropped connection or server error.
- Improved the compression of music assets.
- Improved several native meshes LODs and collisions.

### 🔨 Bug Fixes
- Fixed a CEF sound spike when audio started playing.
- Fixed media keys (play/pause) being forwarded to **WebUIs**.
- Fixed a crash when hiding the UI while some Widgets were invalid.
- Fixed a crash when loading raw base64 images.
- Fixed SkeletalMesh animations not stopping before playing again, which made them pile up between plays.
- Fixed a connection loop when sub-messages disconnected causing fatal errors and crashes.
- Fixed native Lua functions returning no value at all instead of nil when they had nothing to return on optional return methods.

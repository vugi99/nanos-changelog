# nanos world - Version 1.52.0

- **Release Date:** 2023-05-12 11:18:21 UTC
- **Raw Timestamp:** `2023-05-12T11:18:21.800Z`

---

🆕 **New Features**
- Now Blueprint parameters support `FSlateBrush` structure.
- Added a new method to **Particle**: `IsActive()`.
- Added new method to **Console**: `RunCommand()`.
- Added new **Vehicle** Health, Damage and Flatten Tire system and methods (see news blog for more information)!
- Now package reload/load/unload console commands support multiple packages passing separated by spaces!
- Now Asset Packs can have required Asset Packs defined in the Assets.toml!
- Added new parameters to **Paintable** methods (`index` and `attachable_id`), allowing to set Material and Material Parameters on specific Attachable Meshes!

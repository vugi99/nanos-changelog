# nanos world - Version 1.78.0

- **Release Date:** 2025-05-16 12:16:05 UTC
- **Raw Timestamp:** `2025-05-16T12:16:05.000Z`

---

Attention: This is a huge update that includes many structural changes and improvements. While it has been thoroughly tested before release, I appreciate everyone's help in reporting any issues you might encounter!

You can read more about this update in our [May News Blog](https://docs.nanos-world.com/blog/may-2025).


### 🆕 New Features
- Added a new parameter to `Cable.SetCableSettings`: `enable_stiffness`.
- Character events (`GaitModeChange`, `FallingModeChange`, `StanceModeChange`, `SwimmingModeChange`, `ViewModeChange`, `WeaponAimModeChange`) now trigger immediately on the client (if it's the causer) before syncing with the server.
- Enabled two new Plugins: **CommonUI** and **ModelView**.
- Now Spectating syncs crosshairs and on-screen blood.
- Character swimming now follows the camera angle for directional swimming.


### ⏫ Improvements
#### Cable System
- The Cable implementation was reworked, fixing all weird physics and rigid invisible forces. Now it works perfectly and is totally accurate with the visual representation.
- Improved cable error logs by displaying entity name/ID.
- Now picking up Pickables will detach any attached cable. Errors will be thrown if attempting to attach a cable to non-simulating objects (e.g. picked Pickables).
- Now when a Cable gets its Network Authority changed, all children in the chain will be updated to the same net authority, improving overall dynamic gameplay.
- Now `Cable.SetLinearLimits` must be called before any `AttachTo` methods.

#### Network & Authority
- Drastically improved netcode handling, significantly enriching the multiplayer experience, reducing input latency and making online gameplay more responsive, even over high ping connections.
- Reworked Physics Actors local interpolation, fixing jittering and introducing a new algorithm that uses ping to extrapolate location.
- Improved Network Authority system as a whole, fixed cases of snapshots being ignored due to a bug, causing desyncs for several seconds.
- Improved network debug drawing, now green colors will display if we are just 2 frames behind, yellow 4, orange 6 e red if more than it. Also added a Black arrow to display if a packet was refused.

#### Character & Ragdoll
- Improved ragdoll detection system: reduced allowed angle, increased speed to 500 to trigger ragdoll.
- Ragdoll will now apply impulse to the capsule if ragdoll-on-hit is not enabled.
- Now while Character is overlapping a Vehicle, it will be pushed away from it.
- Character will now find a suitable location to stand up from ragdoll.
- Improved ragdoll sync to prevent abrupt movements and rotations.
- Now only the locally controlled Character will have collision enabled with Vehicles, preventing some desyncs.
- Now roaming other NPCs with vehicles will make you the network authority of them automatically.

#### File Handling & Package System
- After each file download, the client now validates integrity to ensure successful, non-corrupted transfers.
- Package load, reload, and unload operations now are added to a queue to avoid conflicts, crashes, and weird client-side behavior.
- File Transfer errors now throw fatal errors for better debugging.
- Failed file downloads now report which files were pending or failed.

#### UI
- Improved Settings and Main Menu UI layout to adapt to higher range of display resolutions, fixing content overlapping and overflowing each other.
- Improved transition from loading screen to game, fixing UI flickers and rare crashes.

#### Gameplay
- **Experimental**: Improved Prop Grabbing using soft constraints and increased grab distance.
- Improved weapons cadence consistency to adapt to different frame-rates.
- Improved pontoon generation calculations for water physics.
- Reduced Vehicle light intensity.

#### System
- Now server crashes throw a custom fatal error and flush all pending logs, preventing (almost all) silent shutdowns.
- Now the internal `NanosWorld.exe` will be automatically added to the firewall when installing the game through steam.
- Now Unreal Actors are named with their Entity name and ID.


### 🔨 Bug Fixes
#### Cable
- Drastically mitigated multiple cables connected in chain causing insane physics issues.
- Fixed cables constraints breaking when resizing Vehicles or Weapons (physics was stopping working).

#### AI & MoveTo
- Fixed `MoveTo` duplicate "Completed" events, now each call has a unique ID.
- Fixed `MoveTo` not resuming movement if no players were connected.
- Fixed `MoveTo` not syncing state with clients, fixing `GetMovingTo` on client side.
- Added extensive logs to `AI.MoveTo` to assist with debugging.

#### Network & Authority
- Fixed `IsNetworkDistributed` always returning `false` for Props and StaticMeshes on clients.
- Fixed `IsNetworkAutoDistributed` not syncing with clients.
- Fixed firing/explosions not transferring network authority to the player that caused the damage.
- Fixed Actors not syncing sleeping mode.

#### Gameplay & Physics
- Fixed legs of other Characters not stopping TIP rotation.
- Fixed Character wrongly throwing grenades when releasing aim or after having the view unblocked.
- Fixed NPCs always going to the bottom of the ocean (now they will always swim up to the surface).
- Fixed Character Camera auto-centering flickering; improved overall camera behavior when in automatic mode.
- Fixed Character `SetRagdollMode` being able to be called while Character is dead (now will throw an error).
- Fixed Vehicle sound effects (brake/skid) not turning off after leaving the vehicle.
- Fixed Vehicle skid sound effect playing while vehicle is in air.
- Fixed CCD not working on small Weapons, causing them to fall through ground.
- Fixed Camera not resetting distance when Character falls directly into water.
- Fixed bullet decals not attaching to the head of `SK_Male`.

#### Scripting
- Fixed WebUI (CEF) not rendering the alpha channel properly, causing "halo" and some darker border effects on elements edges over a transparent background.
- Fixed 'multi Traces' returning empty arrays.
- Fixed map package `compatible_game_modes` being reset.
- Fixed client error: "Failed to find package to HotUnload".
- Fixed default maps not found on client after `package reload all`.
- Fixed CharacterSimple not setting `TargetArmLength` properly.
- Fixed Vehicle door colliders being detected in scripting trace checks.
- Fixed capsule trace debug drawing incorrect trace representation.

#### General
- Fixed 'Draw Debug on World' texts and drawings flickering, now they are drawn in the end of the frame fixing the jittering making them more readable.
- Fixed non-async logs overwriting console/log files from other threads, now they append correctly in order.
- Fixed max FPS resetting to infinite when toggling fullscreen setting.
- Fixed typo in Camera Side keybinding.
- Fixed Effects video setting not showing correct saved value.
- Fixed SM_Thruster Mesh without materials.

#### Crashes
- Fixed internal Lua crashes not displaying errors (was just abruptly closing the server).
- Fixed crash when loading C module packages without `--enable_unsafe_libs`, now throws proper error.
- Fixed sending recursive tables from Lua to JavaScript (CEF) causing stack overflows and crashes.
- Fixed deprecated `GetMaps` method causing crashes.

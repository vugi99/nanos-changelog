# nanos world - Version 1.170.0

- **Release Date:** 2026-11-09 17:20:00 UTC
- **Raw Timestamp:** `2026-11-09T17:20:00Z`

---

### 🆕 New Features
- Added client-side [`Assets.LoadAsync()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/assets#static-function-loadasync) and [`Assets.IsLoaded()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/assets#static-function-isloaded) to load assets asynchronously.
- Added Tracy profiling tools to `Debug`: [`ProfileZone()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/debug#static-function-profilezone), [`ProfilePlot()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/debug#static-function-profileplot), [`ProfileMessage()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/debug#static-function-profilemessage), and [`IsProfilerConnected()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/debug#static-function-isprofilerconnected).
- Added in-game reporting for player profiles.

### ⏫ Improvements
- Server image now supports Server.webp. Also local created resources now supports Package.webp and Assets.webp as well.
- Reworked and improved our internal async loading systems: now loading the same asset multiple times will not fire multiple async threads at the same time anymore (e.g. from Prop/StaticMesh loading).
- Improved client Tracy frame timing information.
- Converted most of built-in assets: character, prop, weapon, and vehicle meshes to Nanite.
- Improved shotgun performance by limiting impact effects based on effects graphics quality and reusing impact emitters. Impact and flyby sounds now play once per shot.
- Added a "skybox" background area to the Playground Map. Also improved it's overall performance and landscape complexity.

### 🔨 Bug Fixes
- Fixed the deleted binding button size in **Keybindings** settings.
- Fixed vehicle wheel physics size, suspension offset, and camera boom failing to update when the vehicle scale changes.
- Fixed a random crash related to rebuilding landscapes when saving video settings.

### 🌐 Account, Store & Website
- Fixed the website crashing when using Google Translator on the page.

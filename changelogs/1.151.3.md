# nanos world - Version 1.151.3

- **Release Date:** 2026-08-15 13:20:13 UTC
- **Raw Timestamp:** `2026-08-15T13:20:13.000Z`

---

### 🆕 New Features
- Added [`Server.IsUnsafeLibsEnabled()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-isunsafelibsenabled), which returns whether the server is running with unsafe Lua libraries enabled.

### ⏫ Improvements
- We are implementing several caching systems in the API, to speed up Vault and Store loading times. Note that some operations like updating a resource or your profile may take a few minutes to be completely pushed to everyone and to the main lists. Please let us know if something is weird!
- Updated **Sentry** to version 1.19.0.

### 🔨 Bug Fixes
- Fixed disabled tabs and a label showing on the wrong tab in the **Vault Resource Manage** screen.
- Fixed `File.GetDirectories()` and `File.GetFiles()` throwing odd errors when given an invalid path.
- Fixed playtest servers getting infinite loading on the find servers tab.

### 🌐 Account, Store & Website
- Added new automatic **Badges**, awarded as you complete your profile, review a resource, create teams, release resources and also anniversary ones!
- Added a **New Team** button directly on your profile page.
- Added an **Unreal version** warning on resource pages, so you can see whether an asset pack is incompatible with the latest Unreal Version.
- Now **Team** and **Resource** sorting takes total ratings and downloads into account.
- Improved the image uploader components, forcing aspect ratios and being standardized in all pages.
- Improved user search sorting.
- Improved navigation: standardized navbar buttons and colors, working middle-click on links.
- Now country flags are shown as circular icons.
- Fixed deleted versions still being returned for download.
- Fixed **Teams** not showing the owner role, and wrong resource counts on user and team pages.

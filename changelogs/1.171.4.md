# nanos world - Version 1.171.4

- **Release Date:** 2026-11-19 13:45:00 UTC
- **Raw Timestamp:** `2026-11-19T13:45:00Z`

---

`Attention: the public branch has been updated to the version 1.171.3.`

### ⏫ Improvements
- Runtime texture loading was internally refactored. It now limits concurrent imports, reuse requests for the same image and cancel pending imports when disconnecting. Potentially fixing Out of Memory crashes when too many images are loaded at the same time. Please let us know if you notice any issues with textures or images!

### 🔨 Bug Fixes
- Fixed texture loads applying to an entity after it was destroyed or its material parameter changed.

### 🌐 Account, Store & Website
- Personal Access Tokens now have selectable scopes, so each token can be limited to the actions it needs. They can be renamed and have their scopes edited. The token list also shows when each token was last used. They also now use a format recognizable by secret scanners. Existing tokens still work but will be deprecated in the future.
- Fixed removing a team's image from its management page.

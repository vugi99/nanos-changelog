# nanos world - Version 1.85.1

- **Release Date:** 2025-09-04 19:15:03 UTC
- **Raw Timestamp:** `2025-09-04T19:15:03.964Z`

### ⏫ Improvements
- Implemented a new internal **Server Favorite System**, replacing Steam's implementation (that wasn't working properly).
- Added more custom settings to Auto Detect feature (Blood, ShadowMap, AA Method).
- Improved the Video Settings Resolutions list, it will now only display compatible resolutions when Fullscreen and common resolutions when Windowed. Also added the Aspect Ratio to the list.
- Improved Profiling UI to color the time values individually.

### 🔨 Bug Fixes
- Fixed CharacterSimple not syncing acceleration.
- Fixed CharacterSimple SetCapsuleSize not applying when connecting after it was spawned.
- Fixed some issues when reloading Asset Packs during runtime.

# nanos world - Version 1.65.0

- **Release Date:** 2024-06-17 11:31:30 UTC
- **Raw Timestamp:** `2024-06-17T11:31:30.194Z`

---

This update includes a new Compatibility Version [1.55.0](https://docs.nanos.world/docs/next/core-concepts/packages/compatibility-versions#version-165) with changes to Events Unsubscribe methods.

🆕 **New Features**
- Added new parameters to [`Sky.SetMoonAngle(yaw, pitch)`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/sky#static-function-setmoonangle) and [`Sky.SetSunAngle(yaw, pitch)`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/sky#static-function-setsunangle).
- Added new method [`Sky.SetSunScale()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/sky#static-function-setsunscale) (deprecated Sky.SetSunRadius).
- Added new parameter to [`Sky.Spawn()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/sky#static-function-spawn): `find_existing`, to use already spawned UDS instance instead of respawning it.

⏫ **Improvements**
- Now Events.Unsubscribe will only unsubscribe from local events, use UnsubscribeRemote to unsubscribe from remote events (see Compatibility Version [1.55.0](https://docs.nanos.world/docs/next/core-concepts/packages/compatibility-versions#version-165)).
- Now the server will warn for bad unicode characters in assets names, telling the exact asset with bad characters (e.g. chinese or russian).
- Improved scripting error messages when passing wrong parameters to a function. It will now tell the wrong value passed itself as well.
- Now SceneCapture will render by default if not used by any Actor.
- Now Traces will be colored as green when success with debug enabled.
- Improved downloaded cached images to reuse images from memory more often.
- Updated Ultra Dynamic Sky to latest version (8.1).
- Updated CEF to latest version (125).

🔨 **Bug Fixes**
- Fixed missing method Viewport.GetViewportScale() which was not exposed.

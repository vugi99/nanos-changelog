# nanos world - Version 1.159.0

- **Release Date:** 2026-10-12 18:15:00 UTC
- **Raw Timestamp:** `2026-10-12T18:15:00Z`

---

### 🆕 New Features
- Added new events to Server and Client to listen when any package loads or unloads: [`PackageLoad`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#event-packageload) and [`PackageUnload`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#event-packageunload) (also on [Client](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#event-packageload)).

### ⏫ Improvements
- We did several improvements on the lua scripting safety: now clients only run script files exactly as the server sent them, refusing modified or modified versions at the loading time. Now Lua scripts can only be loaded as plain text, and most of the `debug` library is disabled for safety. See [Package Loading & Lua Environment](https://docs.nanos-world.com/docs/next/core-concepts/packages/package-loading-and-lua-environment) for the full list of restrictions.
- Improved and hardened our downloaded/cached scripting .lua files encryption on client side. Note that all existing cached files will be invalidated.
- Now entity custom data and server values are only compressed when it actually makes them smaller, saving bandwidth on small payloads.
- Removed the **Compression** setting from the server config: network compression now always uses the optimal defaults, reducing our codebase complexity and matching client and server values.
- Updated **CEF** to version 154.
- Updated **NVIDIA DLSS** (8.8.0), **AMD FSR** (4.1.1) and **AMD Anti-Lag** (2.0.5).
- Bumped several other internal dependencies.

### 🔨 Bug Fixes
- Now **VOIP** voice attenuation checks for obstacles using Camera collision instead of WorldStatic collision, fixing cases of muffled voices for local voip.
- Fixed player roles not being displayed correctly, and fixed profile descriptions not breaking lines on the **Profile** popup.
- Minor fixes, crashes prevention and vulnerabilities improvements.

### 🌐 Account, Store & Website
- Added a new  **Projects** and **Resources** dashboard section to show the daily `Views`, `Downloads` and `Favorites` as charts in the manage page!
- Added **Team Invites**: now adding someone to your Team has a new invitation process. Invited people can accept or deny the invites, and pending invites appear as notifications on your account page.
- Improved the crash report view, which now list more possible causes, including out of memory and corrupted assets.
- Several minor website improvements and bug fixes.

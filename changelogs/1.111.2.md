# nanos world - Version 1.111.2

- **Release Date:** 2026-03-07 10:05:34 UTC
- **Raw Timestamp:** `2026-03-07T10:05:34.000Z`

---

### ⏫ Improvements
- Now Loading a Package (with `Server.LoadPackage()`) will throw an error if other Packages are currently being unloaded.

### 🔨 Bug Fixes
- Fixed a client crash when calling `package reload all`, if the server failed to load packages dependencies but the client had them cached.
- Fixed clients re-downloading the same file every time if the files were just renamed to another casing on server side.
- Fixed Packages sending '.ignore' file or other ignored folders to clients wrongly.
- Fixed Profiling Entities & Events data usage not resetting after reconnecting to a server.
- Fixed a local server (started from menu) stopping if the host changes the map.
- Fixed Fatal errors when using VOIP just before being disconnected.
- Fixed a small memory leak on client when package reloading.
- Fixed Profiling UIs not displaying properly.

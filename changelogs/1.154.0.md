# nanos world - Version 1.154.0

- **Release Date:** 2026-09-03 17:09:19 UTC
- **Raw Timestamp:** `2026-09-03T17:09:19.332Z`

---

### ⏫ Improvements
- Updated **CEF** to latest version 151 build.

### 🔨 Bug Fixes
- Fixed lean **Asset Packs** not being sent to clients, leaving players unable to download them.
- Fixed the **My Profile** page not showing up-to-date data right after creating a team.
- Fixed some fonts not supporting emojis.

### 🌐 Account, Store & Website
- Added a new **Favorites** system: users can favorite store resources, the total favorites is shown on their public pages and listings.
- Personal Access Token (PAT) names can now be up to 100 characters (was 16).
- Improved the resource version uploader with clearer upload progress tracking.
- Team and user profile pages now show a proper empty message instead of blank cards when there is nothing to show.
- Improved mobile layout on most pages.
- Fixed uploaded resource images sometimes being stored with the wrong content type, which could prevent them from displaying correctly.
- Fixed creating a team with a duplicate name returning a raw database error instead of a clear message.

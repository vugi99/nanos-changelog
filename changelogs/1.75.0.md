# nanos world - Version 1.75.0

- **Release Date:** 2025-03-21 11:07:46 UTC
- **Raw Timestamp:** `2025-03-21T11:07:46.000Z`

---

### ⏫ Improvements
- Now Crashes will open an external process to display the crash popup (preventing several fatal errors internally).
- Greatly improved the in-game Console performance, it will not freeze the game when opening it anymore, even with thousands of logs entries!
- Improved the performance of some entities (Weapon, Character, CharacterSimple) on client side by disabling some other components and tick calls when not in use.
- Did some adjustments on WebUI (CEF) settings to attempt to fix the performance issues.
- Added Unreal Slate tick time to Profiling list.
- Now Input.Register, Bind and Unbind will display the scripting line when throwing warnings.
- Renamed our WebUIHelper.exe process to NanosWorldWebUIHelper.exe.
- Increased the threshold to display CEF Profiling warning performance logs to 1ms (was 0.2ms).
- Updated Steam SDK to 1.62.
- The default-testing-map was slightly changed, some trees were removed and adjusted to improve the map overall visibility and performance
- Now the default-testing-map fixed torches will turn on/off based on the time of the day.

### 🔨 Bug Fixes
- Fixed in-game changelog displaying some markdown characters (###).
- Fixed Blueprint calls throwing fatal errors when having blueprint errors.
- Fixed all CharacterSimple methods not being able to be called on client even if it was spawned on client.

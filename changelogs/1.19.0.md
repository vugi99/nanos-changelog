# nanos world - Version 1.19.0

- **Release Date:** 2022-10-15 08:53:15 UTC
- **Raw Timestamp:** `2022-10-15T08:53:15.000Z`

---

**New Features**
- Added new parameter to **Vehicle.SetAerodynamicsSetup**: `center_of_mass_override`.
- Added new parameter to Vehicle constructor: `custom_animation_blueprint`.
- Added new parameter to **Package.GetPersistentData**: `key`.
- Imported new default Vehicles (from Variety Pack and Offroad)!

**Improvements**
- Now **Client.SetDebugEnabled** disables bullet traces and doors as well.
- Now PersistentData files are located in a new folder `Packages/.data/`. Now they will preserve when updating/uninstalling packages.
- Now Vehicles support custom materials for turning lights ON/OFF when turning on, braking and going backwards!
- Updated CEF to latest version.

**Bug Fixes**
- Fixed attached actors not moving to other Dimensions with the parent. Also removed ability to auto move passengers when moving Vehicles through dimensions (it was causing many problems).
- Fixed Databases not closing connection when destroying.
- Fixed Vault update notification label not showing up.

# nanos world - Version 1.64.1

- **Release Date:** 2023-11-24 11:39:16 UTC
- **Raw Timestamp:** `2023-11-24T11:39:16.291Z`

🆕 **New Features**
- Now File class can read any file from Packages/ folder on client side (it has write access only to .transient/ folder, trying to write to other files will throw read-only error).

⏫ **Improvements**
- Reworked the password prompt workflow, now it will be requested after connecting to the server, also fixing following friends connected on passworded servers.

🔨 **Bug Fixes**
- Fixed compatible unreal versions list (added 5.3.2).
- Fixed files staying open in OS when reloading packages, breaking the server (not allowing them to access that file again) and client (breaking live reload).

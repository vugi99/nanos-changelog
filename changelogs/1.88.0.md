# nanos world - Version 1.88.0

- **Release Date:** 2025-09-29 13:40:33 UTC
- **Raw Timestamp:** `2025-09-29T13:40:33.376Z`

---

### 🆕 New Features
- Added **Kawaii Physics** Plugin.
- Added new method to **Character** and **CharacterSimple**: `SetPhysicsAsset()`.
- Added a new method to **Vector**: `IsNear` which efficiently checks if a vector is near other vector.
- Added the new free Fab **Adventures Characters** Pack natively.
- Added a new Anim Slot type on Character: **Head**. To apply animations only on head.

### ⏫ Improvements
- Now SetMorphTarget will also apply it to Attached Skeletal Meshes.
- Now Player VOIP event will trigger when actually starting and stopping speaking. Also it's more precise to stop transmitting only when the voice capture actually ends.
- Now Character Play/StopAnimation method can be called on both sides.

### 🔨 Bug Fixes
- Fixed Spectating not attaching the camera to the character's view point properly.
- Fixed Spectating teleporting the camera to a "random" location when stopping spectating.
- Fixed the spectating pawn still moving while spectating.
- Fixed runtime audio (.ogg) not loading properly, causing random loops and being inefficiently loaded.

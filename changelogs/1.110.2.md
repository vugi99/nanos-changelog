# nanos world - Version 1.110.2

- **Release Date:** 2026-02-27 15:54:40 UTC
- **Raw Timestamp:** `2026-02-27T15:54:40.585Z`

---

### 🆕 New Features
- Added a new parameter to [`NanosPawn.StopMovement(stop_velocity)`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-stopmovement), to also stop the Pawn's velocity.
- Added a new method [`Viewport::SetBrandingBarSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/viewport#static-function-setbrandingbarsettings) for customizing the "nanos world" bar on screen, now it's possible to set it's position and show less information.

### ⏫ Improvements
- Now the [Forge Plugin](https://docs.nanos-world.com/docs/next/assets-modding/forge/setup) latest version is included in the Steam's ADK entry.
- Improved the SM_Cube triangle complexity, enabled Nanite.

### 🔨 Bug Fixes
- Attempt to fix issues when reloading asset packs in runtime, causing players infinite reconnecting to a server.
- Fixed missing TraceMode.ReturnItem.

# nanos world - Version 1.94.8

- **Release Date:** 2025-10-30 22:24:39 UTC
- **Raw Timestamp:** `2025-10-30T22:24:39.399Z`

---

### ⏫ Improvements
- Increased Inherited Classes name size limit to 64 (was 20).
- Reduced the amount of flushes to logs on disk, improving logging performance (specially when logging Verbose and on Client).
- Improved the performance and fixed several issues when validating/caching/downloading files.
- Increased the max network buffer and send rate speed on clients, attempting to fix Fatal errors of "Limit Exceeded".

### 🔨 Bug Fixes
- Fixed Scripting internal logs not being outputted with the correct type (including fatal errors not reporting properly).
- Fixed destroying entities in events (i.e. PickUp or other events that are called on both Character and other Entity) causing crashes.
- Fixed a scripting crash when passing tables with entities as keys that were destroyed.
- Fixed Linux crashes becoming a nightmare, hanging the server forever.
- Fixed log files not being written exactly like the console logs.
- Fixed crashes when disconnecting while downloading files.
- Fixed crashes when opening main menu, console or chat when joining a server.
- Fixed avatars not being downloaded for players that connect after other players already joined.
- Attempt to fix Fatal errors related to WebUI when resizing the screen.

# nanos world - Version 1.170.2

- **Release Date:** 2026-11-12 13:43:00 UTC
- **Raw Timestamp:** `2026-11-12T13:43:00Z`

---

### ⏫ Improvements
- Refactored and redesigned the client console with selectable and copyable text, line wrapping, multi-color messages and ANSI color support.
- Now Vault and Escape Menu Text supports Markdown rendering, (changelogs, Game Jam, News too), with better rendering and formatting for links, tables and code. ([`Client.SetEscapeMenuText()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#static-function-setescapemenutext) using Rich Text will show a deprecation warning).
- Improved the performance of local file validation for large asset packs.
- Now [`Weapon.Reload()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/weapon#function-reload) returns if the request was made successfully.
- Now reconnecting, restarting or changing maps on a password-protected server keeps the password for the reconnect.
- Updated **FSR** to 4.1.2, **Anti-Lag** to 2.0.6, **DLSS** to 8.9.0 and **Sentry Unreal** to 1.126.0.
- Updated **libzip** to 1.12.1, **Sentry Native** to 0.16.8 and **zlib** to 1.4.

### 🔨 Bug Fixes
- Fixed the special grenade particle throwing loading errors when connecting to a server.
- Attempt to fix parked vehicles not waking when having the tire exploded.

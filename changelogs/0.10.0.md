- **Raw Timestamp:** `2020-05-02T13:46:52.917Z`

**New Features**
*  Added function `NanosWorld.GetLocalPlayer()` (client-side only)
*  Integrated Discord SDK to nanos.world! Which means scripters can set custom texts and (predefined custom) images to Discord Player's Status. `Client:SetDiscordActivity()` (client-side only)

**Improvements**
*  We went further on refactoring our core network system, doing more deep and complex changes, please notify us if you experience any server side crash or memory usage increasing abruptly

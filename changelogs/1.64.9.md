# nanos world - Version 1.64.9

- **Release Date:** 2024-01-08 10:38:37 UTC
- **Raw Timestamp:** `2024-01-08T10:38:37.026Z`

---

🆕 **New Features**
- Added a new console command: `password` to change the server password through console!
- Added a new method to WebUI on JavaScript side: `Events.Unsubscribe()`.

⏫ **Improvements**
- Updated several internal libraries dependencies.
- Removed password field from Quick Connect widget.
- Improved blueprint parameters to allow any Materials being passed as string path.
- Added a new label to display detailed download progress in the Vault Item Details screen.

🔨 **Bug Fixes**
- Fixed Package.toml not being generated properly if no one was found.
- Fixed AssetType enum broken.
- Fixed Character SetGravityEnabled resetting the gravity scale set beforehand.
- Fixed Profile Achievements tab stacking multiple times when clicking on achievements.

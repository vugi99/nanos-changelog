# nanos world - Version 0.16.0

- **Release Date:** 2020-05-20 19:23:00 UTC
- **Raw Timestamp:** `2020-05-20T19:23:00.778Z`

---

This is another **Breathtaking Update!** This time we reworked our Weapon's System to allow every kind of customization possible for scripters!

**New Features**
*  **New Weapon System** to allow tons of customization when creating Weapons within the scripting! Please refer to https://docs.nanos.world/scripting/classes/Weapon.html for how to Instantiate and Create new Weapons! This allows Scripters to Compose and Build a Weapon from scratch, choosing it's Meshes, Attachments, Sounds and how it behaves. **Attention Scripters**: This broke the old way of spawning Weapons, please refer to the docs and download our Default Weapons Scripting!
*  We've included also **two** new Weapons: **Desert Eagle** and **AR4**! Ready to use!
*  New Package function: `Package:RequirePackage()` to load and include another Package!

**Improvements**
*  Improved Bullet Blood Hole.
*  Now the camera when Parachuting/High Falling will be centralized.

**Bug Fixes**
*  Fixed a bug causing Crosshair keep red or disappearing some times.

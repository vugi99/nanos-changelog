# nanos world - Version 1.171.3

- **Release Date:** 2026-11-18 14:10:00 UTC
- **Raw Timestamp:** `2026-11-18T14:10:00Z`

---

### 🆕 New Features
- New **Tebex** integration and [Tebex](<https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/tebex>) Static Class! See our News post https://discord.com/channels/124107916432113666/385425494864035849/1572579397859549184.
- Added the `tebex_secret` option to the server's `Config.toml`.

### ⏫ Improvements
- Added missing Scroll Lock and Mouse Thumb key and button images on keybindings.
- Cyclic tables sent through the network now have the cyclic reference removed and produce a clearer warning. `JSON.stringify()` also reports cyclic tables with a clearer warning.

### 🔨 Bug Fixes
- Fixed memory corruption that could cause crashes when joining a server or exiting the game on NVIDIA cards with DLSS Frame Generation enabled.
- Fixed a table used more than once in a remote event or synced value arriving empty after its first occurrence.
- Fixed `TOML.Dump()` producing invalid TOML for tables containing nil values, cyclic references or empty arrays.

### 🌐 Account, Store & Website
- Feedback cards can now be opened in a new tab with the middle mouse button.
- Team recruitment positions now appear as individual cards.
- Fixed the support reply editor keeping its expanded height after sending a message.

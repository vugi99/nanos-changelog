# nanos world - Version 1.153.0

- **Release Date:** 2026-08-28 18:12:57 UTC
- **Raw Timestamp:** `2026-08-28T18:12:57.000Z`

---

### 🆕 New Features
- Implemented a new **heavily experimental** based-sync system, which aims to improve the sync of Characters (and all Pawns) when they are standing on a moving platform (i.e. on a moving Prop, StaticMesh or any other entity), their position now replicates relative to what they're standing on instead of desyncing as the base moves.

### 🔨 Bug Fixes
- Fixed losing network authority not cleaning up local states, causing debugging report it as desynced (red).
- Fixed loading screen being cached locally (if you still see the cached loading screen, you may need to clean up your WebUI local cache folder manually).
- Minor performance improvements and fixes.

### 🌐 Account, Store & Website
- Added a new image cropper to all image uploads, to help you fitting your image in the correct aspect ratios.
- Now any user can create teams and resources (not only testers anymore).
- Superseded package/asset versions are now deleted automatically instead of accumulating.
- Older uploaded versions are now marked as "obsolete" and internally cleaned up, freeing up storage space.
- Now deleting a resource version will also unpublish the resource if this was the only one version.
- Several layout adjusts, improvements and minor bug fixes. Please let us know if you see any issue or have suggestions!


#### Note: The Steam `default` branch was updated to the latest `1.152.2` version.

# nanos world - Version 1.138.4

- **Release Date:** 2026-05-18 14:10:47 UTC
- **Raw Timestamp:** `2026-05-18T14:10:47.625Z`

---

### 🆕 New Features
- New *experimental* AMD **FSR** integration! Now it's possible to enable FSR's **Frame Generation**, **Super Resolution** and **Anti Lag** natively.

### ⏫ Improvements
- Updated **DLSS Plugin** to `8.6` (Updated to **DLSS 4.5**, now supporting up to 6X frame gen).
- Improved the **Video Settings** to support separated Frame Gen and Super Resolution settings.
- Improved **Vault Markdown** parser, fixing newlines not being parsed, or showing incorrectly.
- Improved memory UIs texts.
- Improved CEF mouse inputs handling (will not handle back/forward as left anymore). Added Touch gesture implementation (for trackpads).
- Updated **Discord SDK** to `1.9`.

### 🔨 Bug Fixes
- Fixed local server not starting from menu.
- Fixed console not showing some log entries sometimes.

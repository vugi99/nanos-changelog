# nanos world - Version 1.60.0

- **Release Date:** 2023-09-01 12:31:46 UTC
- **Raw Timestamp:** `2023-09-01T12:31:46.000Z`

---

🆕 **New Features**
- Added new method: [**`Client.Disconnect()`**](https://docs.nanos.world/docs/next/scripting-reference/static-classes/client#static-function-disconnect).
- Added new method: [**`Viewport.GetViewportScale()`**](https://docs.nanos.world/docs/next/scripting-reference/static-classes/viewport#static-function-getviewportscale).
- Added new method [**`CharacterSimple.CallAnimationBlueprintEvent()`**](https://docs.nanos.world/docs/next/scripting-reference/classes/character-simple#function-callanimationblueprintevent).
- Added new parameter to [**`File.GetFiles()`**](https://docs.nanos.world/docs/next/scripting-reference/classes/file#static-function-getfiles) and [**`File.GetDirectories()`**](https://docs.nanos.world/docs/next/scripting-reference/classes/file#static-function-getdirectories): `max_depth`.
- Added new method: [**`Assets.GetAssetPath()`**](https://docs.nanos.world/docs/next/scripting-reference/static-classes/assets#static-function-getassetpath).
- Added new method [**`Character.GetVehicleSeat()`**](https://docs.nanos.world/docs/next/scripting-reference/classes/character#function-getvehicleseat).
- Added a new parameter to [**`Package.Require()`**](https://docs.nanos.world/docs/next/scripting-reference/static-classes/package#static-function-require): `force_load`.

⏫ **Improvements**
- Now `File` won't allow accessing the **Config.toml** file due security reasons (e.g. malicious packages attempting to steal the server token).
- The native `io` class is being deprecated due security reasons. All file access now must be made through the `File` class.

🔨 **Bug Fixes**
- Fixed New Game showing additional packages as 'none' (Issue [#957](https://github.com/nanos-world/issues/issues/957)).
- Fixed Package.Require not considering nil return values when caching loaded files.
- Fixed native require not working anymore (triggering errors) (Issue [#929](https://github.com/nanos-world/issues/issues/929)).

# nanos world - Version 1.11.0

- **Release Date:** 2022-07-14 10:08:57 UTC
- **Raw Timestamp:** `2022-07-14T10:08:57.566Z`

---

**New Features**
* Now Assets will also be auto downloaded when starting a server with auto_download parameter (+ when starting from main menu).
* Added new parameter to **Actor:AttachTo**: use_absolute_rotation, to ignore parent's rotation.
* Added new parameter to **Client.SetDiscordActivity**: reset_time, to optionally reset the elapsed time.
* Added new method: **Client.SetMousePosition**.
* Added a new Vault filter to display only outdated items.
* Added Updates tab to Vault item details.

**Improvements**
* Updated Unreal Engine to 5.0.3 (no compatibility problems found so far).
* Improved Find Servers layout (more space for server list), and now version mismatch servers are grayed out.

**Bug Fixes**
* Fixed Profile popup not disappearning when following a friend.
* Fixed IsInRagdollMode remaining true on client side after Character respawning.
* Fixed OnHighlight triggering an emerg error on client console.
* Attempt to fix NPCs not reloading weapons when not visible by the camera.
* Fixed other characters not firing straightwhen in ADS mode.
* Fixed clicking on WebUI stopping keyboard input.

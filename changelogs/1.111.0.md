# nanos world - Version 1.111.0

- **Release Date:** 2026-03-05 20:20:37 UTC
- **Raw Timestamp:** `2026-03-05T20:20:37.897Z`

---

### 🆕 New Features
- New Entity: [InstancedStaticMesh](https://docs.nanos-world.com/docs/next/scripting-reference/classes/instanced-static-mesh) (*officially*)!
- New **Asset Pack** format! Now it's possible to define multiple `unreal_folders` in a single asset pack, this way you can bundle all your assets packs into a single asset pack! Note that you must also update how the files/folders are copied into your Asset Pack! Please read the [docs](https://docs.nanos-world.com/docs/next/assets-modding/creating-assets/importing-assets#exporting--cooking-your-assets) for more information!

### ⏫ Improvements
- Added new Profiling settings to Main Menu: Now it's possible to profile only the Entities & Events Networking separately from the main Profiling. It's also possible to disable outputting the profiling results to logs - as it reduces performance.
- Deferred setting `lumen hardware ray tracing` setting, to attempt to fix a GPU crash during loading screen. Now it will only be set after completely connected to the server.

### 🔨 Bug Fixes
- Fixed Asset Packs hot-reloading "mounting" errors.
- Fixed reserved Asset Packs folder names being loaded by the Main Menu, causing mess.
- Fixed a rare crash when executing `restart` if the server had Asset Packs loaded.
- Fixed Main Menu Package Creator map list duplicating entries.
- Attempt to fix a crash when running async operations just after executing `package reload all`.

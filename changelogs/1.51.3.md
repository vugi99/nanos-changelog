# nanos world - Version 1.51.3

- **Release Date:** 2023-05-01 12:49:37 UTC
- **Raw Timestamp:** `2023-05-01T12:49:37.322Z`

🔨 **Bug Fixes**
- Fixed changing Dimensions not triggering Spawn event on client side.
- Fixed Trigger not triggering End Overlap events when an overlapping entity changes dimension.
- Fixed a client crash when changing dimension of an entity twice in the same tick.
- Fixed error "moving temp folder..." when having multiple connected clients while reloading packages.
- Fixed a crash when using Player Camera Fade methods just before disconnecting.
- Fixed Blueprints parsing wrong structs names when passing structs as blueprints parameters.
- Fixed Blueprints requiring all parameters being passed when parsing an Unreal Struct (now all properties are optional).

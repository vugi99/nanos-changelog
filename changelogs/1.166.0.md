# nanos world - Version 1.166.0

- **Release Date:** 2026-10-26 14:10:00 UTC
- **Raw Timestamp:** `2026-10-26T14:10:00Z`

---

**Attention: the default branch has been updated to this version as well.**

### 🆕 New Features
- New [**Playground**](https://nanos-world.com/store/packages/default-playground-map) map! A big open sandbox playground to try everything nanos world has, explore entities, physics, tools and easter eggs, made for messing around and learning all nanos world capabilities.
- New meshes for **PhysicsGun**, **ToolGun** & **PukeGun** made from scratch!
- Added new method to Prop: [`SetOneWayInteraction()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/prop#function-setonewayinteraction).
- Added a new set of default **Surface Materials** (Wood Planks, Wood Floor, Wood Dark, Wood Siding, Brick, Concrete, Concrete Tiles, Stone, Marble, Gravel, Dirt, Roof Tiles, Metal Painted, Metal Dark, Metal Corrugated, Wallpaper, Plastic, Rubber, Chrome, Gold, Copper, Neon and more) and a new `M_Default_Opaque_Lit_Triplanar` material.
- Added new native  meshes for Pumpkins, Skeletal Character, Animals, Lamps, CCTV Cameras, Photo Frames, Chairs, Instant Camera, added new native Sounds and Musics. See the full list in [Default Assets List](https://docs.nanos-world.com/docs/next/assets-modding/default-asset-pack/default-assets-list).

### ⏫ Improvements
- Improved some materials missing the "Tint" parameter.

### 🔨 Bug Fixes
- Fixed the **Wireframe** default material not supporting Skeletal Meshes.
- Fixed `AttachTo()` with `AttachmentRule.KeepWorld` / `KeepRelative` not working properly on client-side actors.
- Fixed a crash when leaving a server while inside a **Vehicle**.
- Fixed **Billboard** size having width and height swapped (now X = width and Y = height).
- Fixed the Linux dedicated server hanging on exit after `stop` when running inside containers (Docker/Pterodactyl). It now exits with code `0`.
- Fixed a negative ID showing on the debug world.

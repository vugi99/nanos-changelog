# nanos world - Version 1.172.0

- **Release Date:** 2026-11-22 12:30:00 UTC
- **Raw Timestamp:** `2026-11-22T12:30:00Z`

---

**Attention: the public branch has been updated to the version `1.171.4`.**

### 🆕 New Features
- Added filters to the **Console**, allowing log messages to be shown or hidden by categories.
- Added [`Server.HoldConnection()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-holdconnection), [`Server.ReleaseConnection()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-releaseconnection) and [`Server.GetHeldConnections()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-getheldconnections) to support queues, reserved slots and asynchronous player verification. It keeps the player in the loading screen with a custom waiting message and shows the time elapsed. We also added the `max_held_connections` server setting to allow players to wait for a slot when the server is full.
- Added [`Server.KickBySteamID()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-kickbysteamid) and [`Server.BanBySteamID()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-banbysteamid) to kick or ban players by Steam ID (deprecated `Server.KickByAccountID()` and `Server.BanByAccountID()` since they are not verified by the server).
- Added `ban` and `unban` server console commands using Steam IDs. Offline players can also be banned.
- New `Bans.toml` file to store all bans, moved from the `banned_ids` from Config.toml. `Bans.toml` now stores the player's name, reason and date it happened.

### ⏫ Improvements
- Now using `package reloading all`, restart and map changes make the packages to unload in the reverse order as they were loaded.
- Updated mouse look so sensitivity remains consistent across the configured field of view and slows down when zooming. Mouse look may feel slower than before at higher field of view settings.
- Improved the mouse sensitivity slider with more precise values and Shift + mouse wheel fine tuning.
- Removed the last update **Mouse Smoothing** setting, which did not affect mouse look.
- The [`PlayerConnect`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#event-playerconnect) event now fires after Steam authentication.
- The server console `kick` command now takes a Steam ID, and `players` displays each player's Steam ID.
- Added new `loading_stage_name` to the CEF loading screen's `UpdateScreen` event.

### 🔨 Bug Fixes
- Fixed a crash when clicking or typing inside cross-site iframes in a WebUI.
- Fixed a crash when a client-side **CharacterSimple** was destroyed by its Life Span or Kill Z.
- Fixed client-side pawns' Life Span counting down twice as fast.
- Fixed duplicated "Kicked:" text when using a server console command.
- Fixed a crash when calling the deprecated `Super` method incorrectly. It now raises a Lua error instead.
- Fixed `string.FormatArgs()` failing when an argument contains `%`.
- Fixed log messages containing line breaks or control characters being able to impersonate other log lines.

### 🌐 Account, Store & Website
- Updated our notification and transactional emails with a new layout design.
- Now the Discord bot sends tester instructions when it grants the **Tester** role.
- Improved explanations of player access, community whitelists, and playtest and beta keys.

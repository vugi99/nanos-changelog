# nanos world - Version 1.16.2

- **Release Date:** 2022-09-14 09:44:34 UTC
- **Raw Timestamp:** `2022-09-14T09:44:34.868Z`

---

**Improvements**
- We implemented a new Scripting Entity Constructor system. Initially this shouldn't change anything, please let us know if you are having any weirdness happening (or default parameters different).
- Now Databases return the error as a second parameter in the callbacks/return values.
- Now Weapon hand/aim offsets are updated immediately if changed while a Character holds it.
- Now Blueprint Call and Dispatchers support passing Entities and Actors through!
- Removed NanosWorld deprecated StaticClass.
- Removed deprecated Paintable:SetDefaultMaterial and TextRender:SetColor methods.

**Bug Fixes**
- Fixed Character not being able to prone/unprone.
- Fixed WebUI window.close() crashing the game.
- Fixed Blueprint Dispatcher crashing the game if having a Lua error in the callback.

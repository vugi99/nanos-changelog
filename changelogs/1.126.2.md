# nanos world - Version 1.126.2

- **Release Date:** 2026-04-09 17:06:05 UTC
- **Raw Timestamp:** `2026-04-09T17:06:05.001Z`

---

### ⏫ Improvements
- Updated the **Steam SDK** to the latest 1.64 version.
- Improved our **server messages polling**, and a warning will be thrown there are too many messages in the queue to be processed if the server is not processing them in time.
- Now **VOIP** is transmitted as **unreliable messages**, improving the server performance and reducing networking lag. Note that bad connections may experience voice cut or packets being dropped.
- Player `VOIP` events were reworked internally, now the `is_talking = false` will be always triggered after 0.5 seconds of not receiving any VOIP data.
- The **Blank Map** Landscape was swapped with a SM_Plane. Also Nav Mesh is now built together.

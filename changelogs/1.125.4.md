# nanos world - Version 1.125.4

- **Release Date:** 2026-04-08 21:28:19 UTC
- **Raw Timestamp:** `2026-04-08T21:28:19.980Z`

---

### ⏫ Improvements
- Enabled "Update Only If Rendered" for all Character/CharacterSimple that are not network authority.
- Now actors will be teleported to the correct received location if they are too far due any desync.
- Now Players will not be kicked when Steam is down (or due Tuesday's maintenance).
- Improved client responsiveness and reduced stutters by fetching network messages or callbacks on every frame now.
- Reduced all network packets footprint size and also reduced Actors snapshot syncing networking usage.

### 🔨 Bug Fixes
- Fixed a client-side crash when destroying actors.
- Fixed actors staying desynced for several seconds when they were "sleeping" if they were too far.

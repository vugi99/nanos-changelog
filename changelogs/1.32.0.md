# nanos world - Version 1.32.0

- **Release Date:** 2023-01-27 19:09:59 UTC
- **Raw Timestamp:** `2023-01-27T19:09:59.035Z`

---

🆕 **New Features**
- Now we have a new organized format for **Config.toml** file! Most of the command line settings can now be defined there as well!
- Now **Sky** supports Ultra Dynamic Sky Landscape Weather Effects. We enabled it on TestingMap and BlankMap landscapes (now they get covered by snow/puddles!).
- Added new method to **Player**: `GetCameraArmLength()`.

⏫ **Improvements**
- Now **WebUI:SetVisibility()** receives a `WebUIVisibility` enum as parameter which allows making a WebUI visible but not hit testable - will not capture input (no breaking changes).
- We've got a big rework internally on the memory of entities. Which will improve a lot the performance of their serialization. Let's keep an eye on for problems related to desync when connecting to servers.

🔨 **Bug Fixes**
- Fixed Network Authority not resetting when not distributed (e.g. when Players disconnect after using a Physics Gun).
- Fixed Player.GetAccountIconURL not working properly for local player.
- Fixed Cables not applying correct positions when any attached end is scaled.
- Fixed Input.GetKeyCode returning invalid values for keys with less than 2 characters.
- Fixed a Crash when using the deprecated World.SpawnDefaultSun() method.

### ⏫ Improvements
- Added **Entities Spawning** information to Profiling list.
- Added **Scripting Events** network usage to Network Debug on Screen.

### 🔨 Bug Fixes
- Fixed loading local textures (e.g. from `package://`) not caching and exponentially increasing memory usage (now changing an image during runtime - and keeping the same path - will require reconnecting to take effect).
- Fixed the server sending pending deleting entities to clients when switching dimensions, causing entities to do not be destroyed on clients and unforeseen bugs and crashes.
- Fixed the crashes from last update.
- Fixed reloading packages that inherit entities not reapplying the table passed to Entity.Inherit, causing random errors.
- Fixed WebUIs being able to zoom-in and out with CTRL + Mouse Wheel.

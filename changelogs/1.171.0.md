# nanos world - Version 1.171.0

- **Release Date:** 2026-11-15 12:05:00 UTC
- **Raw Timestamp:** `2026-11-15T12:05:00Z`

---

**Attention: the public branch has been updated to the version `1.170.3`.**

### 🆕 New Features
- Added [`Player:GetVOIPAmplitude()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-getvoipamplitude) to get the amplitude of a player's voice.
- Added methods to customize proximity VOIP: [`SetVOIPLocalHighPassFilter()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-setvoiplocalhighpassfilter), [`SetVOIPLocalLowPassFilter()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-setvoiplocallowpassfilter), [`SetVOIPLocalOcclusion()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-setvoiplocalocclusion) and [`SetVOIPLocalAttenuation()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-setvoiplocalattenuation).
- Added [`Sound:SetAttenuationShape()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/sound#function-setattenuationshape) and [`Sound:SetOcclusion()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/sound#function-setocclusion).
- Added new debug options for Weapons, Melees, Sounds, Lights, Cables, Players, Decals, Grenades and Buoyancy.
- Added a new **Camera Shake** setting to adjust camera shake intensity. Also added Camera Shake effects to explosions and vehicle impacts. And improved other effects.
- Added the `--vault_full_assets` and `--vault_download` command-line options. The `--auto_download` and `--use_vault_assets_lean` options are deprecated.

### ⏫ Improvements
- Improved VOIP audio processing and reduced stuttering when opening the microphone.
- Now pressing `Ctrl+C` cancels an ongoing server or command-line **Vault** download, preserving the partial download so it can resume later.
- Now character impacts use the hit body's physical material for effects and sounds, and only produce blood when the material is PM_Flesh (fixed Skeleton spitting blood).
- Improved performance for static objects in water by avoiding unnecessary buoyancy calculations.

### 🔨 Bug Fixes
- Fixed several Blueprint parameter issues, potentially overwriting neighboring values, causing bugs, memory leaks and crashes.
- Fixed distant physics objects falling and snapping back between network updates.
- Fixed Grenade and Melee buoyancy not updating pontoons when scaled.
- Fixed `Sound:Is2D()` returning an incorrect result.

### 🌐 Account, Store & Website
- Improved the appearance of Markdown tables and code blocks, including a copy button and better handling on narrow screens.
- Improved asset upload validation, including reporting the size limit before an oversized upload starts.
- Fixed asset version uploads failing when the validator queue was temporarily unavailable.

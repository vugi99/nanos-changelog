# nanos world - Version 1.7.2

- **Release Date:** 2022-05-01 14:30:26 UTC
- **Raw Timestamp:** `2022-05-01T14:30:26.138Z`

---

**New Features**
* Added new Character methods: `SetHighFallingTime()` and `SetPhysicalAnimationSettings()`.
* Added Color:ToHEX() method.

**Improvements**
* Added sandbox as compatible game-modes for default maps.
* New Game will disable incompatible maps (wrong unreal version) to be loaded.
* Improved Vehicle buoyancy.

**Bug Fixes**
* Fixed TakeDamage event not validating death or destroy after it's called.
* Fixed Prone animation speed.
* Fixed console errors when loading invalid/non-existing maps images.
* Fixed spawning Props while colliding not finding a better location.
* Fixed leaving vehicles with wrong capsule size.
* Fixed vehicles taillights flickering.
* Fixed Input.Unregister crash.
* Fixed performance on footstep particles (reimported new version).

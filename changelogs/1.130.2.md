# nanos world - Version 1.130.2

- **Raw Timestamp:** `2026-04-14T11:28:45.845Z`

### 🆕 New Features
- Added a new enum `SoundType.Ambient`, and a new **Ambient Audio Setting** for changing it. Ultra Dynamic Sky sounds can be adjusted with that setting.

### ⏫ Improvements
- Added profiling (--profiling) to several parts of the code. Now calling API functions will be profiled, and much more.

### 🔨 Bug Fixes
- Fixed some internal vulnerabilities.
- Fixed vault resources versions not comparing correctly when Major was changed.
- Fixed VOIP input not being released when Mouse was enabled through scripting.

# nanos world - Version 1.172.1

- **Release Date:** 2026-11-25 13:00:00 UTC
- **Raw Timestamp:** `2026-11-25T13:00:00Z`

---

**Attention: the public branch has been updated to the version `1.172.0`.**

### 🆕 New Features
- Added [`Server.IsBanned()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-isbanned) and [`Server.GetBans()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-getbans) to check and list server bans from scripts.

### ⏫ Improvements
- Now the [File](https://docs.nanos-world.com/docs/next/scripting-reference/classes/file) library can access any path and file extension when the server starts with `--enable_unsafe_libs`. The startup warning also lists what the flag enables.
- The server's `clear` command now clears the terminal's scrollback as well as the visible screen.

### 🔨 Bug Fixes
- Fixed built-in **Vault** items requesting an outdated nanos world team icon on startup.
- Fixed team descriptions rejecting plain text containing a `<` followed by a letter.

### 🌐 Account, Store & Website
- Added badge levels and consolidated the nine [**Veteran**](https://nanos-world.com/community/badges/c9e0a1b6-f162-40f0-bb18-6d38dcf2daaf) badges into one badge with nine levels. Existing holders keep their tier and award dates.
- Added six levels each for [**Feedbacker**](https://nanos-world.com/community/badges/5cd8c073-e269-462c-833a-d273a3437397), [**Bug Reporter**](https://nanos-world.com/community/badges/500c0b12-5aad-4f51-abe9-cca7eda80b2c) and [**Reviewer**](https://nanos-world.com/community/badges/c82ac590-d80e-42ef-a2d1-f4623829ae5a). Completed ideas and bugs, and helpful reviews advance their respective badges.
- Everyone can now vote on whether **Vault** reviews are helpful and sort by most helpful.
- Resource creators can now reply to reviews.

### 📚 Documentation
- API reference pages can now be fully translated: labels such as authority, efficiency, basic types, tables and enums are now sent for translation on Crowdin.

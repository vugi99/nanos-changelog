# nanos world - Version 1.117.1

- **Release Date:** 2026-03-23 09:30:37 UTC
- **Raw Timestamp:** `2026-03-23T09:30:37.249Z`

---

### 🆕 New Features
- Added **Server List** to **Escape Menu**! Now you can browse and connect to other servers while being connected to a server!
- Added **Ping** information to the **Players list** on Escape Menu.

### ⏫ Improvements
- Now **Vault Resources** **Description** and **Changelog** supports simplified Markdown notations (`**`, `*`, `#`, `##`, `###`, `####`).
- New **Teams Members Roles**: `admin` (can edit Team information), `maintainer` (can edit Resource Information), `developer` (can push Resource versions) and `member` (Read-only). You can manage your team members in the Teams manage tab, in the main menu!
- Now connecting with `+connect` will resolve **DNS** IP as well.
- We reworked most of the connection/re-connection workflow. If you notice any bug or unexpected behavior, please let us know!

### 🔨 Bug Fixes
- Fixed crash when client gets disconnected due connection problems.

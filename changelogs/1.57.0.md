# nanos world - Version 1.57.0

- **Release Date:** 2023-07-16 21:02:33 UTC
- **Raw Timestamp:** `2023-07-16T21:02:33.041Z`

---

🆕 **New Features**
- Added new class: [VehicleWater](https://docs.nanos.world/blog/june-2023#new-class-vehiclewater)!

⏫ **Improvements**
- The **Vehicle** class was renamed to [VehicleWheeled](https://docs.nanos.world/blog/june-2023#renamed-vehicle-class).
- Added new parameter to **AddStaticMeshAttached** and **AddSkeletalMeshAttached** methods: `use_parent_bounds`, to use its parents bounds when attached (See the latest [news blog](https://docs.nanos.world/blog/june-2023#attached-mesh-bounds)).

🔨 **Bug Fixes**
- Fixed Player Spawn event triggering multiple times on client.
- Fixed CharacterSimple flickering if using Static Mesh.
- Fixed parameters from WebUI (CEF JavaScript) not converting arrays properly.
- Fixed GetAllStaticMeshAttached returning the SkeletalMeshes instead.

# nanos world - Version 1.76.1

- **Release Date:** 2025-04-19 18:17:05 UTC
- **Raw Timestamp:** `2025-04-19T18:17:05.817Z`

---

### ⏫ Improvements
- Added a new main menu theme for Easter Holiday 🐰.
- Added a "Show Server Log" button to Error PopUp when failed to launch a local server.
- Now Modules package type differs loading Windows and Linux libraries. Linux libraries must be compiled and copied as lib[MODULE_NAME].so, and Windows libraries as [MODULE_NAME].dll to the Package's root folder.
- Renamed Modules Package.toml setting from "binaries" to "modules", the file will update automatically.
- Updated CEF and some other internal dependencies.

### 🔨 Bug Fixes
- Fixed crash when Spawning Sky without weather.
- Fixed client console not opening the Log File when pressing the button for it.
- Fixed Error Popup sometimes not showing up when failed to connect to a server.
- Fixed Sound entity not auto destroying automatically.
- Fixed Billboard, Cable, Decal, Light, Particle, Pickables, Sounds and Trigger not executing Translate/RotateTo and also not appearing in the World Network Debug.
- Fixed a CEF fatal error when attempting to paint a Popup.
- Fixed vehicle counting Distance Driving achievement even if it was falling.

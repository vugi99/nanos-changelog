# nanos world - Version 1.45.5

- **Release Date:** 2023-03-31 12:21:06 UTC
- **Raw Timestamp:** `2023-03-31T12:21:06.702Z`

---

**⏫ Improvements**
- Now Vault Items display a rotating "reloading" image while loading the images.
- Reduced the hardcoded error time when the server fails to load from 2s to 500ms.
- Improved multiple API calls to Store when installing several packages at once when starting a server with --auto_download or from New Game, which will speed up a lot the installation.

**🔨 Bug Fixes**
- Fixed clients not storing the assets and packages files cache information, having to recalculate everything every time they join a server.
- Fixed 0 bytes files not uncompressing on HTTP File Transfer causing client errors.
- Fixed you being able to hear yourself when speaking on VOIP.
- Fixed Images cache using negative number as file names.
- Fixed a crash when Image Downloader fails to load an image with empty URL.
- Fixed a crash when pressing ESC on loading screen while being redirected/changing the map.
- Fixed local host servers not fetching server progress if it uses other port than the default 7777.
- Fixed "infinite loading" in the loading screen if the in-game server fails to open.

# nanos world - Version 1.54.0

- **Release Date:** 2023-05-29 10:35:40 UTC
- **Raw Timestamp:** `2023-05-29T10:35:40.771Z`

---

This update includes a new Compatibility Version [`1.54.0`](https://docs.nanos.world/docs/next/core-concepts/packages/compatibility-versions#version-154) with changes to `Client` and `Level` classes.

🆕 **New Features**
- Now [Blueprint Parameters](https://docs.nanos.world/docs/next/scripting-reference/classes/blueprint#list-of-supported-parameter-types) support `UFont` as SpecialPath, `UClass` from strings and new struct `FSlateBrush`.
- Added new method to Pickables, Characters, and Vehicles: [`SetStaticMeshAttachedTransform()`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pickable#function-setstaticmeshattachedtransform), allowing to change attached static meshes relative location/rotation at runtime!

⏫ **Improvements**
- Now [`Client.GetPackages()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/client#static-function-getpackages) behaves like Server.GetPackages(), having a new parameter for filter and returning a list of package information instead of just names (see new compatibility version).
- Now [`Level.CallLevelBlueprintEvent()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/level#static-function-calllevelblueprintevent) behaves like Blueprint.CallBlueprintEvent(), being able to pass parameters in a variadic way and receiving the return of that function (see new compatibility version).

🔨 **Bug Fixes**
- Fixed Widget Native ComboBox not spawning the correct class.
- Fixed Blueprints parameters not being able to parse some objects.
- Fixed Vault Manage tab not refreshing after uploading a new version from menu.

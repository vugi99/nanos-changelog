# nanos world - Version 1.97.1

- **Release Date:** 2025-11-15 21:59:42 UTC
- **Raw Timestamp:** `2025-11-15T21:59:42.943Z`

---

### 🆕 New Features
- The **File Transfer System** has been completely reworked to be far more robust and stable using the inline networking sockets system. A new fair scheduling algorithm keeps track of all connected clients in a queue and distributes the files uniformly between them, ensuring everyone receives data evenly (fixing cases where some players were stuck at 0 B/s). Now it can transmit files of any size (the old 256 MB limit has been removed). If this new system proves solid, HTTP transfers may be fully deprecated in favor of the new approach. Please help us testing it and let us know any bug!
- Added a new setting: **Display Entities Network Stats** - to enable displaying separately General Network Stats (old setting) and only the Entities Network Stats.

### ⏫ Improvements
- **Avoidance** now automatically disables when **Character** or **CharacterSimple** enters ragdoll mode. For **CharacterSimple**, it is also disabled when using any collision mode other than Normal (as it's for Characters).
- **P2P Servers** will have the `max_send_rate` forced back to 1 MB/s, due Steam Relay service limitations. This prevents heavy packet loss during file transfers. Also the config is now limited to the range 1-32 MB/s.
- Disabled Inheritance from **Database** and **File** entities, as they aren't designed to be inherited.
- The internal forced **networking flushes** have been removed, as they caused significant hitches and freezes on the main thread.

### 🔨 Bug Fixes
- Fixed loading screen not cleaning up when reconnecting.
- Fixed some avatar images not loading in chat.
- Fixed an issue when aborting downloads on the client causing fatal errors and crashes.

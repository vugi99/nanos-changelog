# nanos world - Version 0.7.0

- **Release Date:** 2020-04-29 23:11:31 UTC
- **Raw Timestamp:** `2020-04-29T23:11:31.744Z`

---

**Le Incredible and Big Update**

We are happy to announce this release with two new main features: **File Transfer** and **Client-Side Scripting**!

**New Features**
*  **Client Side Scripting!** Now it is possible to develop scripts on client side! Please refer to our https://docs.nanos.world for the new Classes supported. (It is in a very early stage and we will add more features as it goes ;))
*  **File Transfer system** - thanks to the File Transfer system we could enable Client Side Scripting, all Scripts in `Client/` and `Shared/` folder will be sent and will run on the clients.
*  **HotReload** - Yeah! We implemented a HotReload system for reloading the scripts during runtime, just call `package reload [x]` and the client will download the new package version and rerun them as well :D. (Remember to clean up your package on OnUnload event ;))
*  **Client Console!** - Now we have a very pretty Client console which can be opened with `Backslash` key. Yes it is a weird key, soon it will be changed. This console will output all errors and logs which may be useful for scripters and for us ;).

**New Scripting Features**
*  New Package function: `Package:Log("bla bla")` for logging the proper way, do not use print anymore ;). This is the only possible way to print on Client Console.
*  New Classes: *World*, *Render* and *Vector2D*. Please refer to https://docs.nanos.world for information and functions available.
*  Render class features Drawing on the screen. Please note it's in a very early stage, so it will crash and cause lag. Also we haven't finished to expose all possible functions.

**Improvements**
*  We did a lot of internal code improvements which will generate theoretical performance gains
*  We are starting to log some network errors, so if you experience some "Error sending message" error, it's not your fault (it's ours :P).

**Bug Fixes**
*  Fixed number of arguments of Character constructor
*  Fixed some other bugs which were causing some linux crashes

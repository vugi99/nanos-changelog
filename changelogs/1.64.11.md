# nanos world - Version 1.64.11

- **Release Date:** 2024-02-29 10:53:10 UTC
- **Raw Timestamp:** `2024-02-29T10:53:10.460Z`

---

🆕 **New Features**
- (Experimental) Enabled Static Lighting on Project Settings! Meaning we are now able to build maps with Baked Lighting!
- (Experimental) Integrated NVIDIA DLSS! Added two new video settings: DLSS Super Resolution and DLSS Frame Generation (see the [February 2024 News Blog](https://docs.nanos.world/blog/february-2024)).

⏫ **Improvements**
- Reduced the game size by 1-2GB by deleting huge unused assets being cooked.
- Added NavMesh to EmptyMap and minor improvements to NavMesh of BlankMap.
- Now the Escape Menu uses a Low Pass filter effect when being opened.

🔨 **Bug Fixes**
- Fixed a terrible crash causing clients always sending unreliable network packets to server causing several random inconsistencies, warnings and bugs in the game (see the [February 2024 News Blog](https://docs.nanos.world/blog/february-2024)).

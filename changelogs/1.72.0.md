# nanos world - Version 1.72.0

- **Release Date:** 2025-02-14 12:10:40 UTC
- **Raw Timestamp:** `2025-02-14T12:10:40.012Z`

---

🆕 **New Features**
- Added new parameters to [CharacterSimple:SetSpringArmSettings()](https://docs.nanos.world/docs/next/scripting-reference/classes/character-simple#function-setspringarmsettings): `camera_lag_speed` and `camera_lag_max_distance`.

⏫ **Improvements**
- Now server crashes will output a log with it's event id.
- Moved [`GetBoneTransform`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#function-getbonetransform) method from Character to **BasePawn**, and now **CharacterSimple** can use it.
- Moved [`AnimationBeginNotify`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#event-animationbeginnotify) and [`AnimationEndNotify`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#event-animationendnotify) events from Character to **BasePawn**, and now **CharacterSimple** can use it.
- Added new parameters to [`AnimationBeginNotify`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#event-animationbeginnotify) and [`AnimationEndNotify`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#event-animationendnotify) events: `animation_name`, `trigger_begin_time` and `trigger_end_time`.

🔨 **Bug Fixes**
- Fixed Weapon HandlingMode value not syncing on client.
- Fixed inherited class constructor not getting right Package it was spawned, making entities to do not auto destroy when a package is unloaded.
- Fixed VOIP setting not applied when other players connected.
- Fixed typos in Vault Items.
- Fixed Character not syncing EnableHitReaction setting on clients.

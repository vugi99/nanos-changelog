# nanos world - Version 1.167.2

- **Release Date:** 2026-10-31 13:15:00 UTC
- **Raw Timestamp:** `2026-10-31T13:15:00Z`

---

### ⏫ Improvements
- Improved the Rating widgets UI/UX on both Game Jam entries and Vault resources.
- **M_Wireframe** material now supports skeletal meshes.
- Improved the launch error popup "Please launch Steam first", now it tells a better reason it failed to launch: Steam not running, an outdated client, and missing game or Playtest access, and shows Steam's own message.

### 🔨 Bug Fixes
- Fixed grenades damaging players on the same team.
- Fixed the **Friends** widget flickering while refreshing the friends list.
- Fixed vehicle doors showing the enter tooltip when the seat is occupied or the vehicle is destroyed.
- Fixed the **Find Servers** filter not persisting after coming back to the main menu.
- Fixed the password **PopUp** input not canceling when pressing Esc.
- Fixed **Vault** lists being emptied and sorted off the game thread while refreshing, and Vault sort orders changing between refreshes.
- Fixed the game jam card not showing when reconnecting to a game jam server.
- Fixed the escape menu server text not updating.
- Fixed an error for local packages and maps when opening the modal on escape menu.
- Fixed a crash when exiting after **Steam** failed to initialize.

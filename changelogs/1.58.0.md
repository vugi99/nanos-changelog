# nanos world - Version 1.58.0

- **Release Date:** 2023-08-03 10:36:11 UTC
- **Raw Timestamp:** `2023-08-03T10:36:11.915Z`

---

🆕 **New Features**
- Added new console command: `restart`. It will reload all packages and reconnect all players.
- Added new method `Server.Restart()`, to restart the server like the new command.
- Added new method `Package.FlushPersistentData()`, to force the flush pending changes to the Persistent Data of that Package.
- Added new methods to **VehicleWater**: `SetEngineOffset()` and `SetThrustStrength()`.

🔨 **Bug Fixes**
- Fixed Lua parameters containing tables not being passed to C++ in cases of recursion.
- Updated Lua to latest version 5.4.6.
- Attempt to fix a Blueprint issue causing game crashes.
- Fixed starting server from game having timeouts when downloading big assets.

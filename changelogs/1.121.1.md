# nanos world - Version 1.121.1

- **Release Date:** 2026-03-31 20:57:19 UTC
- **Raw Timestamp:** `2026-03-31T20:57:19.490Z`

---

### 🆕 New Features
- Added new methods to server: [`Server.SetDefaultPlayerDimension()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-setdefaultplayerdimension), and [`Server.SetDefaultEntityDimension()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-setdefaultentitydimension). To change which dimensions entities will spawn by default. You can set it just before spawning an entity to force it spawn in that dimension.

### ⏫ Improvements
- We disabled some internal sync that were not being used to improve networking usage.
- Now really far Actors will not sync Location/Rotation/Velocity at all. Characters will not sync Control Rotation as well.
- Improved Characters performance by disabling some movement calculation if you are not the network authority.

### 🔨 Bug Fixes
- Fixed VOIP not applying Global/Local settings on client correctly.

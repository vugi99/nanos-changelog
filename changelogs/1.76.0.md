# nanos world - Version 1.76.0

- **Release Date:** 2025-04-17 15:59:39 UTC
- **Raw Timestamp:** `2025-04-17T15:59:39.000Z`

---

### 🆕 New Features
- Re-added Shadow Map Settings to Video Settings, allowing to switch between normal Shadow Maps and Virtual Shadow Maps, as it is causing lag in some maps.
- Now Frame Timings will be colored (red or orange) if a thread is bottlenecking. Also improved layout by splitting by horizontal lines.
- Added network per second usage in the new Profiling Entities Network panel.
- Implemented Proper Packet Loss debug setting (old was a fake implementation only affecting entities snapshots, newer uses existing low level networking implementation).

### ⏫ Improvements
- Non Authority Characters now use Unreal's SimulatedProxy Role, improving it's internal replication implementation. If you notice anything weird, please let us know.
- Added Individual Entities Classes Ticks to Profiling list.
- Added Individual Entities Classes Ticks to Profiling list.
- Minor Testing Map Foliage colors, shadows, material and performance improvements made.
- Testing Map Trees and most foliage now have Ray Tracing Shadows disabled, improving performance and reducing visual differences between Lumen and Non Lumen settings.
- Now Global Illumination and Reflections defaults to Medium.
- Now TSR is the default Anti Aliasing setting.
- Revisited the Default Scalability Settings, leaving most of graphic settings as Unreal's Default.
- Now the profiling timings will refresh limited at 60hz.
- Improved Character syncing interpolation precision.
- Updated Sentry Plugin, minor Sentry improvements.
- Added logs to Sky when spawning, reusing or destroying the UDS/UDW actor.

### 🔨 Bug Fixes
- Fixed entities sync problem when in bad connection situations (was causing Characters to keep walking forever in the last direction synced).
- Fixed Sky.Spawn not referencing the existing Ultra Dynamic Sky actor if requested.
- Fixed Mouse Sensibility not being affected by FOV (causing huge mouse moves when aiming).
- Fixed Character not keeping firing if it was interrupted and left click was still pressed.
- Fixed Debug Network Advanced Settings saving to disk (it shouldn't).
- Fixes fatal error when disconnecting while a vehicle was honking.
- Attempt to fix VehicleWater crash when setting custom Skeletal Mesh.

# nanos world - Version 1.25.0

- **Release Date:** 2022-12-18 11:16:14 UTC
- **Raw Timestamp:** `2022-12-18T11:16:14.466Z`

---

**New Features**
- Added new parameter to `Color.ToHex(appends_transparency)`.
- Added new method to **Trigger**: `SetOverlapOnlyClasses()`.
- Added new method to **StaticMesh** and **Prop**: `SetMesh()` (experimental).
- Renamed **Vehicle**, **Pickables** and **Prop** method `GetAssetName()` to `GetMesh()`.

**Improvements**
- We are introducing a new Async Loading system which will improve stutters in runtime when loading assets from Disk. Currently this is only implemented for Props for testing.
- Now cables will be automatically destroyed when parent Actors get attached to something else or when Characters enter vehicles (the cables were breaking client-side).

**Bug Fixes**
- Fixed Character FOV not resetting when reloading weapons.
- Fixed entities being initialized before packages were loaded, making custom classes to do not apply on client when package reloading.
- Fixed map-package attempting to reload causing errors on console when changing maps.
- Fixed Killed by Prop achievements being triggered when other players get killed. Also fixed some other Achievements errors/warnings.
- Fixed Materials not applying custom properties when overriding a material until reconnecting.

# nanos world - Version 1.99.2

- **Release Date:** 2025-12-08 14:25:43 UTC
- **Raw Timestamp:** `2025-12-08T14:25:43.381Z`

---

### ⏫ Improvements
- The **Interpolation System** has been drastically improved. We've fixed high-speed entities sync (such as Vehicles) causing it feel very laggy. All sync will feel way smoother now, even in poor network conditions.
- Now the interpolation will only happen for entities that are visible on screen, and close by a distance of 10000 units. Otherwise they are snapped to the network received location.
- Now all error logs will be displayed in the new notification system (disableable by setting Client.SetDebugEnabled(false)).
- Now the **Debug Network in World** debug option will display squares displaying the received snapshot from the server relative to the current location, and the received velocity as an arrow.

### 🔨 Bug Fixes
- Fixed Weapons being translated with Translate/RotateTo causing stutters or rotation snap issues.
- Fixed a crash when spawning a Character while being overlapped by a vehicle.
- Fixed a crash when quitting the game with WebUIs spawned.
- Fixed a fatal error when server tries to send logs bigger than 512 KB to clients (on localhost).
- Fixed server infinitely storing logs in memory without releasing them on localhost servers.

# nanos world - Version 0.28.2

- **Release Date:** 2020-06-26 19:30:01 UTC
- **Raw Timestamp:** `2020-06-26T19:30:01.489Z`

---

**Improvements**
*  Post Process now is attached to the Camera (instead to the map), so imported Maps will have the proper Nanos World PP configuration (it can be overridden with a custom Post Process volume as well).
*  We did several improvements regarding Asset Pack and fixed some bugs which caused bad references. And now importing custom assets/maps may work perfectly. Please take a look at https://docs.nanos.world/getting_started/Assets for more information on how to export/import them.

**Bug Fixes**
*  Fixed a crash when trying to connect to a server after disconnecting from another one.
*  Fixed some minor Asset bugs.

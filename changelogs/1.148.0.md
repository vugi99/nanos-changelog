# nanos world - Version 1.148.0

- **Release Date:** 2026-07-16 13:34:41 UTC
- **Raw Timestamp:** `2026-07-16T13:34:41.000Z`

---

### 🆕 New Features
- Added a new **Dashboard** tab to the Vault Resource Manage, that displays a checklist for completing your resource profile. You will only be able to publish your resource after completing the checklist.
- Added new Actor [`NetworkAuthorityChange`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#event-networkauthoritychange) event.
- Added new client methods to Actor: [`GetMass()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-getmass), [`GetAngularVelocity()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-getangularvelocity).
- Added new method [`Vehicle.IsEngineStarted()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-isenginestarted).
- Added new events to **Vehicle**: [`EngineStart`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#event-enginestart) and [`EngineStop`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#event-enginestop).
- Added new methods to VehicleWheeled: [`SetHeadlightsEnabled()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehiclewheeled#function-setheadlightsenabled) and [`SetTaillightsEnabled()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/vehiclewheeled#function-settaillightsenabled).

### ⏫ Improvements
- Improved our Auth system when connecting to a server, to prevent issues from Steam rate-limiting. Now tickets will only be generated when your queue position reaches to zero.
- Now Character.GetVehicleSeat() returns `-1` when the character is not in a vehicle.
- Now Game settings will limit the FOV to 60-120.
- Improved the Vault Resource Manage Tags tab visualization.

### 🔨 Bug Fixes
- Fixed a crash when using FSR Frame Generation.
- Fixed downloaded Vault .zips not validating special unwanted paths.
- Fixed Pawn.SetMeshSettings() `visible` wrong default parameter.
- Fixed CharacterSimple not updating the camera Z location when being re-scaled.
- Fixed more broken UIs due localization.
- Fixed VehicleWheeled Headlights color not being applied to the Vehicle material.

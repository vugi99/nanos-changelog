# nanos world - Version 1.160.0

- **Release Date:** 2026-10-14 19:40:00 UTC
- **Raw Timestamp:** `2026-10-14T19:40:00Z`

---

### 🆕 New Features
- Added a new **Steam** API to invite friends and handle friend joins: [`Steam.OpenInviteDialog()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/steam#static-function-openinvitedialog), [`Steam.InviteFriend()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/steam#static-function-invitefriend), [`Steam.GetJoinedFromFriend()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/steam#static-function-getjoinedfromfriend) and the [`FriendJoin`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/steam#event-friendjoin) event.
- Added [`Chat.Submit()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/chat#static-function-submit) to submit a chat message on behalf of a Player, so custom chat interfaces keep chat commands working.
- Added [`Timer.Unbind()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/timer#static-function-unbind).
- Added `max_swim_speed` to [`CharacterSimple:SetSpeedSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/charactersimple#function-setspeedsettings).

### ⏫ Improvements
- Morph targets and [`SetTeam()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-setteam) now work on every **Pawn** type (**Character** or **CharacterSimple**).
- Now `SetMaterialFromCanvas()`, `SetMaterialFromWebUI()` and `SetMaterialFromSceneCapture()` respect `attachable_id` and apply to attached meshes.
- Now textures imported from disk are reloaded when their file changes.
- Now accepting a Steam invite to the server you are already on no longer reconnects you (but trigger the `FriendJoin` event).
- We refactored and changed our internal TOML parser library. Let us know if you see any bug!

### 🔨 Bug Fixes
- Fixed leaving a local server started from the in-game UI not shutting down properly, not triggering `Stop` and `PlayerDisconnect` events.
- Fixed `Class.Inherit` reporting wrong messages on invalid arguments.
- Fixed [`Server.LoadPackage()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-loadpackage) not sending the package to the clients already connected.
- Fixed Morph targets not being kept when the mesh changes and when a skeletal mesh is attached later.
- Fixed `SetMaterial()`/`ResetMaterial()` on an attached mesh turning the main mesh's slot into a dynamic material.
- Fixed [`Character:GetAllMorphTargetNames()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-getallmorphtargetnames) not being available on the client.
- Fixed `Player:SetDimension()` not updating the dimension of the owning client, and some other dimensions bugs.
- Fixed `SetDimension()` being able to be called on client side.
- Fixed Characters freezing for other players when the network authority changed in the same tick as a `SetLocation()` (e.g. `Detach()` + `SetLocation()` + `Possess()`).

### 🌐 Account, Store & Website
- Added [**Recruiting**](https://nanos-world.com/community/recruiting): teams can post open positions (skill, compensation, budget, commitment, languages and contact), linked to a project if they want.
- Added a **Help** menu to the top bar with support, feedback and bugs, crash lookup, documentation, server status and troubleshooting.

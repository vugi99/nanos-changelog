# nanos world - Version 1.118.0

- **Release Date:** 2026-03-26 14:14:44 UTC
- **Raw Timestamp:** `2026-03-26T14:14:44.590Z`

---

### 🆕 New Features
- Added new parameter to **VehicleWheeled.SetSteeringSetup()**: `steering_curve`.
- Added new parameters to **VehicleWheeled.SetTransmissionSetup()**: `forward_gear_ratios` and `reverse_gear_ratios`.

### ⏫ Improvements
- Added a small buffer delay on VOIP playback, to reduce micro-stutters due missing or delayed VOIP packets.
- Improved the in-game console efficiency by not adding entries while it's not open.
- Improved the performance of **CharacterSimple** and **Player** by reducing some ticks and components being created for non local players.
- We reduced the max player networking pending data buffer, to kick players faster when they have bad connection.
- Increased the **default-blank-map** landscape size.
- Added Treasure Pack assets.

### 🔨 Bug Fixes
- Fixed several **VehicleWheeled** issues that were not applying scripting properties properly, causing the Vehicles to slip too much or to behave incorrectly.
- Fixed **Gamma Override** resetting when applying video settings.
- Fixed the **server freezing** due a deadlock when players were kicked by having the buffer full.
- Fixed a "OnNewUrlLaunchParameters" notification error when connecting to a server through steam protocol `steam://`.

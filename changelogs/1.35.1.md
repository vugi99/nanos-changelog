# nanos world - Version 1.35.1

- **Release Date:** 2023-02-11 14:14:20 UTC
- **Raw Timestamp:** `2023-02-11T14:14:20.517Z`

---

🆕 **New Features**
- Added new event to **SceneCapture**: `Capture` which triggers when capturing a new frame.
- Added new method to **SceneCapture**: `EncodeToBase64Async()`.

⏫ Improvements
- Added new **ImageType** enum: `BMP` (used by SceneCapture EncodeToBase64 method).
- Removed Stack-O-Bot hardcoded camera shake.
- Enabled HDRIBackdrop Plugin.
- Improved the performance internally by reducing several redundant string copies when passing values to and from Lua scripting.

🔨 **Bug Fixes**
- Fixed EncodeToBase64 performance problem with JPG.
- Fixed Stack-O-Bot AnimationBP making it to walk over the water.

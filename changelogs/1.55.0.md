# nanos world - Version 1.55.0

- **Release Date:** 2023-06-08 12:19:09 UTC
- **Raw Timestamp:** `2023-06-08T12:19:09.798Z`

---

This update includes a new Compatibility Version [`1.55.0`](https://docs.nanos.world/docs/next/core-concepts/packages/compatibility-versions#version-155) with changes to `Assets` static class.

🆕 **New Features**
- Added a new class [Widget3D](https://docs.nanos.world/docs/next/scripting-reference/classes/widget3d), which allows spawning Widgets in 3D world!
- Now [Trigger](https://docs.nanos.world/docs/next/scripting-reference/classes/trigger) can be spawned on Client Side too!
- Added new CLI commands: [`upload package/assets NAME`](https://docs.nanos.world/docs/next/core-concepts/server-manual/command-line-interface#all-cli-commands) which allows uploading new versions of your local resource to the store!
- Now Assets.toml support a new format of listing Assets with [MetaData](https://docs.nanos.world/docs/next/core-concepts/assets#asset-meta-data) included!
- Added new method to Character, Vehicle, Weapons: `GetAllSkeletalMeshAttached()` and `GetAllStaticMeshAttached()`!

⏫ **Improvements**
- Now all [`Assets.GetX()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/assets#static-functions) will return a list of tables instead of list of strings (see [`new compatibility version`](https://docs.nanos.world/docs/next/core-concepts/packages/compatibility-versions#version-155)).

🔨 **Bug Fixes**
- Fixed CEF remote debugging not working since last update.
- Fixed a problem when parsing invalid Assets.toml overriding the local file making it empty. Now it will throw an error and will abort the loading.

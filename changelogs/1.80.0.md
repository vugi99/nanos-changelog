# nanos world - Version 1.80.0

- **Release Date:** 2025-06-13 20:57:25 UTC
- **Raw Timestamp:** `2025-06-13T20:57:25.298Z`

---

### 🆕 New Features
- Added a new [Assets Pack Auto Reload](https://docs.nanos-world.com/blog/june-2025#asset-pack-auto-reload) system, that detects if files were modified and re-caches the Asset Pack, preventing clients from attempting to download deleted/outdated files, causing disconnects and crashes.
- Now Level.GetStreamLevels() will return the `path` and `is_temp` if it's a temporary spawned level.
- Added a new Trace mode: [TraceMode.TraceOnlyVisibility](https://docs.nanos-world.com/blog/june-2025#trace-visibility) to trace for only visible collision.
- Added new enum `CollisionChannel.All`.
- Added new Setting for [System Stats](https://docs.nanos-world.com/blog/june-2025#new-system-stats).
- Added many more new Splash Texts on main menu.

### ⏫ Improvements
- Calling a C function (e.g. any entity method) from Lua will now [preserve parameters in stack](https://docs.nanos-world.com/blog/june-2025#lua-internal-stack).
- Several [File Transfer](https://docs.nanos-world.com/blog/june-2025#file-transfer-overhaul) improvements and bug fixes, greatly increasing stability and performance. Fixed stutters on loading screen.
- Added a new Markdown parser for the main menu [Changelog](https://docs.nanos-world.com/blog/june-2025#changelog-markdown).
- Added server-side warnings if an Asset File is modified after it was cached when a Player tries to download it. And now the client will try to download the newer file without being kicked.
- Improved Assets.toml entries validation, by validating empty paths and outputting the ones that are wrong or invalid.
- Improved Asset Pack async caching algorithm, overall performance increased, also fixed logs and thread count usage and added progress debug log.
- Now times will be displayed with only 2 decimal places (was 3).
- Added warnings when attempting to Load or Unload StreamLevels if it is already loaded/unloaded.
- Improved the Line Traces draw debug by adding a point to the impact location.
- Now Steam Achievements Icons and Steam Profile Images are loaded asynchronously.
- CEF was updated to 137.

### 🔨 Bug Fixes
- Fixed restarting server with restart console command not kicking the players properly, causing fatal errors if they were connecting and downloading files.
- Fixed Character not restoring aiming if it was blocked.
- Fixed Files and Database not cleaning up properly when unloading a Package, remaining open until the server is restarted. Also fixed async operation not being waited when Packages unload, causing crashes.
- Fixed a crash when spawning a vehicle with auto initializing physics.
- Fixed several UI popups with broken layout.
- Attempt to fix some client crashes.

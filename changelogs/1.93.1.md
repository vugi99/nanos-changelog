# nanos world - Version 1.93.1

- **Release Date:** 2025-10-26 10:31:40 UTC
- **Raw Timestamp:** `2025-10-26T10:31:40.100Z`

---

### 🆕 New Features
- Added an "experimental" **Hub Server** section in main menu. For now it will just display the official sandbox server so everyone can directly connect to it.

### ⏫ Improvements
- Improved Character interaction trace distance and angle. Picking up/grabbing items would be more precise now.
- Increased the camera attachment distance from head when in FPS, reducing the character head overlap effects.
- Player's Possess event will now be called after the Character actor was actually possessed on client side.
- Now Trigger will only warn not passing 'overlap_only_classes' once, only if you didn't pass it to the constructor AND didn't set it just after it was spawned.
- Added a Cull Distance limit to Weapons (10.000 units) and Vehicles (15.000 units) to become hidden in far distances (and reduce drawing cost).
- Minor improvements on several main menu UIs.

### 🔨 Bug Fixes
- Fixed Characters losing the Network Authority when detaching while possessed, causing them to be uncontrollable.
- Fixed Highlight/Outline actors not restoring to the scripting defined value after it was "looked at" by the Character.
- Fixed some balloons meshes being invisible.
- Fixed Character collision not resetting correctly when coming back from Ragdoll state, causing it to fall through the ground.
- Fixed having a Controller connected to computer causing the input to get messy (e.g. not being able to sprint).
- Fixed Character animations getting rigid when swimming or flying, also fixed idle animation while in FPS causing it to rotate weirdly.
- Fixed Server crash when passing invalid command_line arguments.
- Fixed the server compressing non-compressible files (e.g. .ogg), also fixed it ignoring the .extension casing for such validations.

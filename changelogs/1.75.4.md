# nanos world - Version 1.75.4

- **Release Date:** 2025-04-10 10:10:12 UTC
- **Raw Timestamp:** `2025-04-10T10:10:12.475Z`

---

### 🆕 New Features
- DLSS 4 is now fully implemented! We added a lot of new Menu Settings. [See blog news](https://docs.nanos.world/blog/april-2025#dlss-4-full-integration).
- Now it's possible to Input.Bind to "Menu" keybinding, allowing scripters to subscribe to ESCAPE being pressed.

### ⏫ Improvements
- The Profiling overlay layout has been improved. [See blog news](https://docs.nanos.world/blog/april-2025#profiling-debug).
- Removed "Show FPS" settings, in favor of the new "Display Frame Times" setting, which displays detailed frame information. [See blog news](https://docs.nanos.world/blog/april-2025#fps-timings).
- Improved default-testing-map performance by disabling Landscape's Grass Dynamic Shadows, and enabling Contact Shadows to achieve the same visual results and huge performance boost.
- Re-added the old ambience sound to default-testing-map (it was not working since the integration of Ultra Dynamic Sky).

### 🔨 Bug Fixes
- Fixed Chat Widgets getting focus and selected when pressing Tab.
- Fixed some default-testing-map props LODs that were too much aggressive.

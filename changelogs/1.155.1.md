# nanos world - Version 1.155.1

- **Release Date:** 2026-09-09 21:44:42 UTC
- **Raw Timestamp:** `2026-09-09T21:44:42.387Z`

---

### 🆕 New Features
- Added [`Client.GetSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/client#function-getsettings).
- Added a new **"Character Shooter Mode"** system: an aim mode where a held Weapon stays aimed while idle or walking, lowers while sprinting, and aim input aims down sights instead of raising the Weapon, enabled with [`Character:SetWeaponShooterMode()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/character#function-setweaponshootermode).
- Added [`GetSocketTransform()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-getsockettransform) support for Attachable IDs.
- Added a **Game Jam** tab to the main menu.

### ⏫ Improvements
- Now `TranslateTo()` uses implied velocity when applying synced positions, fixing sync stutters.
- Improved Network Based sync system and minor fixes. Experimental: `bStayBasedInAir` is now enabled by default.
- Updated **Lua** to version `5.4.9`.

### 🔨 Bug Fixes
- Fixed calling Character.SetCameraMode(FPSOnly) causing the camera to be attached on foot.
- Fixed file transfers not resetting accumulated download speed after the first transfer, showing PB/TB/s speeds.

### 🌐 Account, Store & Website
- Improved the review and rating experience with a new review modal.
- Added particle effects when rating, favoriting or creating a team/resource/project. You should try it! 😉
- Added a [**Birthday**](https://nanos-world.com/account/profile) field to your profile, and a new [**Setting**](https://nanos-world.com/account/notifications) that you can enable for our Discord bot to say happy birthday and give you a special role on your birthday! (bye bugged Mee6).
- Now reviewing or creating a Team or Resource is posted to https://discord.com/channels/124107916432113666/801036656617455616 channel.
- Added a **History** tab to Team/Resources manage page showing an audit trail of changes made to it.
- Improved the resources carousel images visualization and interaction.
- Increased max upload image size to 5 MB; standardized image uploaders components and fixed some issues.
- Increased max screenshots to 10 per resource.
- Several bug fixes, UX, UI and font improvements.

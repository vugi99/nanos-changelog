# nanos world - Version 1.67.0

- **Release Date:** 2024-10-28 12:32:40 UTC
- **Raw Timestamp:** `2024-10-28T12:32:40.000Z`

---

🆕 **New Features**
- The game has been updated to Unreal Engine 5.4!

⏫ **Improvements**
- Now if we start a new game through the main menu and there's already an instance of the server running, it will throw an error and prevent the in-game server from starting.
- Improved a lot of loading/downloading messages during loading screen.
- New Network Authority Debug color: Black, to display if an entity is client side (authority).
- Added new information to Network Debug in the World, displaying the class name and it's ID on screen as well (if the entity is close to the player).
- Updated our Hash functions to use 64 bits instead of 32. Fixing some issues regarding assets hashes colliding when validating files and a lot of other random rare issues. All the assets will need to be revalidated and recached (automatically when loading your Asset Pack).
- Now the game uses Seamless Travel to improve loading times while connecting to a server. The overall Loading process was changed a little to adequate this and a lot has been improved, including labels and texts.
- Now a lot of default used assets are preloaded during the loading screen as well, fixing some stutters during the game.
- Now possessing a character will wait the levels streaming to complete, preventing the character falling through the ground when possessing a far distant character.
- Improved the main menu World easter egg, with new sounds and effects.
- Now if something goes wrong while downloading files during the loading screen, the game will attempt to reconnect to the server, redownloading the missing files.
- Now Assets validating will be done asynchronously (using multiple processors), heavily improving the loading time on server and client when validating asset packs files.
- Improved profiling logs time display (it will parse seconds, minutes and miliseconds separately to display, instead of showing as milliseconds always).
- Updated CEF to 130.
- Updated UltraDynamicSky to 8.4.
- Updated DLSS to 3.7.20.
- Updated Lua to 5.4.7.
- Updated all the library dependencies.

🔨 **Bug Fixes**
- Fixed the "Character Crash" when joining a server with Characters spawned.
- Fixed the missing water on TestingMap, and other fixes and improvements.
- Fixed Character without Swimming animation.
- Fixed Network Debug in World displaying information on screen even if escape menu is opened.
- Fixed DropDown and Button widgets with wrong design/color.
- Attempt to fix random crashes in main menu due Steam Friends API.
- Fixed Package.toml file being wrongly parsed in some cases, getting corrupted and broken.

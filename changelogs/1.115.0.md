# nanos world - Version 1.115.0

- **Release Date:** 2026-03-15 16:32:36 UTC
- **Raw Timestamp:** `2026-03-15T16:32:36.406Z`

---

### 🆕 New Features
- Added a new method [Server.AddMapSpawnPoint()](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/server#static-function-addmapspawnpoint) to dynamically add spawn points.
- Added a new method [WebUI.IsReady()](https://docs.nanos-world.com/docs/next/scripting-reference/classes/web-ui#function-isready).
- Added a new method [Client.OpenEscapeMenu()](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#static-function-openescapemenu) to force opening the escape menu, optionally opening the settings directly.
- Added a new parameter to [Sky.SetTimeOfDay()](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/sky#static-function-settimeofday): `transition_time`.

### ⏫ Improvements
- Now **Inherited Entities** will only trigger `Spawn` event after leaving the constructor.
- Now **CharacterSimple** **Spring Arm** relative location will be `Capsule Height * 1.8` by default. Use [CharacterSimple.SetSpringArmSettings()](https://docs.nanos-world.com/docs/next/scripting-reference/classes/character-simple#function-setspringarmsettings) to manually override it.
- Now scripting **HTTP** requests will not output errors to console anymore.
- Now Character **Parachuting** will be prevented if too close to the ground and in high velocity.

### 🔨 Bug Fixes
- Fixed client side spawned **Props** not triggering Hit events or playing hit sounds.
- Fixed **"Draw Debug Character Capsule"** setting not working on recently spawned **CharacterSimple**.
- Fixed `Sky.Reconstruct()` not working and throwing an error.
- Fixed `Sky.SetMoonTexture()` not working.
- Fixed **Canvas** not rendering **SceneCapture** correctly.
- Attempt to fix client "freezing" due a deadlock when using **SceneCapture** and **EncodeToBase64Async**.

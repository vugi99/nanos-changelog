# nanos world - Version 1.6.0

- **Release Date:** 2022-03-20 10:59:56 UTC
- **Raw Timestamp:** `2022-03-20T10:59:56.952Z`

---

**New Features**
* Added new Timer methods.
* Added new Attachable methods (RemoveAllStaticMeshesAttached).
* Added new method to file: `ReadAsync`.
* Added new event to Characters: `HealthChanged`.
* Added new events to Weapons: AmmoClipChanged & AmmoBagChanged.
* Added new methods to Particles to customize it's Materials and to Activate/Deactivate it.
* Added new method to Player: `IsHost()`.
* Added new methods to Actor: `IsVisible()` and `RemoveActorTag()`.
* Added new methods to Light: `SetCastShadows()`, `SetIntensity()`, `SetAttenuationRadius()`, and it's getters,
* New events to Client: MouseMoveX and MouseMoveY.
* Now all StaticMeshActors from the Map will be automatically loaded as Client's StaticMesh entities.

**Improvements**
* Added a new category to Assets.toml: unreal, with new setting: unreal_version.
* Improved network usage & performance.
* Improved Network Authority Algorithm.
* Props can now be spawned on Client side.
* Vehicles now produce Tire Skid effects on ground and also Blood effects.
* Improved error handling on Databases.
* Improved Logs so they output the correct time.
* Now Grabbed Props will not push other bigger objects.
* Improved Hit sounds to prevent it from retriggering at the same position.
* Now Props will be automatically ungrabbed if they get too far from the Character.
* Improved the performance when spawning blood and bullet decals (will be limited and dependent on the Graphic Effects Settings).
* Improved Ragdoll damage triggering multiple times at once.
* Improved performance on far vehicles.
* Now Textures (when loading to Materials) will be loaded asynchronously.
* Now Cable will have a second constructor parameter: `enable_visuals`, disabling it will make it behave just like a Physics Constraint without the cable visual.
* Now Lights can be disabled/enabled with `SetVisibility()`.
* Now all Basic Structs (Vector, Rotator) operators can be used in any order (e.g. Vector * number or number * Vector).
* Added new Methods to Rotator: GetRightVector() and GetUpVector().
* Improved Vehicle collisions against other objects.
* Improved Sun lights and shadows.
* Removed hit sounds from grabbing props on self Character.
* Improved grabbing Prop interpolation movement when changing stance.


**Bug Fixes**
* Fixed Reloading Packages not waiting all packages to trigger Load event on Client side.
* Fixed Pickables missing some Paintable methods.
* Fixed a crash when leaving the game while in a Vehicle.
* Fixed Health not syncing properly when a Character is created.
* Fixed crash when closing the game during gameplay while having Pickables picked up.
* Fixed Input overriding Game Bindings where having a Scripting Binding with the same key.
* Attempt to fix disconnect crash from Menu.
* Attempt to fix Fatal errors when spawning Props client-side.
* Attempt to fix collisions when spawning a Vehicle at the same position of a Character.
* Fixed Unpossessing Characters causing Network Authority warnings.
* Fixed Props being able to grab always.
* Fixed AddForce not working on attached props.
* Fixed Actor:GetVelocity() always returning positive values.
* Fixed recently respawned characters taking damage if shooter keeps shooting the ragdoll body.
* Attempt to fix characters from appearing in the last position for few ms after respawning.
* Fixed client-side spawned Entities attempting to call Server remote methods.
* Fixed Translate/RotateTo only calling half of the frames when object was out of the screen.
* Fixed Characters being able to fly while were driving.
* Fixed Database "callback hell".

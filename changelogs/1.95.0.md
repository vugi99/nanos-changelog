# nanos world - Version 1.95.0

- **Release Date:** 2025-11-06 17:10:47 UTC
- **Raw Timestamp:** `2025-11-06T17:10:47.000Z`

---

### 🆕 New Features
- Added a new setting to Server's `Config.toml`: `max_send_rate`, allowing to configure the max network send rate per client connected. The default value is now 32 MB/s, and works on both dedicated and P2P servers (increasing P2P servers connection speed).

### ⏫ Improvements
- Updated our Steam SDK to Steamworks v1.62.
- Now Vault validates all installed Packages & Asset Packs asynchronously when the game/server starts.
- Now a pretty reason will be displayed if a client fails to connect due Steam authentication error.
- Now attempting to connect to a server with multiple instances of the same Steam account will show a proper error and the connection will be refused (before it was causing fatal errors and unforeseen consequences). Start the server in offline mode to allow it.
- Now **Player** `VOIP` event will trigger on the client for the local player first.
- Now **Weapon/Character** `Fire` event will trigger on the client for the network authority first.
- Now when aborting connecting to a server (while in the loading screen), a message will appear saying the loading is aborting (and freeze for a few seconds as it flushes all pending loading/downloading).
- Now **Console.RunCommand()** will not allow running native commands, as it was causing some crashes. Use the native scripting methods for that.

### 🔨 Bug Fixes
- Fixed attached Characters and Vehicles losing the network authority when parent gets a new Network Authority.
- Fixed crashes not flushing the Logs to disk.
- Fixed Escape Menu not allowing to scroll the player list.
- Fixed Bullet Decals not being destroyed if attached actor was destroyed.
- Fixed stutters when loading Steam images (achievements, player profile).
- Fixed aborting to connect on servers causing a "blue screen" if it was already at a traveling to map state.
- Fixed WebUI material rendering incorrectly (was 2 sided).
- Fixed CEF not being able to load and play YouTube videos as embedded.
- Fixed server crash if a player is kicked and the server receives a client packet after it.
- Fixed HTTP file transfer errors when the server changes the map while a client attempts to download a file.
- Fixed crash when setting a value on a destroyed entity (i.e. deleted_entity.key = value). Now it will properly throw the "entity is destroyed" error.
- Attempt to fix several CEF crashes and fatal errors when resizing, reloading or destroying them.
- Attempt to fix crashes when disconnecting from servers while in loading/downloading state.

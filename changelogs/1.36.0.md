# nanos world - Version 1.36.0

- **Release Date:** 2023-02-16 13:44:32 UTC
- **Raw Timestamp:** `2023-02-16T13:44:32.453Z`

---

🆕 **New Features**
- Added new Custom Settings type: `select`! Which displays as a DropDown.

⏫ **Improvements**
- Added a recursive validator to prevent SceneCapture from being destroying from inside a Capture event.
- We added a new internal system to report FATAL errors to our Crash center automatically.
- Now Blueprints support passing the Materials from Canvas, WebUI and SceneCapture through Blueprint Functions/Events (Lua -> Blueprint), for that, just pass the entity and it will be converted to it's Material when receiving from Blueprint.
- Now Vault will display local installed items if we are without connection/API is off.
- Now Server.[Load/Reload/Unload]Packages return a bool if the Package was found.

🔨 **Bug Fixes**
- Fixed Vehicle collision resetting to Block All after leaving vehicles.
- Fixed Packages on client side not respecting loading order of requirements.
- Fixed a crash when a Package tries to load itself in the requirements.
- Fixed client not enqueuing custom events when package loading a new package.

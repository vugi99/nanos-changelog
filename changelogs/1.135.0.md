# nanos world - Version 1.135.0

- **Release Date:** 2026-04-30 09:36:14 UTC
- **Raw Timestamp:** `2026-04-30T09:36:14.899Z`

---

### ⏫ Improvements
- Improved Characters networking, optimizing networking jumps and snapshots sync. If you notice any desync, please let us know!
- Improved Character client side interpolation precision and performance.
- Added a new system to force updating distant desynced actors when you get too far from them and come back close. Which was leaving them desynced until they move and get updated again. Now this system will force an update when you get close to any distant actor.
- Added (AI generated) Chinese, Russian, Italian, Japanese and Polish languages. If you are a native speaker of any language, please help us validating the translations!
- Improved client side performance, caching some too frequent method accesses and improved our internal entity loop efficiency.

### 🔨 Bug Fixes
- Fixed Steam rate limiting us when attempting to authenticate more than 500 players on the server.
- Fixed several other not working places for C:/Users with accent. We reworked WebUI, File and Packages loaders, please let us know if you experience any bug.
- Fixed more UI texts not working in some localized languages.

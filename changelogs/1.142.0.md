### 🆕 New Features
- Added a new *experimental* method [`Package.LoadFile()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/package#static-function-loadfile). To load .lua files in a sandboxed way. This method compiles and returns a function to execute the file content, allowing passing a custom `env` table as parameter.

### ⏫ Improvements
- Now the **Profile** window will display the user teams in the sidebar.
- Improved several internal memory allocations.

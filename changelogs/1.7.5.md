# nanos world - Version 1.7.5

- **Release Date:** 2022-05-18 12:39:06 UTC
- **Raw Timestamp:** `2022-05-18T12:39:06.986Z`

---

**Improvements**
* Now all sync/interpolation/extrapolation is using Unreal's Physics replication system. For now this only affects physics objects (and soon will come for Characters as well).
* Tweaked the Network Debug to display the colors in a more useful way.
* Now .ogg files can be defined in the Assets.toml as well and referenced like any other asset.
* Now Actor:GetVelocity() can be called on server side as well.
* Improved the serialization/compression on some data types.

**Bug Fixes**
* Fixed some data serialization bugs decompressing into wrong values on other side.
* Fixed two players being the Network Authority of the same entity.
* Fixed StopAnimation not stopping animations anymore.
* Fixed PlayAnimation not working sometimes.
* Fixed "sleeping" entities getting out of sync and staying at different locations for each player.
* Fixed damage setting Network Authority on non distributed actors.
* Fixed weapons still pulling use after entering vehicle.
* Fixed wrong Eye Height when proning.

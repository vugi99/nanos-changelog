# nanos world - Version 1.66.0

- **Release Date:** 2024-08-01 12:25:33 UTC
- **Raw Timestamp:** `2024-08-01T12:25:33.968Z`

---

🆕 **New Features**
- Added new method to **Character** and **CharacterSimple**: [`SetAirControl()`](https://docs.nanos.world/docs/next/scripting-reference/classes/character#function-setaircontrol).
- Added new static method [`File.GetFullPath()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/file#static-function-getfullpath) to return the full path given a relative path.

⏫ **Improvements**
- Now `Console.Warn()` and `Console.Error()` will display a stack trace in the console.
- Added debug logs when using File.GetFiles() and File.GetDirectories().

🔨 **Bug Fixes**
- Fixed default Package.toml being generated without a type, causing errors (now it will default to script).
- Fixed File.GetFiles and File.GetDirectories not returning correct values on client side. Now it returns paths based on `Packages/` root directory and not `.transient/` directory anymore.

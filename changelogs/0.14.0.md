# nanos world - Version 0.14.0

- **Release Date:** 2020-05-16 16:01:09 UTC
- **Raw Timestamp:** `2020-05-16T16:01:09.378Z`

---

This is a **BREATHTAKING** update! We've been working on such functionalities for the last few days which will open the scripters's possibilities =D

**New Features**
*  New function for every Actor's class: `AttachTo(Actor, Vector)` - you can now attach whatever to anything!
*  New *Breathtaking Functionality*: **SCRIPTERS EVENTS**! You can finally trigger events between packages and between NETWORK! (Server -> Client  and Client -> Server events!). Find out more on https://docs.nanos.world/scripting/global-variables/Events.html! It is possible even to send **Nanos's Objects** such as *Vector*, *Rotator*, *Character*, *Player* and so on!

**Breaking Changes** - Please Scripters update your code:
*  Character's functions `PickUpWeapon`, `PickUpGrenade` and `PickUpItem` were renamed to just `PickUp`
*  Character's functions `GetWeapon`, `GetGrenade` and `GetItem` were renamed to just `GetPicked`
*  Character's events `PickUpItem` and `DropItem` were renamed to just `PickUp` and `Drop`

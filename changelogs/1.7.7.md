# nanos world - Version 1.7.7

- **Release Date:** 2022-05-21 18:22:03 UTC
- **Raw Timestamp:** `2022-05-21T18:22:03.063Z`

---

**New Features**
* Added new in-game Console tab to display the logs in plain text (for easy copy).

**Improvements**
* Added better validation when something fails when downloading files during connecting to a server.

**Bug Fixes**
* Fixed old .cache files not being discarded when the asset was updated.
* Fixed characters being stuck after respawning when in ragdoll mode.
* Fixed vehicles moving without driver not being able to roam characters.
* Fixed windows terminals not outputting correct extended ASCII characters.
* Fixed network authority not sleeping entities.
* Fixed not being able to jump after running over a ledge.
* Fixed entering a vehicle while in ragdoll staying at wrong state.

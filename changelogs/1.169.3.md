# nanos world - Version 1.169.3

- **Release Date:** 2026-11-07 11:15:00 UTC
- **Raw Timestamp:** `2026-11-07T11:15:00Z`

---

### 🆕 New Features
- Implemented .webp support for loading images as Unreal Textures and into materials.

### ⏫ Improvements
- Improved the server and client game thread frame performance by optimizing the tick and iteration of all actors and entities.
- Improved Tracy profiling with more categories, detailed frame and loading stages, and additional Unreal statistics.
- Updated built-in asset thumbnails and pattern images to WebP.
- Internal refactor: the Console and Package scripting classes and entity lists were reworked. These changes should be invisible to scripts, but please let us know if something breaks. Note that assigning custom values and functions to Static Classes is not supported, although it worked for a few classes in the past. We added a warning if you do that to prevent scripting breaks, but in the future it will be completely blocked.
- Internal refactor: our path/files loading system was reworked to solve and fix crashes caused by invalid UTF-8 used by scripts or when loading textures, sounds and fonts and now every file loading goes through this new path validator. If you get any error or crash, please let us know!

### 🔨 Bug Fixes
- Fixed actors (with auto network authority distribution off) retaining network authority when their authority player disconnects.

### 🌐 Account, Store & Website
- Added WebP support for image uploads.
- Lists now remember your page size and sorting preferences, and shared links preserve the selected settings on every table/listing.
- Fixed management breadcrumbs for unpublished projects and resources linking to the public 404 unreleased page.
- Fixed our resource validator not reporting back the error in some cases.

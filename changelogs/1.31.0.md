# nanos world - Version 1.31.0

- **Release Date:** 2023-01-24 19:01:50 UTC
- **Raw Timestamp:** `2023-01-24T19:01:50.080Z`

---

**New Features**
- **Experimental**: Added new method to **WebUI**: `ExecuteJavaScript`, it is only possible to run on local loaded pages.
- **Experimental:** Added new parameter to server `--compression` which allows setting the compression level (0-9) for *some* network operations (currently used for Small Package Files and Server Requirements List). It helps reducing a lot the networking packet sizes at the cost of CPU processing.
- Added new methods to **Vehicle** and **Weapon**: `PlayAnimation()` and `StopAnimation()`.
- Added new method to **Player**: `GetAccountIconURL()` which returns a special URL of the Player's Steam Avatar which can be used from WebUI.

**Improvements**
- Package setting **load_level_entities** is now false by default.
- Added WebUI verbose logs when receiving key events from the interface, for debugging purposes.
- Some improvements were made to reduce network usage from the character construction. Let me know if any desync or weirdness happen.

**Bug Fixes**
- Fixed missing and wrong WebUI KeyCodes (Left/RightCommand, A_AccentGrave, C_Cedille, E_AccentAigu, E_AccentGrave, Section).

# nanos world - Version 1.87.0

- **Release Date:** 2025-09-25 13:02:59 UTC
- **Raw Timestamp:** `2025-09-25T13:02:59.543Z`

---

### 🆕 New Features
- Added new methods to **PostProcess**: `SetGlobalGain()`, `SetGlobalGamma()`, `SetGlobalContrast()` and `SetGlobalOffset()`.

### ⏫ Improvements
- More Trigger improvements, we've improved the validation by only iterating the exact list of the whitelist classes entities when checking for the overlaps, greatly improving it's overall loop performance.
- Now calling AddAttached StaticMesh/SkeletalMesh will add the ID to it's Component Tags list.

### 🔨 Bug Fixes
- Fixed PostProcess effects not applying when possessing an already spawned character.
- Fixed Attachables not being stored in order which they were added.

# nanos world - Version 1.45.7

- **Release Date:** 2023-04-02 17:40:34 UTC
- **Raw Timestamp:** `2023-04-02T17:40:34.253Z`

---

⏫ **Improvements**
- The last added feature which removed old/deleted assets from client folders was rollbacked. It was causing unforeseen consequences.
- Implemented new File path handlers to fix files not being able to load/write if the path was bigger than 260 characters (windows limitation). This was a big change, lets keep an eye out for issues or bugs.
- Improved the scripting file casing checker, it will now also identify bad case sensitivity when loading files from Package.Require, and also folders casings (this is not an issue on Windows, but if you move your package to Linux, your Package may not work properly, this system helps by warning if you try to load a File with incorrect casing).

🔨 **Bug Fixes**
- Fixed default map using the deprecated name on Package.toml.
- Fixed a bunch of typos.

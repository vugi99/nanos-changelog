# nanos world - Version 1.108.0

- **Release Date:** 2026-02-19 12:15:10 UTC
- **Raw Timestamp:** `2026-02-19T12:15:10.000Z`

---

### Note: this update brings some breaking changes: if you use Rotator:Rotate/UnrotateVector(), please update your code accordingly.

### 🆕 New Features
- Added new method [`Player.SetVOIPLocalMaxDistance()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/player#function-setvoiplocalmaxdistance).
- Added new method [`Package.IsUnloading()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/package#static-function-isunloading).
- Added new methods to [**Quat**](https://docs.nanos-world.com/docs/next/scripting-reference/structs/quat#functions): `UnrotateVector()`, `RotateVector()`, `GetForwardVector()`, `GetRightVector()` and `GetUpVector()`.
- Added new method to [**Vector**](https://docs.nanos-world.com/docs/next/scripting-reference/structs/vector): `ToOrientationQuat()` and `ToOrientationRotator()`. `:Rotation()` was deprecated in favor of `:ToOrientationRotator()`.
- Now [`Package.SetPersistentData()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/package#static-function-setpersistentdata) supports passing keys separated by `.`, allowing overriding just a child property of an existing table value.

### ⏫ Improvements
- Improved spawning/destroying entities efficiency by reducing some extra internal containers usage. **Please let us know if you experience any bug or weird thing.**
- Now trying to spawn an entity while the Package is unloading will throw an error, as everything is tearing down. Use `Package.IsUnloading()` inside Destroy events to prevent the errors.
- Now scripting errors will strip the stack trace when being displayed as notifications.
- Improved scripting errors formatting (was having extra spaces).
- Improved scripting structs (Vector, Rotator...) tostring output format.
- Reduced max depenetration force on objects, making them less prone to "exploding" if spawning overlapping.

### 🔨 Bug Fixes
- Fixed Rotator `UnrotateVector()` and `RotateVector()` being inverted. If you use those methods, **you must update your code and invert them!**
- Fixed potential crashes when spawning/destroying entities from some scripting events callbacks (e.g. "Spawn", "Destroy", "Capture", "Begin/EndOverlap").
- Fixed some entities not being cleaned when changing dimensions, causing crashes.
- Fixed not being able to launch multiple game instances, causing infinite loading screen.
- Fixed hash collision Fatal Errors when package reloading multiple times at the same time.

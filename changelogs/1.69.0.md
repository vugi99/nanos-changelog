# nanos world - Version 1.69.0

- **Release Date:** 2025-01-09 09:54:32 UTC
- **Raw Timestamp:** `2025-01-09T09:54:32.000Z`

---

🆕 **New Features**
- Implemented Unreal's new **Enhanced Input System**! It contains breaking changes for scripters, please read the [January News Blog](https://docs.nanos.world/blog/january-2025#enhanced-input-system) to see all the changes.
- Added new **Retry** button when disconnected from servers.
- Enabled Plugins **PoseSearch**, **AnimationWarping**, **MotionWarping** and **Chooser**.

⏫ **Improvements**
- Now Scripting **KeyBindings** shows a label when there are no scripting keybindings assigned.
- Now all temporary files will be stored on **AppData**, and not on local game installation folder anymore.
- Improved main menu **Latest Blog** section, now it links to the latest news blog.
- Updated **FSlateFontInfo** parser to the latest Unreal scheme.
- Now the default spawn location for non possessed players will be **Vector(0, 0, 100)** instead of 0, 0, 0.
- Improved and adjusted **House Keeping** settings tab.
- Improved new game popup overflow title.
- Improved several UI colors and minor design adjustments.
- Improved a lot of log messages.
- Updated **SteamSDK** to 1.61.
- Updated **CEF** to 131.

🔨 **Bug Fixes**
- Fixed a bug causing Linux servers to crash constantly.
- Fixed Achievements texts not loading and typos.
- Fixed CharacterSimple not syncing Attachable or Materialable.
- Fixed .ogg sounds not playing.
- Fixed sounds not playing with auto_play if they are not cached yet.
- Fixed UI Audio Setting not getting right value.
- Fixed PlayerController setting configurations for non local players.
- Fixed client fatal errors related to OnHighlight.
- Attempt to fix Loading Screen crash when using StopMenuMusic event.

# nanos world - Version 1.168.0

- **Release Date:** 2026-11-03 16:30:00 UTC
- **Raw Timestamp:** `2026-11-03T16:30:00Z`

---

### 🆕 New Features
- Added new **Blaster Pistol**, **Blaster Rifle** and **HFG** weapons meshes (removed the old **Blaster** and **DC-15S** assets).
- Added [`SetLODDistanceFactor()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/scenecapture#function-setloddistancefactor) to SceneCapture to control mesh detail in captures.
- Added an optional instigator parameter to Grenade [`Explode()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/grenade#function-explode).
- Added new optional output dimensions parameters to SceneCapture [`EncodeToBase64()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/scenecapture#function-encodetobase64) and [`EncodeToBase64Async()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/scenecapture#function-encodetobase64async).
- The microphone test is now available in the main menu.

### ⏫ Improvements
- We added a new processing for VOIP sounds attempting to improve and normalize all players microphone volume levels. Please let us know any feedback!
- Spectating a Character now applies your field of view setting.
- The **Find Servers** screen now shows servers with the most players in its first tab.
- **Clear All Cache** now shows how much space was freed and refreshes the displayed sizes.
- Improved the error message when a Vault asset pack cannot be installed.
- Improved the **Tool Gun**, **Gravity Gun** and **Puke Gun** mesh assets.
- Deleted (deprecated) Character's `SetAnimationIdleWalkRunProning()` and `SetAnimationsTransitionCrouchingProning()`. These methods no longer have an effect.

### 🔨 Bug Fixes
- Fixed a ragdoll desync when respawning inside the Character's `Death` event.
- Fixed actor translation and rotation not syncing to players who join later when the actor has no network authority.
- Fixed `Server.GetMap()` returning an empty value while the game mode reloads during `package reload all`.
- Fixed a crash in House Cleaning when a folder could not be scanned.
- Fixed **Clear All Cache** reporting an error for the log file currently in use.
- Fixed the server list appearing empty and fixed the connecting tooltip count.

### 🌐 Account, Store & Websites.
- Attached images in discussions (feedback/bugs/support) now open in a gallery that supports arrows, keyboard navigation and swipes.
- Improved the team creation flow and added the ability to upload a team icon during creation.
- Fixed an error when fetching game jam votes.

# nanos world - Version 1.151.0

- **Release Date:** 2026-08-10 13:32:21 UTC
- **Raw Timestamp:** `2026-08-10T13:32:21.374Z`

---

### 🆕 New Features
- Added [`EnterWater`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#event-enterwater) and [`LeaveWater`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#event-leavewater) events to `Actor` (and its subclasses — Character, Vehicle, Prop, etc.), fired when the actor enters or leaves a body of water.

### ⏫ Improvements
- Updated DLSS to **8.7.2**.
- We've got a big refactoring internally. Please let us know if anything behaves abnormally.

### 🔨 Bug Fixes
- Fixed a crash that could occur when kicking a player.
- Fixed a crash when creating a new `Timer` from within another `Timer`'s callback.
- Fixed a crash caused by heap corruption in the Lua scripting stack when passing too many tables with deep values.
- Fixed a crash when a C module failed to load.

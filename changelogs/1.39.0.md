# nanos world - Version 1.39.0

- **Release Date:** 2023-03-04 21:08:19 UTC
- **Raw Timestamp:** `2023-03-04T21:08:19.000Z`

---

🆕 **New Features**
- Added new methods to **Trace**: `SphereSingle()`, `SphereMulti()`, `BoxSingle()`, `BoxMulti()`, `CapsuleSingle()` and `CapsuleMulti()`.
- Added several new methods to **Sky** to manipulate Moon, Sun and Clouds parameters!

⏫ **Improvements**
- We reworked some parts of the **File Transfer** system internally, fixing some bugs and making some improvements on it's internal configuration. Downloading "small" files should be technically faster now. Let's keep an eye on for bugs or weirdness happening!
- We did several deep changes on the **Network Layer** of the framework. Now VOIP and File Transfers use a low-priority network lane to transmit it's data, meaning it will reduce the performance impact on the game-play when players are joining or talking in VOIP - as those use huge amounts of network data.
- Now the server handles **File Transfers** asynchronously! Meaning no more stutters/tick too high when players are joining the server!
- The Network file sizes Debug Settings were adjusted with new values.
- Now players will be kicked from the server is a file failed to transfer during loading or package reloading, preventing chaos from proceeding as they will have invalid/corrupted files locally.
- Now **.ogg** sounds are loaded asynchronously!

🔨 **Bug Fixes**
- Fixed a bug with TOML and JSON parsers identifying Vector, Rotator, Vector2D in texts wrongly.
- Fixed server using 250 MB unecessarily "forever".
- Fixed a bug when using P2P servers causing Fatal errors on console due Limit Exceeded when players are downloading files.
- Fixed Character MoveTo still working even if the Character is dead/ragdoll.

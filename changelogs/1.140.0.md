# nanos world - Version 1.140.0

- **Release Date:** 2026-05-25 13:58:57 UTC
- **Raw Timestamp:** `2026-05-25T13:58:57.427Z`

---

### 🆕 New Features
- Added a new setting **Mic Test** button (available when in-game).

### ⏫ Improvements
- Now **Dimensions** can support up to `4,294,967,295` values (increased from `65,535`).
- Deleted useless `dimension` parameter from `Client::GetActorsInRadius()`.
- Added debug dimensions change logs.

### 🔨 Bug Fixes
- Fixed some Debug widgets not showing/hiding when saving settings.
- Fixed dimension change not resetting the network authority properly, causing clients to do not receive the net. authority.
- Fixed **CEF** internal focus/unfocus on elements not being handled properly.
- Fixed **CharacterSimple** not being able to move after detaching (due getting simulate physics enabled).
- Fixed **Characters** stop firing when unaiming (pressing right click). And several other aiming/unaiming issues when using "hold to aim" setting.
- Fixed **Characters** not crouching after jumping or landing while still holding crouching key.

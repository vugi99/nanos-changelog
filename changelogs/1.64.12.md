# nanos world - Version 1.64.12

- **Release Date:** 2024-03-16 12:49:42 UTC
- **Raw Timestamp:** `2024-03-16T12:49:42.018Z`

---

🆕 **New Features**
- Added new method to **Sound**: `GetPath()`.
- Added new method to **Widget3D**: `GetWidget()`.

⏫ **Improvements**
- Now Blueprint parameters supports passing nil values (it will be defaulted to the default zeroed variable value, e.g. 0 or empty strings).
- Now the client will reconnect if the server reloads packages while it was in loading screen, making sure it always gets the updated version of the packages.
- Now Vault temporary downloaded files will be deleted if something goes wrong during the download (zip files were remaining forever in the disk).

🔨 **Bug Fixes**
- Fixed Escape Menu Low Pass Filter remaining active after being disconnected.
- Fixed CharacterSimple:SetJumpZVelocity not working.
- Fixed Input OnKeyBindingChange event passing wrong binding_name parameter.

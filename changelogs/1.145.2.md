# nanos world - Version 1.145.2

- **Release Date:** 2026-07-01 18:10:33 UTC
- **Raw Timestamp:** `2026-07-01T18:10:33.288Z`

---

### 🆕 New Features
- Added new information to the **Profile** Screen: **Last Seen**, **Join Date**, **Country** and **Biography**. You can also edit your Biography in the manage tab.

### ⏫ Improvements
- Now you can return a number to `TakeDamage` event, working as a multiplier to the final damage.

### 🔨 Bug Fixes
- Fixed Character not returning precise location from GetLocation when inside a vehicle, now it will consider the relative seat location.
- Fixed TakeDamage event not being processed on client sides if the client event handler script returned false, causing desyncs.

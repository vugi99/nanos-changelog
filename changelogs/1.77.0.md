# nanos world - Version 1.77.0

- **Release Date:** 2025-04-22 11:13:26 UTC
- **Raw Timestamp:** `2025-04-22T11:13:26.000Z`

---

### ⏫ Improvements
- Implemented a new super fast and reliable hash library, fixing hash collisions fatal errors and loading an caching files are now 2x faster!
- Disabled TranslateTo and RotateTo on Trigger entity, as it was not supposed to work.
- Now TranslateTo and RotateTo will throw warnings if the entity is not network distributed or has no network authority to apply the interpolation.
- Improved some Actor warnings now telling what is the entity.
- Offroad Vehicle physics has been reworked and will not fly away when the tire hits objects.
- Improved the Buoyancy algorithm to determine the buoyancy radius to apply to objects, it should fix objects from sinking.
- Now Debugging Network on Screen will paint Network Authority sleeping as blue and cyan if it's actively sending data to server.

### 🔨 Bug Fixes
- Fixed Password PopUp not showing up in front of other widgets.
- Fixed Retry button when failed to connected to server not working.
- Fixed Vehicle Steering Setup not being applied properly.
- Fixed default-testing-map spawn locations of weapons and boat, causing physics issues.

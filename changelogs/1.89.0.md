# nanos world - Version 1.89.0

- **Release Date:** 2025-10-03 11:45:00 UTC
- **Raw Timestamp:** `2025-10-03T11:45:00.607Z`

---

### 🆕 New Features
- It's 🎃 **Halloween** time! The Main Menu has been updated with a special theme!
- Added new methods to **Widget**: `SetSlotAlignment()`, `SetSlotPadding()` and `SetSlotSize()`. Also renamed `SetSlotCanvasLayout()`.
- Added new method to **Character**: `SetCanUsePickables()`.
- Added new method to **Pickables**: `SetCanUse()`.
- Added a bunch of new animations from Bossy Enemy Animation Pack.

### ⏫ Improvements
- Now all Package's client .lua files are encrypted to prevent them from being easily read on client's machine.
- Now the server will load and cache the client scripting files with multi-threads, improving a lot the load time when caching a lot of client scripting files.

### 🔨 Bug Fixes
- Fixed MoveComplete event not being called for CharacterSimple.
- Fixed the server allowing to runtime load Loading Screen packages with 'package load' - it doesn't work.
- Fixed the server not caching some client information, making it to reload and parse all data every time a Player connects.
- Fixed loading animations not working sometimes.

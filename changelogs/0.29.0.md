# nanos world - Version 0.29.0

- **Release Date:** 2020-06-28 12:55:24 UTC
- **Raw Timestamp:** `2020-06-28T12:55:24.924Z`

---

**New Features**
*  New Entity: ``Light``! You can now spawn dynamic lights with scripting. Please refer to https://docs.nanos.world/scripting/classes/Light.html for more information
*  New ``Ladders``! Now it is possible to climb stuff vertically (yet ugly). For map/level creators in Unreal: just create a ``Box Trigger`` actor with an **Actor Tag** named ``Ladder`` and ladder functionality will work in-game!

**Improvements**
*  We've disabled Planar Reflections on the whole game, which was causing 15% performance drop.
*  We did some internal changes on the server process which will potentially decreases the "server low performance" warnings and issues.

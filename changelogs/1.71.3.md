# nanos world - Version 1.71.3

- **Release Date:** 2025-02-08 09:16:39 UTC
- **Raw Timestamp:** `2025-02-08T09:16:39.503Z`

---

🆕 **New Features**
- New Networking Stats Profiling Tool. Please read the [February News Blog](https://docs.nanos.world/blog/february-2025#network-stats) for more information.

⏫ **Improvements**
- The Unreal Engine Version has been updated to 5.5.3. This update shouldn't break any asset cooked.
- Improved the Character interpolation synchronization. Please read the [February News Blog](https://docs.nanos.world/blog/february-2025#network-stats) for more information.
- Implemented a cache system for the Vault API, reducing the time load. Please read the [February News Blog](https://docs.nanos.world/blog/february-2025#network-interp-stutters) for more information. You can disable it in the Advanced section in the settings.
- Cables are now attached to mesh if a bone name is passed as parameter.
- Deleted Streaming Pool Size in the settings as it was not being used internally.
- We reworked our Settings system internally, all current settings will be reset to the default value. If you notice any bug or problem please let us know.

🔨 **Bug Fixes**
- Fixed Main Menu labels without text.
- Fixed Attached Skeletal meshes flickering when base mesh is small or invisible.
- Fixed Version Bar not appearing on the in-game menu and loading screen.
- Fixed recursive tables crashing the game/server when passed as parameters to Events or internal methods.
- Fixed crash when the scripting is not able to find the current package (due tail calls), the scripting will throw and error and prevent the execution now in those situations.

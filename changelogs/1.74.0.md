# nanos world - Version 1.74.0

- **Release Date:** 2025-03-15 10:59:47 UTC
- **Raw Timestamp:** `2025-03-15T10:59:47.754Z`

---

We are updating the default steam branch with the latest bleeding-edge version 1.73, the current default version 1.70 (with Unreal 5.4) is being moved to a new steam branch called `1.70.2`.

## 🆕 New Features
- Unreal Engine was updated to version 5.5.4.
- Added new method [`Pawn:SetAIAvoidanceSettings(enabled, consideration_radius)`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#function-setaiavoidancesettings)
- Implemented real CEF native Smooth Scrolling (we had a fake implementation).
- [`Set/GetGravityScale`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#function-setgravityscale) was moved to Pawn (CharacterSimple can officially used it now).
- Profiling now displays Average, Total and Call Count.

## ⏫ Improvements
- Drastically improved the game performance by disabling some entities and built-in map actors (on testing-map) that were constantly requiring the re-generation of the navmeshes (default-testing-map could double the FPS).
- Several other performance improvements were made, reducing unused tick calls, disabling unecessary components, and reduced some code that were causing performance drain. Please let me know if anything weird start happening.
- Added a global toggle setting for DLSS.
- Organized the "Debug" settings tab with a new Gameplay Debug section.
- Now unticking Profiling settings in the "Debug" tab will also disable the Network Overlay setting to be selected.
- Improved the layout of Profiling overlay screen, also non-used entities will not show on network usage list.
- Now CharacterSimple will have the same PushForce and StandingForce used by Character.
- Improved the 'fly by' bullet sounds, making it louder and more noticeable when other characters fire in your direction.
- Added the 'Unreal global Tick' time to our Profiling list.

## 🔨 Bug Fixes
- Fixed the video Resolution Scale setting not working.
- Fixed a bug causing Quaternions being zeroed to wrong value, causing wrong rotations being sent through network (causing characters and entities fliping in some situations).
- Fixed `Events.Unsubscribe()` infinite loop occurring when multiple events with the same name were registered.
- Fixed serialization infinite loop causing a crash when passing recursive tables to remote events (they will be emptied now).
- Fixed Character SetGravityEnabled warning always appearing.

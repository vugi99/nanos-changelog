# nanos world - Version 1.109.0

- **Release Date:** 2026-02-22 13:01:17 UTC
- **Raw Timestamp:** `2026-02-22T13:01:17.315Z`

---

### 🆕 New Features
- Moved [IsBeingDestroyed](https://docs.nanos-world.com/docs/scripting-reference/classes/base-classes/entity#function-isbeingdestroyed), [HasAuthority](https://docs.nanos-world.com/docs/scripting-reference/classes/base-classes/entity#function-hasauthority) from **Base Actor** to **Base Entity**. Now all entities can use those methods.
- Added a new Return to **Trace**: [`TraceMode.ReturnItem`](https://docs.nanos-world.com/docs/next/scripting-reference/glossary/enums#tracemode) which returns a `Item` value, usually representing an Instanced primitive index (e.g. from Instanced Static Meshes).

### ⏫ Improvements
- **A huge refactoring was made internally, affecting all entities and critical paths, bringing big performance and memory usage improvements, from scripting method calls to networking serialization and invokes. If you find anything weird or any desync please let us know immediately!**
- Now when an entity is created or when a player joins the server, the entity construction data will be compressed (if server is using compression), greatly reducing the network usage.
- Now using `--log_show_thread` will display the thread names (instead of IDs).
- Updated Sentry to version 1.7.

### 🔨 Bug Fixes
- Fixed potential server memory leak when broadcasting network packets.

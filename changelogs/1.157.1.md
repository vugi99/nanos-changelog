# nanos world - Version 1.157.1

- **Release Date:** 2026-09-29 15:59:19 UTC
- **Raw Timestamp:** `2026-09-29T15:59:19.649Z`

---

### ⏫ Improvements
- Now [`GetSocketTransform()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-getsockettransform) also returns the socket's `Scale`.
- CEF's (WebUI) accelerated painting was rewritten fixing several bugs and improving performance. Please let us know if something breaks!
- Improved the Playtest/Game connection warning, including a timeout warning to help people starting the server with the correct parameters.

### 🔨 Bug Fixes
- Fixed loading cooked textures (e.g. from `SetMaterialTextureParameter()`) not working if they weren't already loaded before.
- Fixed a crash when closing the game while WebUI was playing sounds.
- Fixed CEF not loading with the correct main GPU when being loaded on laptops with a dual GPUs.
- Fixed menu crashes due images not being downloaded correctly.

### 🌐 Account, Store & Website
- Now support threads support attaching images. Also improved the overall support threads layout.
- Added new details and profile cards for Projects, Resources, Teams and Users when hovering the cursor over them across the site.
- Added new "Create Project / Resource / Team" buttons to store/community pages.
- Store resources pages now show other packages that require them (dependents).
- Redesigned the navbar dropdowns when hovering them.
- Improved the website load performance and speed.
- Fixed teams not being able to remove the description.
- Fixed rating rounding.
- Several other minor improvements and bug fixes.

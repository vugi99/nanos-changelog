# nanos world - Version 1.150.0

- **Release Date:** 2026-08-07 10:42:30 UTC
- **Raw Timestamp:** `2026-08-07T10:42:30.384Z`

---

### 🆕 New Features
- Added new [`SetBuoyancySettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-setbuoyancysettings) and [`SetBuoyancyPontoons()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-setbuoyancypontoons) for **Prop**, **Pickable** and **Vehicle**.
- Added new [Vector2D](https://docs.nanos-world.com/docs/next/scripting-reference/structs/vector2d#functions) function helpers.

### ⏫ Improvements
- Now **HTTP** return the `headers` on [`.Request()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/http#static-function-request) and [`.RequestAsync()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/http#static-function-requestasync).
- Now the server browser will only display Playtest servers if on Beta version (not the vice-versa anymore).

### 🔨 Bug Fixes
- Fixed `custom_settings` not parsing the description correctly from .toml.
- Fixed a crash when loading packages.
- Fixed Character keeping the camera rotation broken when changing views.

# nanos world - Version 1.120.3

- **Release Date:** 2026-03-30 20:13:11 UTC
- **Raw Timestamp:** `2026-03-30T20:13:11.422Z`

---

### 🆕 New Features
- Added a new *experimental* `Ray Tracing` video setting, that will enable `Hardware Ray Tracing` and `Megalights` if enabled. Allowing you to disable Ray Tracing completely if you want. Also all ray tracing related settings will be disabled if your system doesn't support it.

### ⏫ Improvements
- Now console commands have trailing white-spaces trimmed automatically.
- Reworked our internal requirements list (all downloadable assets, script files and assets to load) transfer to clients when they connect. Now they are cached more efficiently and the server will re-generate it way less often. Also the File Transfer system will be used to transmit, reducing overall networking issues of sending too much data at once.

### 🔨 Bug Fixes
- Fixed `Server.SetName()`, `Server.SetDescription()`, `Server.SetPassword()` and `Package.SetPersistentData()` corrupting .toml files if passing unescaped double quotes.
- Fixed `BaseActor.SetVisibility()` not working properly as it was also setting to all attached unreal components on client side, causing desyncs for later connected players. Now it will only affect the Actor itself and all it's Attached SkeletalMeshes/StaticMeshes.
- Fixed connecting while already connected making the client to open the main menu but still connect in the background.

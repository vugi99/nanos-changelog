# nanos world - Version 1.102.0

- **Release Date:** 2026-01-16 16:42:24 UTC
- **Raw Timestamp:** `2026-01-16T16:42:24.000Z`

---

### 🆕 New Features
- Added a new method to **VehicleWheeled**: `IsInAir()`.
- Added a new method to **BaseActor**: `AddAngularImpulse()`.
- Added a new parameter to **CharacterSimple:SetSpeedSettings**: `max_fly_speed`.
- Now `SetFlyingMode()` belongs to **BasePawn** (Added `SetFlyingMode` to **CharacterSimple**).
- Added a new **Rocket Thruster Exhaust** particles Asset Pack.
- Added new methods to **Paintable**: `GetMaterialVectorParameter()`, `GetMaterialColorParameter()`, `GetMaterialScalarParameter()` and `GetMaterialTextureParameter()`.
- Added new methods to **Prop**: `Set/GetMassOverride()` and `Set/GetMassScale()`.
- Added a new parameter to **Hit** event: `other_actor`, the other actor that hit the actor.

### ⏫ Improvements
- Now `M_Default_Translucent_Unlit_Depth` will render after motion blur. Useful for Billboards.
- Now saving your profile will throw error if username not in 2-32 characters range.
- Now VOIP data is only transmitted to players that are near 30 meters (if only transmitting to local channel).
- Updated all Explosion particles to latest Fab version.

### 🔨 Bug Fixes
- Attempt to fix entities syncing not snapping if network distance error is too big.
- Attempt to fix the nanos world process staying alive after closing the game.
- Fixed --use_vault_assets_lean not working, but you must re-upload your Asset Packs for the backend be able to parse it properly to make it work.
- Fixed Players that aren't possessing having network sync issues.
- Fixed the server closing when starting from in-game if the client freezes for +20 seconds while loading.
- Fixed Profiling list not displaying Player data.
- Fixed crash when creating a local resource.
- Fixed server closing if trying to change the map with `map` console command if the map didn't exist.
- Fixed Vault parsing empty folders (without .toml).
- Fixed nul scripting files causing errors when joining a server.
- Fixed TOML generator creating keys with empty spaces, invalidating the TOML. Now keys with spaces will be automatically escaped with quotes.
- Fixed attaching a Prop while it's asset is still loading, making it to not attach properly.
- Fixed attached entities losing attachment when changing a Prop/StaticMesh mesh in runtime (with SetMesh).
- Fixed destroyed entity returning nil when calling IsA(...), now it returns false.

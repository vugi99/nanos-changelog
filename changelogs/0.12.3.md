# nanos world - Version 0.12.3

- **Release Date:** 2020-05-12 14:20:18 UTC
- **Raw Timestamp:** `2020-05-12T14:20:18.053Z`

---

**New Features**
*  New client scripting function: **Client.SetOutlineColor(Color)**. For setting the global value of the outline color.
*  Added a proper and prettier **icon** for NanosWorldServer.exe :)

**Improvements**
*  Improvements on **Grabbing Props**, it is not perfect yet but the handling of objects (rotating it) was improved and should work better.
*  Server Owners: Added some **validations for Config.toml** (eg. Maximum/Minimum Players, Valid Ports Range)
*  Server owners: Now **HTTPPort** and **Port** can have the same value, also the default value for both is now **7777**. You can now set both to 7777 and just forward one Port (UDP/TCP).

**Bug Fixes**
*  Fixed a big bug causing Linux server not work properly in some cases (for example: Props not being able to be grabbed)

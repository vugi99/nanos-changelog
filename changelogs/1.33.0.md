# nanos world - Version 1.33.0

- **Release Date:** 2023-02-02 10:00:28 UTC
- **Raw Timestamp:** `2023-02-02T10:00:28.636Z`

---

🆕 New Features
- Now it is possible to add custom Console Commands! They get natively integrated with the terminal and to the commands list when entering `help`.
- New Server Console layout! The Server colors and format were completely redesigned! Colors everywhere!
- Now it is possible to Bind for Axis Inputs!
- Now Input events will return the Delta value if the input is an Axis (-1.0 ~ 1.0).
- Now the Main Menu will display a balloon telling the game has a new update available.
- Added a new command line parameter: `--log_show_thread` to display the thread that log was generated (was enabled automatically when Verbose logs).

⏫ Improvements
- WebUI:IsVisible() was superseded by WebUI:GetVisibility(), returning an Enum now.
- Input.GetMappedKey() was superseded by Input.GetMappedKeys(), returning a list of Keys now.
- Now Input.GetGameKeyBindings() and Input.GetScriptingKeyBindings() return a map of tables (was map of strings) containing all Keys bound to a Binding. You must update your package to latest (1.33) Compatibility Version to enable this new behavior.
- The log buffer was increased from 8KB to 16KB.

🔨 Bug Fixes
- Fixed Character.ResetMaterial() not working.

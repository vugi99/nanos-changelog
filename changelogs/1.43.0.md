# nanos world - Version 1.43.0

- **Release Date:** 2023-03-19 12:34:00 UTC
- **Raw Timestamp:** `2023-03-19T12:34:00.913Z`

---

🆕 **New Features**
- Now **Melees** supports damaging multiple actors in the same Hit "action".
- Now **Melees** will use Attached Static Meshes as colliders when damaging.

⏫ **Improvements**
- Now the Loading Screen will display the current small step download progress (for each http, sockets and asset packs files being downloaded).
- Now the Loading Screen will display the Installation progress when downloading Assets from Vault.
- Now the Loading Screen will display more information in the Validating Step.

🔨 **Bug Fixes**
- Fixed some internal Vector parameters using 1 decimal precision instead of 2 (case of Scale and Relative Locations).
- Fixed File Transfer downloading Assets from Vault crashing the game sometimes due using wrong size amount data.
- Fixed File Transfer Assets step not moving forward after finishing the download.

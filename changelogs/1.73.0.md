# nanos world - Version 1.73.0

- **Release Date:** 2025-03-10 11:34:36 UTC
- **Raw Timestamp:** `2025-03-10T11:34:36.602Z`

---

## 🆕 New Features
- Added a new method to retrieve if a package is loaded: [`Client.IsPackageLoaded()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/client#static-function-ispackageloaded) and [`Server.IsPackageLoaded()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/server#static-function-ispackageloaded). [See blog news](https://docs.nanos.world/blog/march-2025#ispackageloaded).
- Added [`Server.KickByAccountID()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/server#static-function-kickbyaccountid) and [`Server.BanByAccountID()`](https://docs.nanos.world/docs/next/scripting-reference/static-classes/server#static-function-banbyaccountid). And now returning false from PlayerConnect event is deprecated. [See blog news](https://docs.nanos.world/blog/march-2025#playerconnect-event).
- Added Network Invokes Profiling. [See blog news](https://docs.nanos.world/blog/february-2025#network-invokes).
- Added Network Stats logs to server logs. [See blog news](https://docs.nanos.world/blog/february-2025#network-stats).

## ⏫ Improvements
- Added the actual Unreal version to server logs when starting the server and to the bottom of the game screen.
- Updated to DLSS 4. Frame Generation should be back working.
- Removed depenetration force applied when two meshes are overlapping, fixing recent bugs causing props to behave erratically (e.g., flying/exploding around).
- `Character.GetBoneTransform()` is now [`Actor.GetSocketTransform()`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/actor#function-getsockettransform) and supports Bone/Socket. [See blog news](https://docs.nanos.world/blog/march-2025#actorgetsockettransform).
- Added [`Pawn.GetCapsuleSize()`](https://docs.nanos.world/docs/next/scripting-reference/classes/base-classes/pawn#function-getcapsulesize). [See blog news](https://docs.nanos.world/blog/march-2025#pawngetcapsulesize).
- Verbose logs now indicate which package spawned an entity.
- Improved Vehicle creation internally to be more optimized, nothing should be affected, but if you notice anything weird, please let us know.

## 🔨 Bug Fixes
- Fixed `.ogg` sounds not being able to rewind and removed related warnings.
- Fixed some settings not applying immediately after saving (e.g. Profiling Tools).
- Fixed DNS Lookup not resolving URLs passed as IP.
- Profiling Benchmark now tracks Canvas Draw, Canvas Repaint and Individual Assets loading.
- Fixed News Blog not fetching the correct Date in the main menu.

# nanos world - Version 0.19.0

- **Release Date:** 2020-05-25 12:20:45 UTC
- **Raw Timestamp:** `2020-05-25T12:20:45.31Z`

---

**New Features**
*  New Scripting namespace: `Timer`, with functions: `SetTimeout` and `ClearTimeout` to set and create timers! Please refer to our documentation: https://docs.nanos.world/scripting/global-variables/Timer.
*  New **Weapon sounds**! We've added some more weapons sounds, including Glock, Desert Eagle, AR4 and AP5! Please update your https://github.com/nanos-world/nanos-world-weapons package!
*  Now when you get hit, a **Camera Shake** effect will happen to improve our hit feedback, headshots will cause a bigger shake.

**Improvements**
*  We've improved a bit the **Bullet Trace effect**, also increase it's velocity on nanos-world-weapons package to fit better the animation.

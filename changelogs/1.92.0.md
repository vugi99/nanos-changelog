# nanos world - Version 1.92.0

- **Release Date:** 2025-10-16 16:01:27 UTC
- **Raw Timestamp:** `2025-10-16T16:01:27.227Z`

---

### 🆕 New Features
- Added a new default material: `M_Default_Masked_Lit_WorldAligned`, with the scalar parameter `TextureSize`.
- Added new scalar parameters to `M_Default_Masked_Lit`'s materials: `VTiling` and `UTiling`.
- Included the FPS Animation Pack Plugin (C++ code only).

### ⏫ Improvements
- Now Network Authority distributor will only iterate actors that distribute the network authority, improving the overall server performance when having too many actors spawned.
- Now Trigger will show a warning when not passing overlap_only_classes parameter.
- Added a new Profiling entry for 'During Physics Tick' time.
- Added new and updated the game achievements.
- Improved several UIs, making them less complex and rendering efficient.
- Improved Character TIP animations.
- Improved impulse applied when Characters take damage.
- Slightly improved Rotation sync precision.
- Removed the "locked" anim state when aiming with a Melee (it will stay only when aiming with the fists).

### 🔨 Bug Fixes
- Fixed Sky.SetMoonTexture() crashing the game.
- Fixed Characters not animating idle when in first person.

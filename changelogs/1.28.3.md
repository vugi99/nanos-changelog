# nanos world - Version 1.28.3

- **Release Date:** 2023-01-16 09:51:14 UTC
- **Raw Timestamp:** `2023-01-16T09:51:14.200Z`

---

**Improvements**
- Now loading an Asset Path with reserved **UnrealPath** names (NanosWorld, NanosWorldMaps, etc) will throw an error and the Asset Pack will not be loaded.
- Now **Level** StreamLevelLoad/StreamLevelUnload events will also be triggered for World Partition and for automatic load/unload from streaming distance.
- Now **StaticMesh** entities from stream levels (including World Partition) will be properly created/destroyed when it gets visible/hidden - potential crash fixes.
- Added two new events to **Level**: `StreamLevelShow` and `StreamLevelHide`.

**Bug Fixes**
- Fixed StaticMesh & Props collision sync.
- Fixed a random Main Menu crash.
- Fixed Vault Uninstall not re-enabling Start Game button.
- Fixed Asset Packs not unmounting when unloaded.
- Attempt to fix Server Favorites not persisting.

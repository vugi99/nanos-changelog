# nanos world - Version 0.8.0

- **Release Date:** 2020-04-30 17:28:51 UTC
- **Raw Timestamp:** `2020-04-30T17:28:51.186Z`

---

**New Features**
*  Added new Events to `Character`: `GaitModeChanged`, `FallingModeChanged`, `RagdollModeChanged`, `StanceModeChanged`, `SwimmingModeChanged`, `ViewModeChanged`, `WeaponAimModeChanged`, `Punch`
*  Added new Functions to `Character`: `GetWeapon()`, `GetItem()`, `GetGrenade()` (I don't like these multiple methods as well, in the future we will try to reduce it to only 1)
*  Added new Function to `Grenade`: `Explode()`
*  Added new Functions to `Prop`: `SetGrabbable()` and `IsGrabbable()`
*  Added new Event to `Vehicle`: `Horn`

**Improvements**
*  We went further in our overhaul and we've refactored more internal code, these changes will significantly improve the performance of both Client and Server
*  We are starting to release the game as a Shipping version, so the Unreal's built-in console should be gone. We've also added `Quote` and `Apostrophe` as keys to open the console. Let's see if it works =D

**Bug Fixes**
*  Fixed (some primitive) Props and Characters colors not being set by `SetTintColor`
*  Fixed File Transfer not updating the client files (it was a problem with our Hash generator)
*  Attempt to fix Setting Location of Actors, causing them to keep the velocity after teleporting (this may break Vehicle's SetLocation - please check)
*  Fixed `World` and `Render` stopping working after reloading a package

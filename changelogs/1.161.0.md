# nanos world - Version 1.161.0

- **Release Date:** 2026-10-21 14:40:00 UTC
- **Raw Timestamp:** `2026-10-21T14:40:00Z`

---

### 🆕 New Features
- Added [`Sky.SetMoonMaterialColor()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/sky#function-setmoonmaterialcolor) and [`Sky.SetMoonLightColor()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/sky#function-setmoonlightcolor).
- Added [`Actor.SetImpulseOnDamage()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-setimpulseondamage) and [`Actor.IsImpulseOnDamage()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-isimpulseondamage).
- Added [`Actor.RotateRelativeTo()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-rotaterelativeto) and [`Actor.TranslateRelativeTo()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-translaterelativeto).
- Added [`Pickable.SetPickable()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pickable#function-setpickable).
- Added a new **PlayTypingSounds** audio setting, to mute the typing sound on native inputs.
- The `default-testing-map` is now a package in the [Vault](https://nanos-world.com/store/packages/default-testing-map/).

### ⏫ Improvements
- We reworked our runtime audio loading (.ogg), they are now decoded in real time by the engine, reducing its file size in memory (fixing several out of memory crashes), fixing other several issues and bugs too. Please let us know if you see any issue (or stutter when loading) with .ogg.
- Now sound, particle, crosshair, parachute texture and physics asset setters accept `nil` or an empty string to clear the asset, and `SetPhysicsAsset`, `SetDeathSound` and `SetPainSound` no longer log an error for it. Clearing a Physics Asset or Parachute Texture restores the default.
- Now Physics "Hit" event is not longer flooded when resting contacts happen, saving a lot of performance when having several props spawned.
- Now Buoyancy only ticks while a body is awake.
- Now Weapons will stop updating when sleeping.
- Now `MoveTo` while a Pawn is flying moves directly without path finding.
- Now NPC Pawns use acceleration for paths.
- Now the default server `SendRate` is 2MB/s and the client side limit is up to 512 kb/s (from 256 kb/s).
- We improved the server tick timer to be more precise on Windows.
- Improved several native sounds attenuation reducing the amount of channels being used at the same time for things such footsteps, breathing, buttons, pickups, shell drops, weapon handling, etc.

### 🔨 Bug Fixes
- Fixed Music sounds player priority.
- Fixed sounds attenuation overriding other sounds being spawned using the same asset.
- Fixed `IgnoreOnlyPawn` collision channel not working properly.
- Fixed already loaded assets not being cached properly, skipping Unreal caching and being laoded again.
- Fixed `GetActorsInRadius` never returning anything when passing an empty `only_classes`.
- Fixed `Sky.SetFog` not overriding when a UDWeather actor was spawned.
- Fixed ragdoll jitter and camera flicker when the Character mesh is hidden or off screen.
- Fixed a crash on AMD GPUs under Proton caused by Streamline latency markers.
- Fixed a crash when duplicating montages.
- Fixed SpotLight default rotation not applying.
- Fixed Decal not updating when its size changes.
- Fixed Cable not updating segments properly, causing crashes sometimes.
- Fixed Text3D not updating its material properly.

### 🌐 Account, Store & Website
- New [**Content Guidelines**](<https://nanos-world.com/guidelines>) page, with tips and recommendations when creating your resources or projects.
- Fixed broken docs links duplicating `docs/next`.

# nanos world - Version 1.8.0

- **Release Date:** 2022-05-24 20:28:17 UTC
- **Raw Timestamp:** `2022-05-24T20:28:17.895Z`

---

**New Features**
* Added new **Character** method: `SetSimulatePhysics()` (will disable movement and enable capsule physics).
* Added new method to **NanosMath**: `RelativeTo()`.

**Improvements**
* Added Recoil sync to weapons.
* Disabled the sync with attached/grabbed/picked entities to improve the performance and the network usage.
* Improved Vehicle Engine sounds curve.
* Increased new colored Console font size.
* Re-enabled CCD on small props.

**Bug Fixes**
* Fixed Vehicles hand wheel position on some meshes (now it uses Control Rig).
* Fixed a problem causing the double of blood and sounds happening when taking damage on controlling character.
* Fixed weapons magazine being invisible after aborting the reload.
* Fixed new Console file link.
* Fixed not spawning blood when falling.
* Fixed weapons sync rotation (again).
* Fixed some sync not cancelling (causing objects teleporting back to the original location with physics gun for example).
* Fixed other characters uncrouching causing a flickering.
* Fixed sleeping entities displaying red milliseconds for some time before getting white.

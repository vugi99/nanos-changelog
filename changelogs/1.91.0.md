# nanos world - Version 1.91.0

- **Release Date:** 2025-10-11 16:07:57 UTC
- **Raw Timestamp:** `2025-10-11T16:07:57.000Z`

---

### 🆕 New Features
- Added a new methods to **Character**: `SetRagdollStandUpCooldown()` and `SetRagdollOnHitEnabled()`.
- Added a new method to **BasePawn**: `SetRagdollOnDeathEnabled()`.
- The Character method `SetHitReactionEnabled()` was moved to **BasePawn**.
- Now Characters will float in water when in ragdoll.

### ⏫ Improvements
- **StaticMesh** can now be Network Auto Distributed and have the Network Authority changed with `SetNetworkAuthority()`. The auto change is disabled by default (enable it with `SetNetworkAuthorityAutoDistributed()`).
- Now `SetNetworkAuthority()` and `SetNetworkAuthorityAutoDistributed()` will throw an error if called on not allowed Classes (i.e. classes that don't distribute network authority at all).
- Now the `TakeDamage` event will trigger even if the character is already dead.
- Now passing `blend_out = -1` to `PlayAnimation()` will disable the blend out (keeping the animation in last state forever).
- Adjusted all damageable bones weights on Characters.
- Improved the Character ragdoll sync and interpolation.
- Now Characters can leave the ragdoll even in water (it will skip standing up animation).

### 🔨 Bug Fixes
- Now `IsNetworkDistributed()` correctly returns if the entity "can" be network distributed (even if `SetNetworkAuthorityAutoDistributed()` was set to false).
- Fixed `SetNetworkAuthority()` not allowing to be called if `SetNetworkAuthorityAutoDistributed()` was set to false.
- Fixed CharacterSimple not syncing damage hits effects properly (duplicated or not applying at all), now all damage effect will pass through the server first, fixing sync issues.
- Fixed CharacterSimple not applying impulse when getting damage when ragdoll.
- Fixed radial damage applying too much impulse on Characters in ragdoll.
- Fixed Box Trace with wrong color and rotation when debugging.

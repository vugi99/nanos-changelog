# nanos world - Version 1.22.0

- **Release Date:** 2022-11-29 10:24:19 UTC
- **Raw Timestamp:** `2022-11-29T10:24:19.000Z`

---

**New Features**
- Added new methods to **Actor** base class: `WasRecentlyRendered()`, `GetDistanceFromCamera()`, `GetScreenPercentage()`.
- Added new setting to Package.toml configuration: `compatibility_version`, this must be set to the latest game version (major.minor) which this package works and will be used to grant it keeps working between breaking changes.
- Added new methods for **Events**: `SubscribeRemote()`. Now remote events will only be triggered there, the old behavior will keep working if in compatibility mode. You must update the compatibility version to enable the new behavior.

**Improvements**
- `SetOutlineEnabled` and `SetHighlightEnabled` will now apply the effect on all attached children as well.
- JSON will now parse/stringify built-in structs as well (Vector, Rotator, etc).
- Reduced base character capsule width from 52 to 48.
- Improved some error handling and crashes when loading packages/asset packs.

**Bug Fixes**
- Fixed Particle and TextRender not syncing scale properly.
- Fixed ResetPhysicalAnimation not working properly.
- Attempt to fix Database many connections problems.
- Attempt to fix ResetCamera making camera going to origin when in FPS mode.
- Fixed SetValue not syncing values on players in another dimension.

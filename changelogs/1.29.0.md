# nanos world - Version 1.29.0

- **Release Date:** 2023-01-18 20:18:32 UTC
- **Raw Timestamp:** `2023-01-18T20:18:32.812Z`

---

**New Features**
- Added new method **Client**: `.SetNearClipPlane()`.
- Added new method to **WebUI**: `:SetLayout()` to adjust the size, location and anchors of the WebUI on the screen. Allowing better usability of multiple WebUIs over others as windows.
- Renamed **HTTP** methods: now `Select` is sync and `SelectAsync` is async. To use the new methods, update the compatibility version of the Package.
- Renamed **Database** methods: now `Select/Execute` is sync and `SelectAsync/ExecuteAsync` is async. To use the new methods, update the compatibility version of the Package.
- Deprecated **WebUI** and **Canvas** methods from SetVisible() in favor of `SetVisibility()`.
- Added new method to **Input**: `GetKeyCode()`.

**Improvements**
- Now Viewport.SetHardwareCursor receives Special Path as parameter.
- Now WebUI alerts will be supressed and ignored.
- Now Client Console will be disable with `Client.SetDebugEnabled(false)`.
- Now it's possible to pass Vector2D through blueprint functions and values.
- Now Weapon Spread will be treated separately from Recoil.
- Now Databases return `nil` if failed to connect.

**Bug Fixes**
- Fixed chat glitch when set to not visible and the Player tries to open it.
- Fixed Discord and Steam not resetting Activity when leaving the server.
- Fixed Character ViewMode not applying properly after possessing.
- Fixed reloading packages not initializing entities before Package Load event.
- Fixed Prop not syncing some other properties.

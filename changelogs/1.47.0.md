# nanos world - Version 1.47.0

- **Release Date:** 2023-04-09 12:46:57 UTC
- **Raw Timestamp:** `2023-04-09T12:46:57.036Z`

---

🆕 **New Features**
- Added new event to **Input**: `MouseMove`, deprecating MouseMoveX and MouseMoveY.
- Added new method to **Input**: `SetMouseCursor()`, to change the type of the cursor dynamically.
- Added new constructor parameter to **Canvas**: `screen_position` - Now canvas can have a position offset when drawing to screen.
- Added new methods to **Canvas**: `Resize()`, `GetSize()`, `SetAutoResize()` and `SetScreenPosition()`.
- We implemented the support for **WebUI/CEF** to trigger `dragstart` and `dragend` events (**experimental**). Note: events such *drag* or *drop* are not technically supported.

⏫ **Improvements**
- Now Input Mouse events will always trigger, even if you have a WebUI/Widget with focus! (It does not trigger if you have Escape Menu, Console or Chat open).
- Now Escape Menu shows the current Map and Game Mode as Vault Items properly with images.
- Now Escape Menu shows the Server Logo.
- Character ragdoll impulse when dying was slightly increased.
- Now Loading Screen Finishing Up stage will have a fade-out effect just before ending.

🔨 **Bug Fixes**
- Fixed Left Hands not properly attaching on weapon for some meshes.

# nanos world - Version 1.35.0

- **Release Date:** 2023-02-10 17:04:00 UTC
- **Raw Timestamp:** `2023-02-10T17:04:00.000Z`

---

🆕 **New Features**
- Added Player Avatar to chat messages!
- Added a new method to **Chat**: `Clear()`.
- Added a new method to **CharacterSimple**: `SetSpeedSettings()`.
- Added new method to **SceneCapture**: `EncodeToBase64()`.
- Added new built-in server console commands: `kick` (to kick a Player) and `players` to list all connected Players and their IDs.
- We've added the Stack-O-Bot in the game as an example usage for the new CharacterSimple class (`nanos-world::SK_StackOBot` and `nanos-world::ABP_StackOBot`).

⏫ **Improvements**
- The Console Commands now finds the best match to execute an command (exact match will have preference).
- Now Ultra Dynamic Sky Weather sound effects will be affected by Game Volume settings.

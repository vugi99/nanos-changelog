# nanos world - Version 1.136.3

- **Release Date:** 2026-05-03 12:52:58 UTC
- **Raw Timestamp:** `2026-05-03T12:52:58.491Z`

---

### 🆕 New Features
- Added a new (experimental) parameter to most of entities constructor `defer_spawn`: if `true` it will not spawn the entity on clients until you call `FinishSpawn()`. This is an optimized way to spawn entities on server that you need to set several values or parameters after spawning it, to avoid multiple subsequent network calls just to override the default values. Any API call that does a networking sync will not be transmitted before Finishing the Spawn of that entity. Note that **Inherited Classes** will automatically call `FinishSpawn()` after leaving the inherited constructor.

### ⏫ Improvements
- Deprecated **VehicleWheeled** `auto_create_physics` constructor parameter (now must use the new constructor with `defer_spawn`) and `RecreatePhysics()` method (must use `FinishSpawn()`).
- Now all client network packets will be grouped to be flushed at the same time at the end of the tick (the same as happens on server), improving client performance and efficiency.
- Now the Server Browser will display all servers from both Main and Playtest game AppIDs. Note those they are still incompatible.
- We did more improvements on client interpolation algorithm to sync actors/characters.

### 🔨 Bug Fixes
- Fixed more broken UIs due translated texts.
- Fixed login callback being triggered for all opened game instances.
- Fixed "Network Authority" error on server when a client disconnects.
- Fixed some *forgotten* errors logs on server.

# nanos world - Version 1.42.1

- **Release Date:** 2023-03-15 19:47:46 UTC
- **Raw Timestamp:** `2023-03-15T19:47:46.000Z`

---

🆕 **New Features**
- Added new method to **WebUI**: `GetName()`.
- Added new tab to settings: **Advanced**, which will hold Transfer File settings.

⏫ **Improvements**
- Added new toggle setting: **Use File Transfer HTTP Connection Pool**, to speed up files downloading through HTTP.
- Now requiring files through HTTP uses a more secure workflow by only allowing access to files that were previously loaded by the server (the same system that sockets transfers use).

🔨 **Bug Fixes**
- Fixed an operating system error when downloading a lot of files through sockets at the same time, now it has a hard limit of max 128 files at the same time (OS can't handle a lot of files opened simultaneously, causing errors when joining servers with thousands of "small" files).
- Fixed File Transfer error logs duplicating base path of files.
- Fixed File Transfer not resetting the current downloaded size between stages.
- Fixed File Transfer speed not showing up if the download is too fast.
- Fixed Sentry (our crash reporter) not being initialized on client to report Fatal errors.
- Fixed Network Authority being set on recent-spawned entities from another dimension players, causing complete havoc on the game.
- Fixed Persistent Data not reloading when package reloading.
- Fixed a crash when something fails during File Transfer.

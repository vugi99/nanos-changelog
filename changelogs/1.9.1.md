# nanos world - Version 1.9.1

- **Release Date:** 2022-06-02 12:13:55 UTC
- **Raw Timestamp:** `2022-06-02T12:13:55.532Z`

---

**New Features**
* Added P2P servers (experimental). Now you can start a server through Steam Relay Service without the need of forwarding ports (as this is experimental, the connection speed is still quite limited and some bugs may happen).

**Improvements**
* Improved some main menu server icons.
* Added new icon to define if a server is P2P or Dedicated in the server browser.

**Bug Fixes**
* Disabled the main menu pre-loading tabs (vault, servers, new game) which were causing some crashes.
* Tweaked Network Debug Screen.
* Fixed a crash when disconnecting from servers.
* Fixed a bug causing custom Skeletons get in ragdoll mode due being shot in the root bone.

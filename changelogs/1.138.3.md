### 🆕 New Features
- Now the client **Console** is integrated directly in the **Main Menu** and **Escape Menu**. Also improved copying selected texts entries. Note that the events Console Open/Close will not be triggered anymore.

### 🔨 Bug Fixes
- Fixed actors spawning with velocity > 0 not resetting to zero, causing desyncs.
- Fixed attached, picked and entered vehicles actors not resetting the velocity values.
- Fixed SetNetworkAuthority console errors when destroying entities.
- Fixed Login not aborting if it takes more than 10 seconds.
- Fixed more UIs broken due localization.
- Fixed WebUI select elements not getting focus when clicked.

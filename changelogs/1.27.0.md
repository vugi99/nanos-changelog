# nanos world - Version 1.27.0

- **Release Date:** 2023-01-07 11:41:41 UTC
- **Raw Timestamp:** `2023-01-07T11:41:41.000Z`

---

**New Features**
- New Package and Lua Engine VM behavior. Read the December Blog news for more information!
- New Configuration Files format. Read the December Blog news for more information!
- Added a bunch of new Static Classes. Read the December Blog news for more information!
- Added new static event to classes: `ClassRegister` which is triggered when a new class is registered/inherited.
- Added new parameter to `.Inherit` method, allowing to set custom values directly in the class before the event is triggered.
- Now Packages, Assets and Server logo image should be placed besides it's .toml with the name `Package.jpg`, `Assets.jpg` or `Server.jpg`.
- New Server Custom Settings feature, game-modes can define custom settings in `Package.toml` to be set in the New Game menu or through server command line. The values can be accessed through `Server.GetCustomSettings()` method.
- Added new methods to Blueprint: `Set/GetBlueprintPropertyValue`.
- Now you can create Asset Packs with Plugin Content!


**Improvements**
- Now re-registering classes from the same package just returns the existing class and don't throw errors anymore.
- Improved performance by disabling water effects if you are too far from it.
- `nanos-world-weapons` and `nanos-world-vehicles` are no longer built-in packages, and now must be downloaded from vault with new names `default-weapons` and `default-vehicles`.
- CEF will paint and tick at the player's game framerate now (was fixed at 60 fps).
- Suppressed CEF "CACHE_MISS" warnings on client console.
- Tweaked weapons reload animations, they should be more visible now when in FPS.
- Added a Depth of Field effect when aiming in TPS.
- Deprecated assets://NanosWorld schema, use assets://nanos-world now.


**Bug Fixes**
- Fixed network entities being limited to 65k (now supports up to 2bi).
- Fixed Database and Files never being destroyed causing max connection errors on Database.
- Fixed achievements errors.
- Fixed client triggering Package Load event for all packages after a package reload.
- Fixed the game not being able to load custom maps.
- Fixed server not auto downloading content when starting a server from Main Menu.
- Fixed New Game 'singleplayer' games resetting max players to 64.
- Fixed weapon reloading throwing the magazine to wrong side.
- Fixed Vehicles with attached meshes using wrong buoyancy values.
- Fixed a "deadlock" freezing linux servers when unloading packages.
- Attempt to fix a CEF crash when loading thousands of resources at the same time.

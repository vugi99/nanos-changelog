# nanos world - Version 1.103.0

- **Release Date:** 2026-01-23 18:57:12 UTC
- **Raw Timestamp:** `2026-01-23T18:57:12.000Z`

---

### 🆕 New Features
- The entity `TextRender` has been renamed to [`Text3D`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/text-3d). A new compatibility version [`1.103`](https://docs.nanos-world.com/docs/next/core-concepts/packages/compatibility-versions#version-1103) was added in order to keep existing scripting using TextRender to be redirected to Text3D.
- Added a new Entity: [`TextRender`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/text-render). Now TextRender uses Unreal's TextRender component to render text as flat materials, while the new Text3D entity uses the Unreal's Text3D Plugin to generate more advanced texts in 3D (note: Text3D is experimental as it has some limitations/caveats).
- Added a new method to **WebUI**: `HasNodeFocus()`, returns if any DOM node currently has input focus.
- Added new `A_Thruster_XX` sound effects.

### ⏫ Improvements
- The game has been updated to Unreal `5.7.2`. It should not break any existing Asset Pack.
- Improved Hit event logic and performance.
- Improved several internal sounds spawning performance.
- Improved the WebUI image loading performance.
- Improved the Vehicle tire smoke particle effect when skidding.
- Now calling Events.Call/BroadcastRemote will throw an error if passing more data than the supported.
- Now when pressing Escape while having a WebUI node focus, it will unfocus from the node (and not open the escape menu anymore).
- Now when having a WebUI node focus, all the game input will be ignored.
- Updated some UI fonts and widgets.
- Updated to Sentry 1.5.

### 🔨 Bug Fixes
- Fixed Cables not attaching properly on scaled actors.
- Fixed Characters switching weapons having the hands offset resetting, causing a weird animation effect.
- Fixed CLI not downloading some assets/packages dependencies.
- Fixed uploaded versions from in-game causing the version to do not show progress when downloading them from vault.
- Fixed starting a server with --auto_download and --use_vault_assets_lean still downloading the asset pack if it's a dependency of other package/asset pack.

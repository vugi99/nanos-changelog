# nanos world - Version 1.91.1

- **Release Date:** 2025-10-13 17:53:37 UTC
- **Raw Timestamp:** `2025-10-13T17:53:37.362Z`

---

### 🆕 New Features
- Added a new method to **Client**: `SetSettingGammaOverride()`, to force a gamma value and prevent the user from changing it.
- Added a new method to **BaseDamageable**: `IsDead()`.

### 🔨 Bug Fixes
- Fixed Sound always auto playing even if auto_play = false.
- Fixed UnPossessing a Character while it's in ragdoll making it's capsule collision to turn on.
- Fixed BasePawn SetHitReactionEnabled not setting properly (was always false).
- Fixed closing Escape Menu not restoring focus to viewport when closed.

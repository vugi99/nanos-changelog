# nanos world - Version 1.51.0

- **Release Date:** 2023-04-23 12:27:49 UTC
- **Raw Timestamp:** `2023-04-23T12:27:49.735Z`

---

🆕 **New Features**
- Added a new parameter to `Player.SetCameraArmLength(length, force)`: **force**, to force the new location without interping.

⏫ **Improvements**
- Now opening more than 1 client instance will use another local cache folder, to avoid file overrides and disconnects/corrupt files. Making possible to open several clients locally at the same time without any problem.
- Now package reloads will be queued on client if it is already performing a package reload. To avoid the client disconnecting if multiple package reloads happen too often, also fixing some other bugs of corrupted files and errors.
- Now Input.Bind/Unbind will output a warning if the KeyBinding was not registered/defined.
- Now Characters will always calculate the interaction traces, even if aiming.
- We updated our SteamWorks library to the latest version.

🔨 **Bug Fixes**
- Fixed Server Stuck for 0ms warning.
- Attempt to fix a crash when aborting the loading while in finishing up state.
- Fixed Player.SetCameraArmLength() not calculating the multiplier properly when being called.

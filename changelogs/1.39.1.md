# nanos world - Version 1.39.1

- **Release Date:** 2023-03-05 14:34:03 UTC
- **Raw Timestamp:** `2023-03-05T14:34:03.292Z`

---

🆕 **New Features**
- Added new **Sky** method: `SetMoonVerticalOffset()`.

⏫ **Improvements**
- Now if the Steam is not opened, a nice Popup alert will ask you to open it (instead of just closing/cashing the game).
- Scripting warning and errors labels were renamed from `SCRIPT` to `S_WARN` and `S_ERR`.

🔨 **Bug Fixes**
- Fixed Characters physics going insane when getting to ragdoll mode for the first time.
- Fixed Highlight/Outline not working properly in some indexes.
- Fixed game crashing if Steam was not opened.
- Fixed crash when interacting with object that has been just destroyed.
- Fixed a crash when connecting to a server while having local files or folders opened. Now it will throw an error and disconnect you from the server.
- Attempt to fix a rare crash when opening the in-game menu.

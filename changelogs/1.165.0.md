# nanos world - Version 1.165.0

- **Release Date:** 2026-10-25 17:10:00 UTC
- **Raw Timestamp:** `2026-10-25T17:10:00Z`

---

### 🆕 New Features
- Now when connecting to a server running a game jam, it will display the Game Jam entry in the escape menu, and also display the button to rate it.
- Added the servers tab to the Game Jam menu tab. To see all servers running under a game jam entry.
- Added Game Jams tab to the escape menu.
- Added more meshes from Playground to the Spawn Menu.
- Added [`SetAIStopWithBraking()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-setaistopwithbraking) to Pawn: when enabled, AI movements brake to a stop using the Pawn's braking settings instead of stopping instantly (disabled by default).

### ⏫ Improvements
- Holding Escape now always opens the native **Escape Menu**, even when a script blocks the Escape press to show its own menu, and it no longer flickers open and closed. Also Escape key repeats are no longer sent to scripts.
- The **Server Browser** now only lists servers compatible with your version by default.
- The **Server Browser** now requests the full server list at most every 30 seconds and only re-queries the known servers in between. Preventing Steam from throttling the queries and returning empty lists.
- Reduced the trace sphere on interactions, making interactions more precise.
- Characters standing on a client-side mesh attached to a synced entity now replicate relative to that entity, so other players no longer lag behind moving platforms built that way.

### 🔨 Bug Fixes
- Fixed a crash when saving the settings after enabling the **Profiling Screen** while Profiling was on.
- Fixed welded children collisions staying outdated in the wrong position.
- Fixed `Chat.AddMessage` spawning a broken Player and passing it to the `ChatEntry` event instead of `nil`.
- Fixed **Game Jam** entry links opening a broken jam page.
- Fixed the loading screen showing wrong download totals (e.g. 99 MB / 0 B) when updating outdated **Vault** Asset Packs while joining a server.
- Fixed **WebUIs** playing a short beep when created or destroyed. WebUI native audio output is now always muted, and the audio keep-alive only starts once `WebUI:SpawnSound` is used.
- Fixed the "Failed to find Achievement to Update" error when unlocking a chat messages achievement. Also fixed them not showing in the list.
- Fixed AI Characters slowing down heavily when approaching their target with `MoveTo()` and `Follow()`.

### 🌐 Account, Store & Website
- Game jam entry images now accept up to 5 MB.
- Improved the resources **Versions** tab: the changelog is rendered as markdown and is clamped to 2 lines, there is a unified "show more information" toggle, and a switch to hide old deleted/declined versions.
- Resources screenshots list now supports drag and drop to reorder them.
- Fixed uploading a second screenshot failing with a 404.
- Fixed the navbar dropdown staying open when leaving the tab.

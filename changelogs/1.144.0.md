# nanos world - Version 1.144.0

- **Release Date:** 2026-06-25 19:07:36 UTC
- **Raw Timestamp:** `2026-06-25T19:07:36.665Z`

---

### 🆕 New Features
- Reworked all `AddSkeletalMeshAttached()` methods. Added a new Compatibility Version [1.144](https://docs.nanos-world.com/docs/next/core-concepts/packages/compatibility-versions#version-1144) since we added 4 new parameters. Allowing to attach it to bones, with relative transform and also with custom animations (allowing easily using retargeters).
- Added a new method [`BasePawn.SetMeshSettings()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-setmeshsettings) for configuring the main mesh attachment and visibility.
- Added a new parameter to [`BasePawn.SetCapsuleSize()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-setcapsulesize): `crouched_half_height` for customizing the crouching capsule size. Also added it to `GetCapsuleSize()`.
- Deprecated the parameter `adjust_capsule_size` from [`CharacterSimple.SetMesh()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/character-simple#function-setmesh). Must use the new `SetMeshSettings()` now.

### ⏫ Improvements
- Now [`BasePawn.SetCapsuleSize()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-setcapsulesize) has `0` as default parameters, and by default it calculates the radius and half height automatically from the meshes.
- Added a new parameter `impact_normal` to the new Weapon `BulletHit` event (breaking change!).
- We reworked a lot of Character/CharacterSimple **Camera** and **Capsules** related code, please let us know if you see any bug related to it!
- We disabled the ability to Characters to **Prone**, as it was an unfinished and bad looking feature, needing a ton of extra implementation to support it.
- Enabled the Plugin `WaterAdvanced`.

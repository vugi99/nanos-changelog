# nanos world - Version 1.58.1

- **Release Date:** 2023-08-12 11:14:01 UTC
- **Raw Timestamp:** `2023-08-12T11:14:01.625Z`

---

⏫ **Improvements**
- Added Tint parameter to the built-in ClassicMale and PostApocalyptic character meshes ([Sandbox Issue #27](https://github.com/nanos-world/nanos-world-sandbox/issues/27)).
- Changed Clear Scripting Keybindings button label text ([Issue #934](https://github.com/nanos-world/issues/issues/934)).
- Now Package's already required files will be cached and it's return value will be returned instead of nil ([Issue #933](https://github.com/nanos-world/issues/issues/933)).
- Improved Async Operations to do not halt the thread when any File, Database or SceneCaptures is being destroyed (it will only halt if this specific entity has an async operation running).

🔨 **Bug Fixes**
- Fixed a deadlock when destroying File, Database or SceneCaptures from inside some callbacks ([Issue #930](https://github.com/nanos-world/issues/issues/930)).
- Fixed NanosUtils.Benchmark with wrong amount (thanks [Voltaism PR](https://github.com/nanos-world/nanos-world-lua-lib/pull/21)).
- Fixed crash when sending and returning recursive/cyclic tables inside parameters ([Issue #939](https://github.com/nanos-world/issues/issues/939)).
- Fixed cyclic tables not being referenced when returning parameters ([Issue #931](https://github.com/nanos-world/issues/issues/931)).

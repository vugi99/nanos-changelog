# nanos world - Version 1.23.0

- **Release Date:** 2022-12-06 19:21:44 UTC
- **Raw Timestamp:** `2022-12-06T19:21:44.778Z`

---

**New Features**
- Added new method to **Player**: `GetDimension`.
- Added new methods to **SceneCapture**: `SetDistanceOptimizationEnabled` and `SetForceAlwaysRendering`.
- Added new constructor parameters to **SceneCapture**: `enable_distance_optimization` and `force_always_rendering`.
- Added new events to **Character**: `PullUse` and `ReleaseUse` (*officially*).
- Added Secret Stuff.

**Improvements**
- Now Packages have a new system to only load files once. I.e. trying to **Package.Require** the same file twice will ignore the second loading.
- We've reworked our HTTP class internally, please let us know if anything goes weird.

**Bug Fixes**
- Fixed main menu crashes when rapdily connecting/quitting from a server.
- Fixed Pickable events PullUse and ReleaseUse not being triggered on Classes subscribed events.
- Another attempt to fix Physical Animations not resetting properly.
- Fixed *an* annoying warning.

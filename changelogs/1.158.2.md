# nanos world - Version 1.158.2

- **Release Date:** 2026-10-08 18:00:00 UTC
- **Raw Timestamp:** `2026-10-08T18:00:00Z`

---

### 🆕 New Features
- We are implementing our first iteration of our in-house server-side **Anti-Cheat**. The server now validates what clients send and refuses what an unmodified client could never send, such as calls to server-only methods, taking control of entities or applying damage on behalf of other players, malformed network messages, unexpected damages and more. We'll keep tweaking it and release more options, methods and events to control and handle it in the next updates.
- Added a link to the crash report page in the **Crash Reporter**, so you can look up your crash on our new https://nanos-world.com/crash page.
- Added an **Open Mic** voice chat mode! You can now switch between **Push to Talk** and **Open Mic** in the Audio settings. In Open Mic, the voice key mutes and unmutes your own mic. The top bar in the escape game menu show whether your mic is open or muted.
- Added [`Client.IsVOIPSelfMuted()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#static-function-isvoipselfmuted) and the new Client event [`VOIPSelfMuteChange`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#event-voipselfmutechange), so scripts can tell when the player mutes their own mic. Also added `VoicePushToTalk` to the settings returned by `Client.GetSettings()`.

### ⏫ Improvements
- Improved the **Game Jam** server entries and popup in the main menu.
- Now text inputs in the menus use the new monospace font.

### 🔨 Bug Fixes
- Fixed Package.jpg or Assets.jpg images not being loaded from local packages/asset packs.
- Fixed clients failing to validate or download files with non-ANSI characters in their names on Windows.
- Fixed fatal errors when messages were flushed while disconnecting.
- Fixed a rare crash when sending bundled packets.
- Fixed the "too much data already queued" network issue being reported as a fatal error, it is now a regular error.
- Fixed some **Halloween** layout on main menu being broken.

### 🌐 Account, Store & Website
- Added a new **Sign-in** page and improved the login flow.

- Added search to the **FAQ**.
- Added a **Leave Team** button on the account Teams page.

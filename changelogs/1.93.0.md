# nanos world - Version 1.93.0

- **Release Date:** 2025-10-22 10:45:17 UTC
- **Raw Timestamp:** `2025-10-22T10:45:17.757Z`

---

### 🆕 New Features
- Added new default materials: `M_Default_Translucent_Unlit` and `M_Default_Translucent_Unlit_Depth`.

### ⏫ Improvements
- Now the Client **Profiling** list will sort and display the list based on the call stack hierarchy, also it displays if an item is running on an async thread.
- Now `M_Default_Translucent_Lit_Depth` will be rendered after fog.
- Enabled a few more old-disabled **Vault** features and tabs.

### 🔨 Bug Fixes
- Fixed Character head moving too much when in first person.
- Fixed Melee causing other players to look like hitting several times consecutively.
- Fixed error when calling StopAnimation with a not-yet loaded animation.
- Fixed Y-aligned weapons not calculating the start bullet trace location when firing.
- Fixed custom_settings .toml section not applying proper indentation.
- Fixed Player SetVOIPMuted not syncing properly causing Fatal errors on client.
- Fixed Trigger not getting parent location to calculate the optimization distance.
- Fixed Melee not applying the Skeletal Mesh as attached when passing it to the constructor.
- Attempt to fix client "hash collision" errors when multiple package reloads called consecutively.

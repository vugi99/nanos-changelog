# nanos world - Version 1.113.0

- **Release Date:** 2026-03-11 14:19:07 UTC
- **Raw Timestamp:** `2026-03-11T14:19:07.494Z`

---

### 🆕 New Features
- New **Config.toml** setting: `language`, now you can define the language of your server that will appear as a flag in the Find Servers list!
- New **Loading Screen** stage: `fetching`, this will happen after "connecting" and before "validating", with a new progress bar while downloading/fetching server initial information.

### ⏫ Improvements
- Improved **File Transfer** system, now it will reduce the network buffering usage and respect the max_file_transfer_rate more precisely.
- Now Players will be automatically kicked if they hit the maximum network buffer (due bad connection), preventing further desyncs, fatal errors and server performance issues. The max pending network data buffer was also reduced.
- Reduced the max_send_rate setting possible value to 16 MB/s.
- Added profiling to network Send/BroadcastMessage calls.
- Updated **Ultra Dynamic Sky** to 9.3A.

### 🔨 Bug Fixes
- Fixed loading screen hanging on "disconnecting..." for several seconds when aborting the load with ESC.
- Fixed Lumen Hardware Ray Tracing setting not being applied correctly.

# nanos world - Version 1.134.1

- **Release Date:** 2026-04-27 18:27:10 UTC
- **Raw Timestamp:** `2026-04-27T18:27:10.831Z`

---

### 🆕 New Features
- Added new method [`Client.GetLanguage()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#static-function-getlanguage) and new **Client** [`LanguageChange`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/client#event-languagechange) event.
- The **Loading Screen** is now fully translatable too. Thank you everyone for contributing to the [Crowdin](https://crowdin.com/project/nanos-world-game) project.

### ⏫ Improvements
- Now `Server.SetValue()` synced values will be cached and compressed to be sent to clients when they join. Making a better optimized use to store values that need to be sent to the clients instead of using Events.CallRemote when they join.
- Now hovering the languages settings will display the translation percentage for each language.
- Optimized all `Server.SetValue()` and `Entity.SetValue()` calls.

### 🔨 Bug Fixes
- Fixed `Client/Server.GetPackages()` wrong `PackageType` enums.
- Attempt to fix **WebUI** loading issues when non utf-8 C:/Users join the server.

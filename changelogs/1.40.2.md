# nanos world - Version 1.40.2

- **Release Date:** 2023-03-11 17:30:55 UTC
- **Raw Timestamp:** `2023-03-11T17:30:55.033Z`

---

⏫ **Improvements**
- Now starting a new server from the New Game will display more information of the server loading and downloading progress in the loading screen!
- Achievements are now sorted by Unlock Time and will auto refresh from time to time.
- Loading Screen 'Finishing Up' stage is faster now.

🔨 **Bug Fixes**
- Fixed File Transfer Timeout beeing too aggressive. The system was reworked to have a global timeout instead of being per-file, fixing timeout cases of P2P servers or bad connection.

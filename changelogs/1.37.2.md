# nanos world - Version 1.37.2

- **Release Date:** 2023-02-24 14:11:56 UTC
- **Raw Timestamp:** `2023-02-24T14:11:56.948Z`

---

🆕 **New Features**
- Now Vault resources will display icons telling if the resource is official and if you have ownership of it.
- Now it is possible to Create Packages/Assets through the Vault UI! This will create a local Package/Asset Pack. In the future it will be possible to publish it to the store through the UI too.
- Added new tab to Vault Resource screen: "manage", which is enabled when you have ownership of that item. For now it just has buttons to redirect to the store, but will be used to edit the resource information in the future when the Store API supports it.

⏫ **Improvements**
- Improved Vault resources loading time.
- Several Vault UI improvements were made.
- Several Notifications UI improvements were made.
- Now Attached Skeletal/Static meshes uses parent bounds.
- Now selecting additional Packages through the New Game UI will only display scripts, and not game-modes.
- Adjusted Assets.toml spaces count in [unreal] section.

🔨 **Bug Fixes**
- Fixed client side crash on PickUp events.
- Fixed grenades not ignoring themselves when triggering radial damage (causing some explosions to do not cause damage).
- Fixed Characters Team not working for preventing damage. 
- Fixed Weapon AmmoClipChange, AmmoBagChange and Fire events being triggered in wrong order.

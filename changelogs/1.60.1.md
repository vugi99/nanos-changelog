# nanos world - Version 1.60.1

- **Release Date:** 2023-09-11 09:45:11 UTC
- **Raw Timestamp:** `2023-09-11T09:45:11.893Z`

---

🆕 **New Features**
- Now the methods `os.execute`, `os.rename`, `os.remove`, `os.exit`, `os.getenv`, `os.tmpname`, `os.setlocale`, `dofile`, `loadfile` and all `io.*` can only be executed if the server is started with the new command-line parameter: `--enable_unsafe_libs` (read more in the [August News Blog](https://docs.nanos.world/blog/august-2023#scripting-safety)).

🔨 **Bug Fixes**
- Fixed Trigger not applying scale and color properly on client side.

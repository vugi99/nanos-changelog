# nanos world - Version 1.42.0

- **Release Date:** 2023-03-13 21:49:55 UTC
- **Raw Timestamp:** `2023-03-13T21:49:55.000Z`

---

🆕 **New Features**
- Added new *missing* method to **Vehicles**: `SetSteeringSetup()`.

⏫ **Improvements**
- Now pressing Connect on Main Menu will not freeze the game anymore. That waiting process was moved to the loading screen.
- Improved even more the loading screen information when starting a server from the menu.
- Now setting a Character into a Vehicle will make the current passenger at that seat to leave the vehicle.
- We replaced some internal Vector structures to use 32bits version instead of the new 64bits for some cases unnecessarily. Some Entities should be lighter in size again. This changed a lot of internal structures sizes, lets keep an eye on for weird problems and crashes!

🔨 Bug **Fixes**
- Fixed Escape Menu muffled sound not resetting when disconnecting.
- Fixed ragdolls "floating" in air when joining a server with others existing ragdolls.
- Fixed client side Fatal error when trying to enter a vehicle with a passenger.
- Fixed Loading Screen bars not working properly since last update.
- Fixed a problem when entering passengers into Vehicles not validating if the seat exists before.
- Fixed Characters not syncing Dead state client side.

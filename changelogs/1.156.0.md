# nanos world - Version 1.156.0

- **Release Date:** 2026-09-17 12:57:08 UTC
- **Raw Timestamp:** `2026-09-17T12:57:08.125Z`

---

### ⏫ Improvements
- **Attention:** Now the Game Server will start automatically in Playtest appid by default. For switching to "game" appid, launch the server with the new command line `--steam_app "game"`. Also `--playtest` was deprecated in favor of `--steam_app "playtest"`.
- Updated **Steam SDK** to version 1.65.

### 🔨 Bug Fixes
- Fixed CharacterSimple Based Sync issues causing them to keep entering falling state.
- Fixed Vault descriptions markdown code blocks and quotes not being skipped in-game.

### 🌐 Account, Store & Website
- Added a unified [**Hub**](https://nanos-world.com/hub) that merges Store browsing into one page.
- Added a new Global Search to the navbar, which you can search for anything on the store/community.
- Added new options to our Navbar, and we made it more richer.
- Added a new **Recruiting** label to projects, so you can mark your Project as "looking for devs".
- Added a new badge [**Admirer**](https://nanos-world.com/community/badges/fc6fd2e7-b16f-462f-9321-4ae5b0a21fe4) for favoriting a Resource or Project.
- Now the badge [**Creator**](https://nanos-world.com/community/badges/9a25d8c9-cc5a-4194-a448-a4a7be252828) will also be given to Project creators.
- We implemented a new **Markdown Editor** for editing descriptions.
- Moved our public [**Roadmap**](https://nanos-world.com/roadmap) and [**Changelog**](https://nanos-world.com/changelog) to the main website.
- Now the Store's "Recently Updated" list reflects an resource's latest version.
- Improved projects/resources carousel navigation and layout.
- Improved the Workflow of creating a new Team, Project and Resources. It should be much more easy and intuitive now.
- Improved our Support pages by adding new support entries and more help information.
- Improved the workflow of requesting keys through a Project.
- Fixed dangling/orphaned versions and unresolved images appearing on Store and Vault items.
- Increased the description characters limit to 25K, and screenshots to 20.
- Fixed several mobile pages layout, including the Projects page.
- Several navigation, UI, layout, and bugs fixes made.

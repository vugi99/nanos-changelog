# nanos world - Version 1.50.0

- **Release Date:** 2023-04-18 14:34:56 UTC
- **Raw Timestamp:** `2023-04-18T14:34:56.092Z`

---

🆕 **New Features**
- New Static Class **NanosTable**! Which will contain `table` helper and utility methods. NanosUtils.ShallowCopyTable() and NanosUtils.Dump() were deprecated in favor of `NanosTable.ShallowCopy()` and `NanosTable.Dump()`.
- Added custom methods to `string` native table: `string.StartsWith()`, `string.EndsWith`, `string.Trim()` and deprecated NanosUtils.FormatString() in favor of `string.FormatArgs()`.
- Now you can pass and receive **any** Unreal Struct as **Blueprints Parameters** which are parsed to/from Lua tables.
- The *File** Static Class is now Client Side too! On Client you can store/read files from the Client 'sandboxed' `Packages/.transient/` folder. Allowing you do store/retrieve custom cache files persistently on clients!

⏫ **Improvements**
- Now you can pass `Player.GetAccountIconURL()` as Blueprint Material parameters.

🔨 **Bug Fixes**
- Fixed cache files adding extra slashes to path.
- Fixed Input.SetMouseCursor not working if any WebUI/Widget had visibility ON.
- Fixed Package.GetCompatibilityVersion returning empty string.
- Fixed Package.Subscribe not returning the callback.

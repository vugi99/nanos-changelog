# nanos world - Version 1.143.0

- **Release Date:** 2026-06-21 11:11:10 UTC
- **Raw Timestamp:** `2026-06-21T11:11:10.000Z`

---

### 🆕 New Features
- Added a new method [`Input.GetKeyboardLayout()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/input#static-function-getkeyboardlayout) to retrieve the keyboard layout. Useful for creating default Inputs based on QWERTY/AZERTY keyboards.
- Added a new Weapon [`BulletHit`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/weapon#event-bullethit) client side event.
- Added a new *experimental* method [`Package.ReloadClientFile()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/package#static-function-reloadclientfile) to re-cache and send to players a new version of a file, triggering [`FileReload`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/package#event-filereload) event on them.

### ⏫ Improvements
- Updated **CEF** to v149.
- Updated **HTTP** library.

# nanos world - Version 1.13.0

- **Release Date:** 2022-08-05 17:49:38 UTC
- **Raw Timestamp:** `2022-08-05T17:49:38.549Z`

---

**New Features**
- New WebUI renderer using CEF.
- WebUI SetFocus and RemoveFocus have been deprecated.
- Added new methods to WebUI: SpawnSound, GetSize, SendMouseWheelEvent, SendKeyEvent, SendMouseMoveEvent and SendMouseClickEvent.
- New Settings Menu UI.
- New Settings tab: House Keeping (experimental)
- Added new event to Client: `MouseScroll`.
- Added Mouse Input do bindings on Input static class.
- Added new method to Server: `Unban`.

**Improvements**
- Improved Vault overview size.
- Loading screen now displays the whole file name path when downloading.
- Disabled some warnings on client side from vault.
- Now loading custom files through WebUI is done with package:// instead of package///. (Old schemes have been deprecated but still work).
- Now pressing enter on Quick Connect input will make it submit it.
- Now Lumen Global Illumination is OFF by default.
- Now server console will display a list of all commands when entering an invalid command. You can prevent it by returning false on Server's `Console` event (and handle the command).
- Now CLI will validate the path when creating an Asset Pack/Package.
- Improved Package's GetFiles/GetDirectories to load from the current path instead of the current Package.
- Added a new Cache system to Assets/Packages. Server load will be faster after the first caching.

**Bug Fixes**
- Fixed some wrong Key images path (from GetKeyIcon).
- Fixed Vault update count not updating correctly when updating a vault item.
- Fixed in-game menu opening with game console over it.
- Fixed far Characters not moving legs when walking.
- Fixed TopDown view mode not working.
- Fixed StaticMeshes with NoCollision staying with visibility collision on (blocking shots).
- Fixed Scripting converting Lua's double to float.

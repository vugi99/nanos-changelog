# nanos world - Version 1.24.0

- **Release Date:** 2022-12-10 14:09:01 UTC
- **Raw Timestamp:** `2022-12-10T14:09:01.017Z`

---

**New Features**
- Added new Static Methods to Classes: `.IsChildOf(class)`, `.GetParentClass()` and `.GetName()`;
- Added new method to all entities: `:IsA(class)` and `:GetClass()`.

**Improvements**
- Entity `:GetType()` has been deprecated. Use alternatives like comparing `:GetClass()` directly, `:IsA()` or `:GetClass().GetName()`.
- `NanosUtils.IsA()` has been deprecated in favor of `entity:IsA()`.
- Upgraded CEF version.
- Upgraded some internal dependencies.

**Bug Fixes**
- Fixed client side not being able to iterate through GetPairs or GetAll on inherited entities.
- Fixed Character constructor not setting assets properly.
- Fixed Cable attachment location wrong.

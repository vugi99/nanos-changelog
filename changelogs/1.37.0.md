# nanos world - Version 1.37.0

- **Release Date:** 2023-02-19 13:32:55 UTC
- **Raw Timestamp:** `2023-02-19T13:32:55.774Z`

---

🆕 **New Features**
- New **Notifications** area in Main Menu! Now notifications will appear as a floating balloon and will be contained under the new Notifications screen. More notification messages will be added as the time goes.
- Added a new validator for **Assets.toml** when loading Asset Packs! It will tell if an Asset File configured on it was not located in the disk.
- Added new methods to **Character**: `SetFootstepVolumeMultiplier()` and `SetRadialDamageToRagdoll()`
- Now you can return false to **Player** `VOIP` event to prevent that audio stream from being sent.

⏫ **Improvements**
- Added Blog News section into the Main Menu Home.

🔨 **Bug Fixes**
- Fixed game crashing when parsing invalid Assets.toml.
- Fixed a server & game crash when store Assets/Packages don't have releases.
- Fixed Debug Capsules Setting not working.
- Fixed a TestingMap House with too small door size.

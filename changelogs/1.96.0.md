# nanos world - Version 1.96.0

- **Release Date:** 2025-11-11 08:40:49 UTC
- **Raw Timestamp:** `2025-11-11T08:40:49.902Z`

---

### ⏫ Improvements
- Our **Files Validator** has been completely reworked. It now validates local files much faster (using all your CPU threads) and properly removes any outdated files that were deleted on the server (for both Packages and Assets), fixing crashes caused by leftover old assets on the client side.
- Now the client's **Packages Cache** folder is unified across all servers. This means if you connect to another server using the same package, it will reuse the existing cache. No more unnecessary re-downloads! This also greatly improves the experience for P2P servers, which previously had to re-download all scripting files every time.

### 🔨 Bug Fixes
- Fixed an issue where changing a Player's dimension wouldn't properly spawn or destroy them for other clients, leading to severe desyncs.
- Fixed crash when shooting at surfaces without physical materials.
- Fixed a crash caused by triggering a Lua error when passing an object instead of a string parameter.
- Fixed .png files not being cached correctly on the client, which caused Vault images to be re-downloaded every time.
- Fixed Player identifying the local player wrongly, causing a few unexpected issues.
- Fixed a file transfer issue where files couldn't be read to calculate their hash if their path length was too big.

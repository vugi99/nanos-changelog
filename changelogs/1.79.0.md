# nanos world - Version 1.79.0

- **Release Date:** 2025-05-28 16:12:06 UTC
- **Raw Timestamp:** `2025-05-28T16:12:06.035Z`

---

### 🆕 New Features
- New Server Delta Time algorithm. Improving the overall precision of each server tick. Now the global server configuration `tick_rate` was renamed to `max_tick_rate` and must be set in Hertz (ticks per second), it was in Milliseconds before, it will be converted automatically when launching the server for the first time. We also improved the server tick stutter logs to provide more information about the frame time.
- New `LoadingScreen` object JSON format. Now it splits player and server data in two different sub-tables. Also added steam_id to the player object. See [the full format](https://docs.nanos-world.com/docs/next/core-concepts/packages/loading-screen#player-information).

### ⏫ Improvements
- Now Timers are more precise! We reworked it to use a more precise clock internally, fixing some timing inconsistency that were being affected by stutters and delta time oscillations.
- Now the server will be abruptly closed if too many CTRL+C are pressed (you should avoid it).
- Now every time the Lua VM is started, a new random seed will be generated automatically (`math.randomseed(os.time())`).
- Increased the clients max network send rate to 1 MB/s (was 256 KB/s).
- Updated DLSS to 4.0.2.
- Fixed WebUI not rendering properly when applied to 3D objects.

### 🔨 Bug Fixes
- Now if a socket file fails to download, the client will be kicked (same behavior as HTTP files). The real issue will still be fixed.
- Fixed Water River rendering issues (added an workaround to force them being updated).
- Fixed unpossessed Player always teleporting the camera to 0, 0, 0.
- Fixed Mouse Cursor not showing up during Loading Screen (and during Password popup shows up).
- Fixed bug allowing some entities being able to be spawned without permission.
- Fixed fatal errors when clients were trying to send network messages while shutting down.
- Fixed some random crashes.

# nanos world - Version 0.17.0

- **Release Date:** 2020-05-23 17:37:29 UTC
- **Raw Timestamp:** `2020-05-23T17:37:29.5Z`

---

**New Features**
*  Now server's password is implemented and will be prompted when attempting to join a passworded server.
*  Now server's max players will be check and avoided further connections.
*  New Scripting function: `Actor:AddImpulse()` to apply impulse in any actor.

**Improvements**
*  Now the ID passed to Render Items will be used to order the rendering, i.e.: the higher index will be rendered in front of lower indexes.
*  Now disabling gravity will also disable physics on Actors/Props.

# nanos world - Version 1.131.0

- **Release Date:** 2026-04-17 12:03:11 UTC
- **Raw Timestamp:** `2026-04-17T12:03:11.000Z`

---

### 🆕 New Features
- Now the **Server Requirements** files list will be cached locally to avoid re-download every time connecting to a same server (that didn't change the requirements).
- Implemented a new system that bundles all network messages together and flush them at once at the end of the server frame. Improving a lot the server performance when many players are connected.

### ⏫ Improvements
- Added a new loading screen step of "Fetching Loaded Assets", which is now separated from "Fetching Server Requirements".
- Improved the performance of all Lua API calls by skipping logic for simple methods.
- Improved the performance of all internal network "broadcast", by skipping re-validating all players every time by having them cached in a list.
- Now the Authentication Queue will display the player queue position in the loading screen.
- Removed the titles of Frametimes and other Debug widgets to make them lean.
- Now Actors will skip Water logic and Pontoons creation if the map has no Water component.
- Several other minor performance improvements in scripting calls.
- Updated CEF to version 146.

### 🔨 Bug Fixes
- Fixed `Package.FlushPersistentData()` not working (with wrong name).
- Fixed client's local dimension not returning correct dimension when using `Server.SetDefaultPlayerDimension()`.
- Fixed `IsInWater()` not working correctly.

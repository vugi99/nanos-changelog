# nanos world - Version 1.171.5

- **Release Date:** 2026-11-20 11:43:00 UTC
- **Raw Timestamp:** `2026-11-20T11:43:00Z`

---

### 🆕 New Features
- Added a **Mouse Smoothing** setting.
- Added an experimental **Animation Quality** setting to control how frequently distant characters animate.

### ⏫ Improvements
- Improved character animation performance by adjusting animation update rates for other players characters.
- Improved the smoothness of grabbed props on Characters.
- Added a byte limit for client remote events to help protect servers from excessive traffic.
- Server launch options and console commands now reject invalid numeric values with a proper error.

### 🔨 Bug Fixes
- Fixed the server crashing at startup when boolean launch options were given `true` or `false`.

# nanos world - Version 1.114.1

- **Release Date:** 2026-03-13 12:41:56 UTC
- **Raw Timestamp:** `2026-03-13T12:41:56.381Z`

---

### 🆕 New Features
- New **Distance Optimization** system. This system works by reducing amount of sync network data (location/rotation/velocity/etc) to players if they are too far from an Actor. This can be adjusted with the new Config.toml setting: `distance_optimization` and can be defined from 0 to 9 (0 being disabled, and 9 very aggressive). It can also be enabled/disabled in runtime with the new console command `distance_optimization`.
- Now `max_send_rate` is defined in KB/s (was MB/s). And added new console command `max_send_rate` to allow changing it in runtime.

### ⏫ Improvements
- We did several network serialization improvements for Pawns (Character + CharacterSimple), making it more efficient and reducing bandwidth usage for it's sync.
- Now the server description accepts up to 200 characters.
- The game has been updated to Unreal 5.7.4.

### 🔨 Bug Fixes
- Fixed **Trigger** not drawing correctly if it's Box or Sphere on client side.
- Fixed client freezing forever when package reloading while another package reload was already happening.
- Fixed client spawned entities not being destroyed if they reach the kill z.

# nanos world - Version 1.45.0

- **Release Date:** 2023-03-26 20:01:41 UTC
- **Raw Timestamp:** `2023-03-26T20:01:41.000Z`

---

**🆕 New Features**
- Now we have a new Package type: `map`! This will be the preferred way of setting up your Maps now. This way maps have their own entry on Store/Vault and will be displayed on the Map List even if you don't have them downloaded, also as they are Packages, they can have their own scripts and a special Package.toml format for setting up Spawn Points and Custom Data. Loading maps in the old format (by the asset path reference) is still supported but deprecated, now you must set the map's package path instead.
- Now the Vault will display each Package type in a separated tab, including the new Map one.
- The default maps can now be loaded as the built-in packages `default-blank-map`, `default-testing-map`, `default-ocean-map` and `default-empty-map`.
- Added new methods to **HTTP**: **SetConnectionTimeout()** and **SetReadWriteTimeout()** to globally change the requests timeout settings.

**⏫ Improvements**
- Added several new mutexes and guards around the code, several weird crashes and problems on Menu and Loading Screen may be reduced now.
- Now Package files asked through HTTP will be sent from the memory cache (instead of being loaded from disk), making good use of the compression system. Assets are still loaded from disk.
- Added Ultra Dynamic Sky as a built-in entry on Vault, just for visualization.
- Now all Packages have their type validated when loading (e.g. `game_mode` can only load game-mode packages now).
- Now Vault images are loaded in a deferred way (only when they get visible), reducing the stutter when first opening the menu.
- The Main Menu and Vault Resource Details screen got several UI/UX improvements.
- Added a validator to check if the Index.lua is in lowercase.

**🔨 Bug Fixes**
- Fixed Vehicles not auto destroying with auto_destroy or by Kill Z.
- Fixed some random File Transfer errors and bugs.
- Fixed a bug when returning to menu from game not loading any Vault Resource.
- Attempt to fix HTTP file requests failing in the server with fatal error as the file was not present in the filesystem.
- Attempt to fix Camera Attachment being offset by wrong parameters.

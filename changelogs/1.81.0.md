# nanos world - Version 1.81.0

- **Release Date:** 2025-06-23 20:38:05 UTC
- **Raw Timestamp:** `2025-06-23T20:38:05.000Z`

---

Note: this update brings some significant internal refactoring that shouldn't break anything. Please report if you notice anything abnormal. Also, we are pushing the current bleeding-edge to the Steam default branch.

### ⏫ Improvements
- We've restructured our internal loading workflow for entities and hardcoded assets, improving spawning and loading entities and now deferring all gameplay assets to be loaded in the loading screen itself (they were being loaded when the game launched). Please report if you notice anything weird or asset missing (i.e. no sound, particle, mesh).
- We've refactored all internal log systems, for improving it's performance, fixing stutters and internal usability, async logs should output faster now. Please report if you notice any typo or broken log!
- Improved Entity Constructor error logs, now it displays exactly the internal error for each attempt constructor called.
- Removed last parameter from Input.Unregister (key_name). Calling it will throw an warning. You don't need to pass this parameter anymore.
- Now Input.Unregister will warn if attempting to unregister an unknown binding.
- Improved entities Hit sounds intensity algorithm to make it more consistent based on the impact force.

### 🔨 Bug Fixes
- Fixed several Lua coroutine crashes and issues, now values are passed between coroutines and the main lua states properly when calling C functions, also fixed Package.Require not working when called from inside a coroutine.
- Fixed Input.Unregister not removing from in-game keybinding settings.
- Fixed Client Console not copying the lines properly.
- Fixed UI Balloons with "hand cursor" when hovering.
- Fixed a crash when unloading a package while it was being loaded during a hotload.

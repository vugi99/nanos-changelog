# nanos world - Version 1.100.0

- **Release Date:** 2026-01-07 18:38:42 UTC
- **Raw Timestamp:** `2026-01-07T18:38:42.058Z`

---

### 🆕 New Features
- Now it's possible to **leave**, **delete** and **add members** to your Team through the Team Manage tab!
- Now it's possible to **transfer** a Vault Resource to another team, and **delete** a resource through the Vault Resource Manage tab.
- Added a new parameter to **Client.ShowNotification**: `duration`.

### ⏫ Improvements
- Now when saving a resource information, it will save the title to the .toml as well.

### 🔨 Bug Fixes
- Fixed New Game Popup not showing the custom settings descriptions when hovering them.
- Fixed a crash when uploading a new version and the connection fails.

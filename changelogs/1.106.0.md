# nanos world - Version 1.106.0

- **Release Date:** 2026-02-06 10:03:09 UTC
- **Raw Timestamp:** `2026-02-06T10:03:09.000Z`

---

### 🆕 New Features
- Now any texture parameter supports loading **Base64**, **URL images** (experimental), and cooked texture assets!
- Added a new method [`Steam.TriggerScreenshot()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/steam#static-function-triggerscreenshot) to trigger a Steam Screenshot.
- Added a new method [`Prop.SetInteractionToolTipText()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/prop#function-setinteractiontooltiptext) to change the Prop interaction tooltip.
- Added a new method [`SceneCapture.CaptureScene()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/scene-capture#function-capturescene) to force a capture. Also now it supports passing render_rate = -1 to disable auto rendering.
- Now [`Actor.AttachTo()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-attachto) and [`Cable.AttachStart/EndTo()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-attachendto) will return bool if the attachment was successful.
- Added a new Popup asking for First Time Benchmark when starting the game for the first time (will not do it automatically anymore).
- Cables have been reworked, and now "Locked" constraints will not be spawned with an offset automatically anymore. We added a new parameter to [`Cable.AttachEndTo()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/cable#function-attachendto): `constraint_offset` so it can be set and customized through scripting.
- Added new default Switch/Button sounds.
- added new default meshes SM_RetroCamera, SM_PhotoFrame, SM_LightSwitch and SM_PushButton.

### ⏫ Improvements
- Now the Drop input will also drop the grabbed prop.
- Improved Cable spawn performance, now if using all Free constraint, the Physics Constraint will stay deactivated (can be used just for visuals).
- Slightly improved Cables jittering and physics.
- Updated Sentry to 1.6.

### 🔨 Bug Fixes
- Fixes Cables not attaching correctly on Skeletal Meshes.
- Fixed Cables not attaching correctly when setting Limited angular limits.
- Fixed actors breaking all children collisions when being scaled.
- Fixed changing a mesh from a StaticMesh or Prop not resetting to placeholder "loading" mesh while the new one is loading.
- Fixed KeyBindings Settings not showing the keybinding description.
- Fixed Vault start button not appearing for local game modes.
- Fixed Loading Screen not playing media/sounds.
- Fixed Player.ResetCamera not resetting original values completely.
- Fixed some weapons collisions.
- Fixed Actor.SetRenderCullDistance not working if called on server-side.
- Fixed Paintable entities resetting all overrides when setting a new parameter.

# nanos world - Version 1.78.5

- **Release Date:** 2025-05-21 14:21:00 UTC
- **Raw Timestamp:** `2025-05-21T14:21:00.468Z`

---

### ⏫ Improvements
- Added profiling entries for all core ticks categories and to files downloads.
- Improved our internal ticks even more, making sure they run in correct order, decreasing the overall network latency between ticks.
- Improved the CTRL+C handling on server side, preventing the server being obliterated and smashed, causing unforeseen crashes and fatal errors.
- Added more internal logs and sentry debug info for helping debugging crashes and fatal errors.
- Increased the client-side network buffer to 1 MB (was 512 KB).
- Improved the News font on main menu.
- Disabled native Context Menu on main menu inputs.

### 🔨 Bug Fixes
- Fixed Fatal Errors when sending and flushing network messages to "invalid connections".
- Fixed Network Authority not updating the chained actors network authority properly, causing some actors to become with no net. authority client at all.
- Fixed a crash when loading invalid Textures.
- Fixed actors increasing the snapshot behind time indefinitely on clients that are the current network authority.

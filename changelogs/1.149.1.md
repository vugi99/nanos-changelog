# nanos world - Version 1.149.1

- **Release Date:** 2026-07-26 12:55:21 UTC
- **Raw Timestamp:** `2026-07-26T12:55:21.478Z`

---

### 🆕 New Features
- **Note: Potential breaking change:** `FinishSpawn()` now effectively finishes and trigger the `Spawn` event even from inside an Inherited Class constructor, and server `Spawn` event is triggered after sending `Spawn` event to clients.
- Added a new enum  [`SpawnMode`](https://docs.nanos-world.com/docs/next/scripting-reference/glossary/enums#spawnmode) to replace the old `defer_spawn` constructor parameter. Also new **Entity** methods  [`:SetSpawnMode()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/entity#function-setspawnmode) and [`:IsSpawned()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/entity#function-isspawned) to override it's behavior.
- Added **Animation Blueprint** methods to **Vehicle**: [`SetAnimationBlueprintPropertyValue()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-setanimationblueprintpropertyvalue), [`GetAnimationBlueprintPropertyValue()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-getanimationblueprintpropertyvalue). 
- Added new method [`Vehicle:SetCameraArmLength()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-setcameraarmlength).
- Added crouching full support and sync for **CharacterSimple**, and new methods  [`IsCrouching()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/charactersimple#function-iscrouching) and [`SetCrouching()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/charactersimple#function-setcrouching).
- Moved [`GetCanCrouch()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-getcancrouch) and [`GetCanJump()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/pawn#function-getcanjump) to **Base Pawn**.
- Added new method [`Input:IsBindingDown()`](https://docs.nanos-world.com/docs/next/scripting-reference/static-classes/input#function-isbindingdown).

### ⏫ Improvements
- Now the **Crash Reporter** window will display the crash stack to help identifying the possible reason of the crash.
- New [`Actor:GetAttachedEntities()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#function-getattachedentities) `recursively` parameter to also return the Actors attached to the attached Actors.
- Now `.GetAll()`, `.GetPairs()` and `.GetByIndex()` return all the inherited entities as well.
- Improved Steam authentication timing issues.

### 🔨 Bug Fixes
- Fixed `VehicleWheeled:FinishSpawn()` allowing to be called multiple times.
- Fixed [`Vehicle:PlayAnimation()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/vehicle#function-playanimation) with wrong parameter order.
- Fixed [`Weapon:PlayAnimation()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/weapon#function-playanimation) and [`StopAnimation()`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/weapon#function-stopanimation) missing and incorrectly ordered parameters.
- Fixed Client  [`NetworkAuthorityChange`](https://docs.nanos-world.com/docs/next/scripting-reference/classes/base-classes/actor#event-networkauthoritychange) triggering before the entity finished initializing.
- Fixed `MovementModeChange` event not passing the new movement mode.
- Fixed Character crouching not syncing correctly for other players.
- Fixed `distance_optimization` from the server's `Config.toml` not persisting.
- Fixed the Friends list failing to load a player's public profile info in some cases.
- Fixed a bug in Unreal Engine 5.7 causing incorrect UI background blur rendering.
- Fixed a malformed version string not throwing a proper error.

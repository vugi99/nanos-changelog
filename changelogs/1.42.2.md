# nanos world - Version 1.42.2

- **Release Date:** 2023-03-18 10:09:52 UTC
- **Raw Timestamp:** `2023-03-18T10:09:52.000Z`

---

🆕 **New Features**
- Added new method to **Blueprint** and **Widget**: `UnbindBlueprintEventDispatcher()`.

⏫ **Improvements**
- Now Character Camera uses TargetOffset (World location) now instead of relative attached location, solving problems of camera rotating or going into the ground when car is flipped for example.
- Improved Vehicle Unflip system, now to unflip you must rotate the steering instead of accelerating, also the system should more physically stable now.
- Added new Settings to Advanced Tab: `Download Idle Timeout`, to abort the file transfer if passed too much time without receiving any file/data packet from the server.
- Now `--logo` will download the server image in-memory, and not locally as Server.jpg anymore.
- Removed File Transfer Pooling (didn't succeeded and was causing too many problems).
- Increased Max HTTP File Transfer simultaneously to 32 and default to 16.

🔨 **Bug Fixes**
- Fixed Character PlayAnimation not stopping reload.
- Fixed Player ResetCamera not resetting interp location speed to default value.
- Attempt to fix a bug causing Characters to enter in swimming mode even when driving or attached to something.
- Fixed a crash when opening the chat just after the loading screen.
- Fixed .ogg Sounds being destroyed just after spawning if auto_destroy was true.
- Fixed passing Canvas, SceneCapture and WebUI to Blueprints not using the proper UI Material.
- Fixed achievements being given even if your Character was dead or in ragdoll.
- Fixed File Transfer freezing the client when using more than 8 simultaneous connections.
- Fixed "stuck" File Transfer problem when multiple players are connecting at the same time using high simultaneous connections.
- Fixed File Transfer errors while caching files.
- Fixed Vehicles not syncing Engine Started state on clients.
- Fixed Pickables enabling to be picked if setting collision on them.
- Fixed Console.Log causing errors when trying to print larger texts.
- Fixed House Keeping buttons in wrong settings page.
